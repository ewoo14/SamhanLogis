Security Architecture

보안 설계

JWT 발급 · Gateway 검증 · 내부 토큰 · 7단계 권한 · Soft Delete

인증 흐름

1
로그인 요청 → auth-service
POST /api/auth/login → Caffeine Rate Limit 검사 → BCrypt 비밀번호 검증 → JWT HS256 발급 (sub: userId, role 포함)
2
API 요청 → Gateway JWT 검증
Authorization: Bearer {token} → GatewayFilterFactory에서 JJWT 검증 → 실패 시 즉시 401 반환
3
X-User-Id / X-User-Role 헤더 주입
JWT 클레임에서 사용자 ID/역할 추출 → 헤더로 하위 서비스에 전달 → 하위 서비스는 JWT 재파싱 불필요
4
HeaderAuthenticationFilter (각 서비스)
X-User-Id/X-User-Role 헤더 읽기 → Spring Security Context 세팅 → @AuthenticationPrincipal로 접근
5
서비스 간 직접 호출 (게이트웨이 우회)
X-Internal-Token Shared Secret → InternalTokenFilter 검증 → ROLE_MASTER로 SecurityContext 세팅

Quick Start

로컬 개발 환경 시작

JDK 17 + Docker Desktop + Node.js 20+ 필요

백엔드 + 인프라

# 1. 인프라 스택 기동 docker compose -f infrastructure/docker-compose.yml up -d # 2. 전체 빌드 (테스트 제외) ./gradlew assemble # 3. 테스트 (Docker 필요) ./gradlew test # 4. 순서대로 서비스 기동 ./gradlew :services:eureka-server:bootRun # :8761 ./gradlew :services:api-gateway:bootRun # :8080 ./gradlew :services:auth-service:bootRun # :8081 # ... 나머지 서비스
