# 1068 fix3 real-QA spec

## 확정 계약

- 전잔은 회계일자와 전표번호 순으로 target 전표 직전까지의 posted 분개를 누적한다.
- 같은 날 전표번호가 없는 분개·입금·조정은 모든 slip 전표 뒤로 정렬한다.
- posted 분개만 금액 정본이다. slip projection과 직접 입금 projection은 화면 보조 표시이며 fold에서 제외한다.
- CANCELED/삭제 전표는 별도 목록이 아니라 posted 분개 상태로만 판정한다.

## real-QA 범위

- 격리 Testcontainers PostgreSQL과 accounting-service Spring context를 사용한다.
- 같은 날 앞/뒤 slip journal, no-slip manual journal, posted journal + projection, CANCELED projection을 검증한다.
- Testcontainers가 제공하는 실제 repository query와 transaction 왕복을 사용하며 mock은 외부 partner/slip client에만 사용한다.
