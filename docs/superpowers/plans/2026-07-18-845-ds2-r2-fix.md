# #845 DS-2 R2 적대검증 fix 실행 계획

> 기존 사용자 승인 계약 `docs/specs/845-ds2-template-management-spec.md` v4를 실행하는 계획이다. git 명령·커밋은 수행하지 않으며 PM이 대행한다.

**Goal:** SOL R2가 확증한 FE active-layout/latch/normalize 및 BE 도메인·Jackson·동시성·권한·상한 검증 결함을 회귀 테스트와 함께 수정한다.

**Architecture:** FE는 동일 `QueryClient`에서 mount fetch 완료를 기다리고 오류·검증 실패를 DEFAULT로 수렴시킨다. BE는 DTO 경계의 strict scalar 검증과 도메인 자체 가드를 유지하며, 활성 전환은 명시적 bulk 강등·flush·승격과 409 계약으로 보호한다. Flyway V10은 변경하지 않는다.

**Tech Stack:** React 18, TanStack Query v5, Vitest/Testing Library, Spring Boot/JPA, Jackson, JUnit 5, Testcontainers PostgreSQL, Flyway.

## Global Constraints

- git 금지: 파일 수정과 검증 명령만 수행하고 커밋·브랜치 조작·reset을 수행하지 않는다.
- FE 실행은 `npm`만 사용한다. pnpm/corepack을 사용하지 않는다.
- 모든 entity는 BaseEntity chain·soft delete 정책을 유지하고, 신규/수정 Java public 동작에는 한국어 Javadoc을 유지한다.
- Flyway V10은 불변이다. 마이그레이션 수정이 필요하면 신규 V11만 허용하되, 이번 fix에서는 V10을 수정하지 않는다.
- UUID·lock_version·audit 내부값은 사용자 화면/응답 계약에 노출하지 않는다.
- 제외 결함(code 60 VARCHAR(40), legacy DEFAULT sentinel, Playwright `||true`)은 수정하지 않는다.
