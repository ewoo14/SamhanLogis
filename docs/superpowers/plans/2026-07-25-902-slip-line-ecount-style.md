**도달 경로** — 사용자가 품목을 고르고 수량을 비워 두거나, 수량만 입력하고 품목을 못 고른 채 저장하면 그 행은 **경고 없이 사라집니다**. 사용자는 자기가 입력한 줄이 전표에 없다는 걸 저장 후에야 알게 됩니다.

**적용 범위 실측** — 전표 작성 폼은 `SlipFormPage.tsx` **하나**이며 `isOutbound` 분기로 출고/입고를 함께 처리합니다(`:988` `requiredWh = isOutbound ? sourceWh : destWh`). 따라서 이 한 화면 변경이 전표 전종을 덮습니다.

**선행 조건 해소 확인** — 이슈가 지정한 선행 #824(품목행 공급가액·부가세 열)는 이미 정리됐습니다(원격 브랜치 삭제·이슈 close). 같은 그리드를 지금 건드려도 충돌하지 않습니다.

## 2부 · 착수 확정 사항 (PM 결정)

이슈가 "착수 시 확정"으로 남긴 것들을 확정합니다.

| 항목 | 결정 | 이유 |
|---|---|---|
| 초기 빈 행 개수 | **5행** | 이카운트 관행. 대부분의 전표가 5행 이하이므로 '행 추가' 클릭이 사실상 사라짐 |
| "값을 넣으면"의 판정 | **행이 비어 있지 않게 된 순간**(품목·수량·단가 등 어떤 셀이든 사용자 입력이 들어간 때) | 품목 선택만을 트리거로 삼으면 수량부터 입력하는 사용자에게 증식이 안 일어남 |
| "정확히 설정되지 않은 행" 판정 | **현행 저장 필터를 그대로 유지**(`productId` 있음 AND `quantity > 0`) | 판정 기준을 바꾸면 BE 계약·합계·기존 테스트까지 흔들림. 이번 슬라이스는 **판정은 그대로 두고 표시만 추가** |
| 순서 영속 | **현행 유지**(배열 순서 = 저장 순서) | req3 이 이미 그렇게 동작 |
| 적용 범위 | **전표 작성 폼(`SlipFormPage`) 만** | 아래 범위 동결 참조 |

## 3부 · 불변식 (구현 수단은 지시하지 않습니다)

| # | 불변식 |
|---|---|
| **I1** | 사용자가 값을 입력한 행은 **저장에서 조용히 사라지지 않는다**. 저장하기 전에, 그 행이 전표에 포함되지 않는다는 것을 화면에서 알 수 있다. |
| **I2** | 마지막 행에 입력하면 아래에 입력 가능한 빈 행이 생겨, **'행 추가'를 누르지 않고 연속 입력**할 수 있다. |
| **I3** | 빈 행이 몇 개 있든 **저장 페이로드·합계 금액·유효 행 수는 달라지지 않는다**. 빈 행 때문에 저장 버튼이 막히거나 합계가 틀리지 않는다. |
| **I4** | 자동 증식은 **끝없이 자라지 않는다** — 마지막 행이 채워졌을 때 한 행만 생긴다. 입력을 지웠다가 다시 넣어도 행이 중복 증식하지 않는다. |
| **I5** | 기존 동작이 깨지지 않는다 — 드래그 정렬, 선택 삭제, 최소 1행 유지, 거래처 변경 시 단가 재조회, 세트(BUNDLE) 재고 가드가 모두 그대로 동작한다. |
| **I6** | **키보드만으로** 연속 입력이 가능하다. 새로 생긴 행으로 이동이 끊기지 않고, 화면 낭독기 사용자에게 행이 늘어난 사실이 전달된다. |
| **I7** | 제외 표시는 **사용자가 아직 입력 중인 행을 오류처럼 위협하지 않는다** — 빈 행(아직 손대지 않은 행)과 "입력했으나 불완전한 행"을 구별해 다룬다. |

🚨 I7 이 핵심입니다. 초기 5행이 전부 "제외됩니다" 로 붉게 표시되면 그건 개선이 아니라 소음입니다.

## 5부 · 회귀 울타리 — 표면을 명시합니다

"테스트를 추가했다"가 아니라 **어느 표면이 RED 로 잡히는지** 명시하십시오.

| 표면 | 울타리가 잡아야 하는 것 |
|---|---|
| 자동 증식 | 마지막 행 입력 → 행이 **1개** 늘어남. 중간 행 입력으로는 늘지 않음. 반복 입력으로 중복 증식하지 않음(I4) |
| 저장 페이로드 | 빈 행 5개가 있어도 전송 payload 의 lines 수·내용이 빈 행 없을 때와 **동일** (I3) |
| 합계·저장 버튼 | 빈 행이 합계 금액과 저장 가능 여부를 바꾸지 않음 (I3) |
| 제외 사전 표시 | 품목만 고르고 수량 0 인 행 / 수량만 있고 품목 없는 행이 **저장 전에** 제외 대상으로 표시됨. 손대지 않은 빈 행은 그렇게 표시되지 **않음** (I1·I7) |
| 기존 기능 회귀 | 드래그 정렬 · 선택 삭제 · 최소 1행 · 거래처 변경 단가 재조회 · 세트 재고 가드 (I5) |
| 키보드/a11y | 새 행으로 이동이 끊기지 않고 증식이 낭독됨 (I6) |

🚨 **RED-first**: 각 불변식을 깨는 실패 테스트를 **먼저** 쓰고 **RED 출력 원문을 제출한 뒤** 구현하십시오.
