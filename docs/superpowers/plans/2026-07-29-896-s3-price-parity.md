# #896 슬3 가격 정합 구현 계획

> **For agentic workers:** 이 계획은 현재 세션에서 순차 실행한다. 각 단계는 RED→GREEN 검증을 거친다.

**Goal:** 라이브 GAS와 order-app·estimate-app의 리모컨 360 및 냉방전용 상부토출 30HP 방진가대 선택·단가를 일치시키고, 카탈로그 누락을 조용히 삼키지 않게 한다.

**Architecture:** 두 앱의 기존 inline 계산 함수를 최소 수정한다. 공통 수량 경계 하네스를 이용해 같은 입력의 두 앱 출력을 비교하고, 각 앱의 실제 `commUnitPrice`를 별도 VM 테스트로 실행한다. 파생 품목을 최종 `commQty`에 반영하기 전에 카탈로그 행을 필수 조회하여 누락 시 명시적 오류를 낸다.

**Tech Stack:** inline JavaScript, Vitest, Jest, Node `vm`, shared `legacyQuantityBoundary`, Docker PostgreSQL `product_db` read-only query.

## Global Constraints

- `tools/legacy-gas/**`는 읽기 전용이며 수정하지 않는다.
- git 쓰기 명령(commit/push/checkout/reset/stash)은 실행하지 않는다.
- 이번 슬라이스는 차이 ①②만 다룬다. 기준일(③)은 변경하지 않는다.
- `AR-EH05`와 `방진가대S2중`은 공유 `product_db`에 실재하는 코드만 사용한다.
- `isStd` 30HP의 `방진가대S2대` 규칙과 estimate-app의 이미 일치하는 360 리모컨 규칙은 변경하지 않는다.
- RED 테스트는 생산 코드 수정 전에 실행해 실패 원문을 기록한다.
