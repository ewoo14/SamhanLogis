# 901/894 서버 메뉴 catalog Implementation Plan

**Goal:** auth-service가 인증 계정별 권한 필터 메뉴 catalog를 제공하고 두 데스크톱이 이를 사용한다.

**Architecture:** 메뉴 메타데이터는 auth-service의 코드 정본으로 유지한다. API는 현재 인증 주체의 VIEW 권한과 교집합한 앱별 catalog만 반환하며, FE의 route guard는 그대로 둔다.

**Tech Stack:** Spring Boot MVC/JUnit/MockMvc, React/TypeScript/Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-08-15-901-894-menu-catalog-design.md`

## Global Constraints

- 결정 B만 구현한다. Claude tool call과 chat-room 변경은 구현하지 않는다.
- git 명령(add/commit/push/checkout/worktree/stash)을 실행하지 않는다.
- auth-service만 재배포한다.
- UUID와 DB id를 catalog 응답에 넣지 않는다.
- 권한 없는 메뉴는 응답·렌더링에서 제거하고 route guard는 유지한다.
