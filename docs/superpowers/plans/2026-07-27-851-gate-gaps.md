# #851 게이트 0 표면 보강 구현 계획

> **작업자 안내:** 이 계획은 현재 작업 트리에서 단계별로 실행한다. 사용자 지시에 따라 git 명령(add/commit/push/checkout/branch/stash)은 실행하지 않는다.

**목표:** real-QA 공유 하네스의 상대경로 네비게이션을 복구하고, arologis-only PR에서도 Notion zero 및 config audit 가드를 실행한다.

**구조:** 공유 Playwright 설정의 `use.baseURL`만 보강해 기존 스펙의 `/…`와 `/#/…` 이동 문자열을 유지한다. arologis 전용 워크플로에는 기존 가드 명령을 별도 read-only 잡으로 추가하고, 공용 CI와 중복되는 경우에도 서로 독립된 check로 동작하도록 잡 이름을 구분한다.

**기술 스택:** Playwright Test, GitHub Actions YAML, Bash 정적 가드, PowerShell 설정 감사 가드.

## 전역 제약

- `clients/desktop/playwright.real-qa.config.ts` 로 발견되는 `*-real-qa.spec.ts` 중 네비게이션 설정 때문에 실행되지 못하는 스펙은 0개여야 한다.
- 기존 real-QA 스펙의 BrowserRouter 경로와 HashRouter `#/` 경로를 수정하지 않는다.
- 로컬에서는 이 슬라이스와 직접 관련된 대상 스펙/가드만 실행하고 저장소 전체 테스트 스위트는 실행하지 않는다.
- Playwright는 `clients/desktop/node_modules/.bin/playwright`를 직접 사용한다.
- 두 가드의 실제 위반 주입 RED 출력 원문을 기록하고 주입한 변경은 원복한다.
- 모든 보고서와 주석은 한국어로 작성한다.
