# D-G7 — 정산서 확정 취소 경로 + 확정 후 기준일 잠금

> 근거: `docs/dev-reports/2026-08-11-gas-sweep-devlead-decisions.md` (D-G7)

## 경위

```text
개발책임자 1차 결정  "정산서 확정 후 기준일 수정 금지"
구현자 중단 보고     확정 취소 경로도 기준일 수정 API 도 **아예 없다**
                     ⟹ 그대로 넣으면 사실상 **영구 잠금**
PM 재상정            선택지 3개로 올림
개발책임자 2차 결정  **"확정 취소 경로를 만든다"**
```

## 범위

```text
① 확정 취소 (CONFIRMED → DRAFT)
② 기준일 수정 — DRAFT 에서만
③ 재확정 (DRAFT → CONFIRMED)
```

## 🚨 착수 시 확정해야 할 미결

```text
· 이미 결재에 붙은 정산서를 취소할 때 **그 결재를 어떻게 하는가**
    결재 진행 중이면 취소를 막는가 / 완료됐으면 취소가 안 되는가
· 재확정 시 문서번호를 **새로 받는가 유지하는가**
    🔑 새로 받으면 ApprovalAttachment.ref_doc_no 참조가 끊긴다
```

## 이미 있는 것

```text
S1  문서번호 yyyy/MM/dd-N · DRAFT 무번호 · CONFIRMED 시 채번 (기준일 = settlementDate)
S2  versioned 요율 계약 — 계약은 저장소에서 versionNo 로 조회 · CONFIRMED snapshot 불변
S3  ApprovalAttachment 가 문서번호 문자열(ref_doc_no)로 참조 (#1168 · 검증 중)
```
