# #887 슬5 R3 잔여 3건 구현 계획

> **실행 담당자 안내:** 이 계획은 현재 세션에서 직접 실행한다. 각 단계는 체크박스로 추적하며, 사용자가 금지한 git 명령은 실행하지 않는다.

**목표:** CODEF·일마감·안전재고 세 화면에서 오류 안내 대비, 전체 범위 칩의 키보드 왕복 토글, 대안 경로 안내 계약을 일관되게 고친다.

**구조:** 공용 `TagChip`은 이미 `Enter`·`Space`를 pressable 영역의 `onClick`으로 전달하므로 수정하지 않는다. 세 화면의 전체 범위 클릭 핸들러를 `ALL이면 해제, 그 외에는 ALL 선택`으로 바꾸고, 안내 문구는 각 화면의 실제 대안 선택 단위를 함께 말한다. CODEF 오류 힌트는 자매 화면의 `--color-danger-700` 토큰을 사용한다.

**기술 스택:** React + TypeScript, Vitest/Testing Library, Playwright mock renderer, CSS custom properties.

## 전역 제약

- 잔여 3건만 다루며 이미 해소된 MED·LOW·pre-existing 항목과 V64 적용 마이그레이션은 수정하지 않는다.
- 세 항목 모두 구현 전에 실패 테스트를 실행하고 RED 원문을 보고서에 기록한다.
- 대비값은 fallback 주장 없이 실제 브라우저의 `getComputedStyle` 렌더 결과와 실제 배경으로 계산한다.
- `aria-pressed`가 있는 전체 범위 컨트롤은 같은 키(Enter/Space)로 켜고 끌 수 있어야 한다.
- 모든 보고서·문서·주석은 한국어로 작성한다.
- 전체 저장소 스위트는 실행하지 않고 관련 테스트만 실행한다.
- 데스크톱 타입 검증은 `npm run typecheck`를 사용한다.

### 작업 3: 세 화면 전체 범위 칩을 양방향 토글로 변경

**파일:**

- 수정: `clients/desktop/src/renderer/routes/components/CodefImportScopeForm.tsx`
- 수정: `clients/desktop/src/renderer/routes/DailyClosingPage.tsx`
- 수정: `clients/desktop/src/renderer/routes/SafetyStockAlertsPage.tsx`

**수정 계약:**

- CODEF: `scopeMode === 'ALL'`이면 `clearScope()`, 아니면 `selectAllScope()`를 호출한다.
- 일마감: `execScopeMode === 'ALL'`이면 기존 전체 해제 상태 정리를 수행하고, 그 외에는 기존 전체 선택 상태 정리를 수행한다.
- 안전재고: `configScopeMode === 'ALL'`이면 기존 전체 해제 상태 정리를 수행하고, 그 외에는 `selectAllConfigScope()`를 수행한다.
- X 제거 버튼은 그대로 유지하며, keyboard/mouse 중앙 토글과 같은 해제 결과를 만든다.

### 작업 4: 세 화면 대안 경로 문구를 동일 계약으로 보강

**파일:**

- 수정: `clients/desktop/src/renderer/routes/components/CodefImportScopeForm.tsx`
- 수정: `clients/desktop/src/renderer/routes/SafetyStockAlertsPage.tsx`
- 확인: `clients/desktop/src/renderer/routes/DailyClosingPage.tsx`

**문구 계약:**

- CODEF: 전체 칩 또는 계좌·카드·대출 개별 항목 선택 경로를 모두 안내한다.
- 일마감: 전체 칩 또는 거래처 선택 경로를 모두 안내한다.
- 안전재고: 전체 칩 또는 창고 선택 경로를 모두 안내한다.
