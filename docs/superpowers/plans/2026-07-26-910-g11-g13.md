# 910 닫는 적대라운드 — G11~G13 실행 계획

## 목표

- `build:win`뿐 아니라 직접 `electron-builder` 호출도 sentinel을 배포 가능한 Electron 산출물로 포장하지 못하게 한다.
- PWA와 Capacitor의 릴리스 산출물 경로를 명시 버전 wrapper로 분리하고, 무주입 개발·CI 빌드는 계속 동작시킨다.
- 고정 개발 sentinel이 실 서버의 최소 지원 정책 때문에 개발자를 차단하지 않도록 공개 버전 판정을 fail-open 한다.
- sentinel은 admin 릴리스 등록 대상이 아니며, 정식 릴리스 버전으로 오인되지 않는다는 계약을 유지한다.

## 구현 순서

1. 기존 우회 경로와 sentinel CRITICAL 판정을 실패 테스트로 고정한다.
2. Electron builder hook에서 릴리스 모드·주입 버전·포장된 ASAR의 실제 버전을 함께 검증한다.
3. PWA/Capacitor 명시 버전 릴리스 wrapper와 산출물 검증을 추가하고 README·계약 테스트를 갱신한다.
4. 서버에서 `0.1.0-dev`를 릴리스 순서에 넣지 않고 `NONE`으로 응답하는 테스트와 구현을 추가한다.
5. 무주입 개발 경로, 명시 주입 릴리스 경로, 모바일 EAS, 서버·클라이언트 회귀를 순서대로 검증한다.
6. 생성 산출물·프로세스·테스트 DB가 남지 않았는지 확인하고 변경 파일과 미검증 범위를 보고한다.

- git 쓰기와 GitHub 쓰기를 하지 않는다.
- `docs/qa/**`, 적용된 Flyway, 공유 `dashboard_db`를 변경하지 않는다.
- #931 대상 `clients/desktop/src/main/auto-update.ts` 및 해당 interop 테스트는 수정하지 않는다.
