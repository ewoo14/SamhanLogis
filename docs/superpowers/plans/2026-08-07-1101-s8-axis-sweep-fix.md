# S8 축 기반 자격 배선 수정 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development and superpowers:verification-before-completion to implement this plan task-by-task.

**Goal:** 저장소의 남은 QA 자격 소비 실행 파일 8개가 표준 자격 로더를 경유하도록 하여 직접 환경변수를 읽지 않고, `.env.local` fallback과 fail-fast 계약을 유지한다.

**Architecture:** 기존 `scripts/lib/qa-credentials.cjs`를 그대로 사용한다. 네 Playwright spec에 `resolveQaCredential('QA_DEV_DEFAULT_PASSWORD')`를 import하고 로그인 payload 생성 시 호출한다. 별도 로더·환경변수·컨테이너 변경은 하지 않는다.

**Tech Stack:** TypeScript, Playwright, Node.js `node:test`, 기존 QA credential loader.

## Global Constraints

- `git ls-files` 기준으로 자격 읽기 축을 재계수하고 `node_modules` 원천을 배제한다.
- `DEV_PASSWORD` 직접 소비 실행 파일은 0개로 만든다. 로더 alias 정의와 기존 로더 테스트의 호환성 검증은 유지한다.
- 자격 누락 시 표준 로더가 `.env.local` 경로와 키 이름을 안내하며 실패해야 한다.
- `.env.local` 환경의 기존 로그인 동작과 자격 불필요 CI 동작을 보존한다.
- 비밀번호·`.env.local`은 커밋하지 않고, 다른 워크트리·commit/push·컨테이너 rebuild는 하지 않는다.
