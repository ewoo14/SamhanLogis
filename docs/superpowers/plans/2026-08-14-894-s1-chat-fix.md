- `clients/desktop`의 정상 채팅 경로를 깨뜨리지 않는다.
- `ux_messages_room_sequence` unique 제약을 삭제하거나 완화하지 않는다.
- UUID는 사용자 화면·URL에 노출하지 않는다.

- git 쓰기 명령과 커밋은 사용하지 않는다.
