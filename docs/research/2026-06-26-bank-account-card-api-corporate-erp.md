# 딥리서치 — 국민·기업·우리·신한 계좌·카드 거래내역 API (법인 ERP 자동연동 관점)

> 조사일 2026-06-26 · 기준 2025~2026 현행 · 목적: 법인 회계 시스템이 은행 계좌·법인카드 거래내역을 **read-only 자동수집**해 회계 대사·자동분개에 활용.
> 방법: 5각도 병렬 검색 → 공식 1차 출처 fetch → 핵심 주장 적대적 3중 검증. 신뢰도 표기(✅공식확인/🟡정황/⚪미발견).

## 0. 핵심 요약 (TL;DR)
1. **계좌 거래내역 API는 4개 은행 모두 제공 — read-only 자동수집 기술적으로 가능.** 경로: ① **금융결제원 오픈뱅킹**(2025-01-02부터 **법인도 전 은행 계좌 잔액·거래내역 실시간 통합조회**, 단 **조회 전용·이체 불가**) ② **각 은행 자체 기업 오픈API 포털**(KB·IBK 거래내역 API 1차 확인, 신한·우리 포털 존재) ③ **펌뱅킹**(예금거래명세 전송).
2. **일반 ERP 벤더가 은행 API 키를 "직접" 발급받긴 어렵다.** 오픈뱅킹·은행 포털 모두 핀테크/전자금융업 자격 또는 **제휴·이용기관 심사 + 금융보안원 보안점검** 요구 → 현실 경로 = **자격 보유 ASP(쿠콘·웹케시 등) 경유** 또는 **각 은행 개별 제휴**.
3. **카드 거래내역은 은행이 아니라 카드사 영역, 표준화 미흡.** 공식 오픈API로 법인카드 승인·청구내역 제공 확인된 곳 = **우리카드(apiportal.wooricard.com) 유일**. KB·IBK는 은행 기업채널로 카드 조회(자사발급 중심). 신한카드·KB국민카드 외부 self-service 법인카드 API ⚪미발견.
4. **마이데이터는 법인카드에 사용 불가**(신용정보법상 개인 한정). 개인사업자 '마이비즈니스데이터'(2026 추진)도 법인격 기업 제외.
5. **다(多)카드사 통합 수집의 현실 해법 = 스크래핑/EDI 기반 ASP**(쿠콘·비즈플레이·경리나라·더존·CODEF·뱅크다). 단가는 전부 B2B 견적형(비공개).

## 1. 규제 맥락
- **오픈뱅킹** = 전자금융거래법 기반, 금융결제원 공동운영, 보안점검=금융보안원.
- **법인 오픈뱅킹 = 2025-01-02 시행** — 한 은행 채널에서 全은행 본인계좌 잔액·거래내역 실시간 조회. **조회 전용(이체 미포함)**. [fsc.go.kr/no010101/83750](https://www.fsc.go.kr/no010101/83750)
- **마이데이터 = 개인 한정**(법인 신용정보 제외, 신용정보법 제2조). 무허가 영위 형사처벌.
- **마이데이터 스크래핑 2022-01-05 전면금지**(표준 API만). 단 비-마이데이터 B2B 법인 자기계좌 스크래핑은 별개로 잔존.
- **이용기관 자격** = 핀테크 분류업종/전자금융업자 + 이용적합성 심사 + 금융보안원 보안점검 + 이용계약.
- ⚠️ **정정**: "법인 오픈뱅킹은 횡령 우려로 이체 제한" 인과는 금융위 원문 아님(언론 해설). 공식 명칭 자체가 "오픈뱅킹 법인계좌 **조회**서비스"로 구조상 조회 전용. **ERP read-only 대사엔 이 제한 무관**(이체 불필요).

## 2. 은행별 종합표 (범례 ✅공식1차 / 🟡정황 / ⚪미발견)
| 은행 | (A) 계좌 거래내역 API | (B) 카드 거래내역 API | 실시간 | 신청/비용 |
|---|---|---|---|---|
| **KB국민** | ✅ 기업 OpenAPI(obizapi.kbstar.com): 타행 수시입출 거래내역·오픈뱅킹 계좌거래내역 + 오픈뱅킹 | ✅ 같은 포털 카드정보·승인내역·승인다건·청구·대사 6종(은행 기업채널) ⚪KB국민카드 자체 self-service ⚪미발견 | 🟡조회시점·오픈뱅킹 실시간 | 제휴 7단계 심사·기업인터넷뱅킹. 과금 협의(비공개) |
| **IBK기업** | ✅ IBK 오픈API(devapiportal.ibk.co.kr): 원화/외화 예금계좌 거래내역 조회 | 🟡 카드 승인내역 조회 API(IBK=BC카드 회원사, 자체카드사 없음) | 🟡조회성 | 앱 등록→정보보호 보안심사→운영키. 비공개 |
| **우리** | 🟡 우리 Developer(developer.wooribank.com) 금융데이터조회 + 오픈뱅킹/기업 대량거래내역조회 | ✅ **우리카드 개발자포털(apiportal.wooricard.com): 법인카드 정보·승인·청구집계·청구상세 4종**(가장 명확) | 🟡약정 기반 | 기관약정→API약정→서비스 신청·승인. 비공개 |
| **신한** | 🟡 신한 Open API 마켓(openapi.shinhan.com, 2023-10): 거래내역 조회 포함(제휴) | 🟡 신한카드 DataBada(B2B 데이터마켓, 2024-08) ⚪법인카드 self-service 공개 API 미발견 | 🟡조회성 | 1:1 제휴문의→검토→계약. 비공개 |

**공통**: ① 거래내역 API 카탈로그상 존재 ② 개인 셀프서비스 아닌 **제휴/이용기관(B2B) 모델** ③ 과금표 전부 비공개(계약 협의) ④ 별도로 오픈뱅킹 공동망으로도 계좌내역 수집 가능.

## 3. 경로별 비교 (ERP 자동연동)
| 경로 | 계좌 | 카드 | 실시간 | 법인적합 | 난이도 | 비고 |
|---|---|---|---|---|---|---|
| ① 오픈뱅킹(금결원) | ✅법인(2025-) | △청구·기본정보 | 실시간 | 높음(정공법) | 높음(자격·보안점검) | 직접자격 없으면 ASP 경유, 건당 수수료 |
| ② 펌뱅킹/CMS | ✅예금거래명세 | △우리 WIN-CMS 법인카드 | 실시간/일괄 | 높음(기업전용) | 중~높음(전용선·고객비용) | 건당 과금(신한 실시간 300원, 2021) |
| ③ 각행 자체 오픈API | ✅KB·IBK | ✅우리카드·KB/IBK 은행채널 | 조회성 | 중(개별제휴) | 중~높음(다은행 N중) | 단일 주거래은행이면 합리적 |
| ④ 스크래핑/RPA | ✅인터넷뱅킹 위임 | ✅다카드사 | 5~30분~호출시점 | 중(인증위임 보안부담) | 낮음(ASP위탁) | 마이데이터 금지, B2B 법인 자기계좌 잔존 |
| ⑤ **핀테크 ASP** | ✅혼합 | ✅EDI/스크래핑 | ASP별 | **높음(업계표준)** | **낮음(API 1개로 다기관)** | **현실적 최선**, 단가 견적형 |

### 핀테크 ASP
- **쿠콘** — 스크래핑+펌뱅킹+마이데이터 혼합(은행22·증권20·카드15 직결), 다기관 단일 API 애그리게이터.
- **웹케시** — 펌뱅킹 기반(인하우스뱅크/브랜치)+경리나라, 대기업·공공 자금관리 1위, ERP 내재화(WeHub).
- **비즈플레이** — 카드사 EDI 17사+스크래핑, 카드 10사 실시간(하나 30분 배치), 국세청 과세유형 검사. (웹케시 사내벤처 출신, 더존 계열 아님.)
- **더존 Smart A/iCUBE** — 카드사 ID/PW 스크래핑(자료수집→자동분개), ERP 내장.
- **뱅크다** — 인터넷뱅킹 스크래핑(5~10분, 인증서 불요)+REST API, 은행 입출금 자동확인 특화.
- **CODEF** — 위임 스크래핑(은행+14개 카드사 법인 승인·청구), 개발자 친화 API(개인+법인).

## 4. 카드 거래내역(법인카드 경비 자동수집) — 4경로
1. **카드사 공식 오픈API** — 우리카드 유일 명확(법인카드 4종). 신한·KB국민카드 외부 self-service ⚪미발견.
2. **은행 기업채널(펌뱅킹/기업 오픈API)** — KB obizapi 카드 6종, IBK 카드승인내역(자사발급 중심).
3. **제3자 집계 ASP(스크래핑/EDI)** — 비즈플레이·CODEF·경리나라·더존. **여러 카드사 통합 시 사실상 유일 해법**(카드사 포털 자격 위임 필요).
4. **국세청 홈택스 사업용 신용카드** — 세무 보조(지연 집계, 실시간 대사 한계).

### ❌ 용도 혼동 주의
- **마이데이터** = 개인 한정, 법인카드 불가.
- **여신금융협회 매통조(cardsales.or.kr)** = 가맹점(판매자) 매출·입금 데이터(받은 매출 대사용), "우리가 쓴 법인카드 경비"엔 부적합.

## 5. ERP 자동연동 권고
- **주거래 1~2개 은행 + 단일 카드사** → 해당 은행 기업 오픈API/펌뱅킹 직접제휴 + (우리카드면) 우리카드 법인카드 API 직결이 최선.
- **다은행·다카드사 통합** → 쿠콘류 API 애그리게이터 또는 법인 오픈뱅킹(자격보유 파트너 경유). 카드는 EDI 기반(비즈플레이형)이 증빙·실시간 우위.
- **자체 직접구현 비추천**(자격·보안점검·개별계약 장벽) → 자격 보유 ASP 위탁이 업계 표준.
- **요약: 계좌=법인 오픈뱅킹(실시간·조회전용) 정공법 + 카드=ASP(스크래핑/EDI) 조합이 가장 합리적.**

## 6. 불확실·미확인 (정직)
- KFTC 거래내역 "1회 3개월·5년" = 공식 미명시(페이지당 25건 페이지네이션만 확인). 단정 금지.
- 오픈뱅킹 2025~2026 현행 단가 미확인(2021 인하 거래내역 10원/건만). 카드사 self-service(신한/KB) "미발견"≠"부재"(비공개 제휴 가능성).
- 신한·우리 거래내역 API 상세 = 포털 로그인벽으로 제목/카테고리 레벨까지만. ASP 단가 전부 견적형.
