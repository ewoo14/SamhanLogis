## 결함 / 재현

입고 상세의 lifecycle 버튼 라벨과 API 전이가 역전되어 있습니다.

1. 입고 전표를 `SENT`까지 전송하고 수락합니다.
2. `완료 (처리 시작)`은 `/process`를 호출해 `PROCESSING`으로 전이합니다.
3. 화면의 `완료 (검수 시작)`을 클릭하면 `/inspect`를 호출하지만, 백엔드는 `PROCESSING → INSPECTING`에 `/complete`를 요구해 `409`: `전이 가능한 상태가 아닙니다: 현재 처리중, 필요 검수중`을 반환합니다.
4. `/complete` 후 화면의 `완료 (처리 완료)`를 클릭하면 `/complete`를 다시 호출해 `409`: `전이 가능한 상태가 아닙니다: 현재 검수중, 필요 처리중`을 반환합니다.

이번 QA에서는 동일 실 인증 세션의 정식 `/complete` API와 GUI의 검수 완료 액션을 조합해 입고를 끝냈습니다. 이는 라이브 QA 결함으로 기록하며 코드 수정은 하지 않았습니다.
