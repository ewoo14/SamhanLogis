## 확인 3 — 실행 중 서비스의 기존 호출·무권한·PARTNER 실제 HTTP

- 실 데이터 영향 건수: 201행 모두 8열 원천값 존재, 미매핑/공란 0건.

## 1차 적대검증 판정

- **도달 결함 1건:** 응답 DTO의 내부 UUID 3종 노출. 기존 실 HTTP에서 2행·6필드 값 노출을 재현했고, 전체 201행 순회 시 603필드 값으로 확대 가능하다.
- 기존 `productId` 계약은 직접 호출 HTTP 200 및 전체 inventory-service 테스트 통과로 유지됨을 확인했다.
- 무권한 내부 역할과 PARTNER는 구 런타임에서 전체조회가 먼저 400으로 막혀 새 코드의 실제 403을 확인하지 못했다. 정적 권한 경계는 변경 없고 grant 대상은 내부 4역할뿐이다.
- VIRTUAL은 화면 세 수량 열 모두 `—` 분기다. 실 DB VIRTUAL balance는 0행이라 실 화면 재현은 없었다.
- 활성 balance 201행·balance 창고 2곳·품목 101종·실재고 46,700은 재현됐다. 단, “활성 창고 2개”라는 표현과 달리 실제 미삭제 창고는 4곳이며 balance 보유 창고가 2곳이다.
- 조회 IT 실측은 DB 2 statement(content+count)였고 N+1은 관측되지 않았다. V23 번호/적용 충돌은 없으나 실 DB 미적용 상태라 실제 index 사용은 확인하지 못했다.

## 이 라운드가 보지 않은 축

- PR 코드가 배포된 실 inventory-service의 전체/창고별 HTTP 200 응답 본문.
