## 3. Unicode 정규화 — Java/TypeScript 동일 규칙

비교용 skeleton을 다음처럼 닫았다.

```text
NFKD → \p{M}(결합문자) 제거 → \p{Cf}(format 문자) 제거 → dash/confusable folding → UUID 판정
```

반환용 표시 문자열에는 이 skeleton을 사용하지 않는다. 이름을 아는 경우의 원문, 자모 분해형 한글, `변경자 미상`, `system` → `시스템` 동작을 유지한다.

실제 추가 공격:

```text
c\u0301afebabecafebabecafebabecafebabe
```
