## 종료조건 1 — 새 조합 열거 및 확인

이번 배선 변경으로 가능한 생성 조합은 다음 4가지로 열거했다.

1. Spring 운영 bean: `PartnerLedgerReadService + TaxInvoiceBatchRepository + ObjectMapper + LedgerSnapshotBatchNoGenerator` 4-인자 생성자 → `@Autowired`로 선택. `Mig11LedgerPartnerCodeWidthImportIT`, `LedgerSnapshotPersistenceIT` 컨텍스트 로드 GREEN으로 확인.
2. 기존 단위 테스트 legacy 조합: 앞의 3개 의존성만 직접 전달하는 3-인자 생성자 → 직접 호출 유지. `LedgerSnapshotServiceTest` GREEN으로 확인.
3. R33 신규 단위 테스트 조합: 4개 의존성을 직접 전달하는 4-인자 생성자 → 직접 호출 유지. `LedgerSnapshotServiceTest` GREEN으로 확인.
4. `@MockBean LedgerSnapshotService` 조합: Spring 컨텍스트의 실제 service 대신 mock으로 대체 → `AccountingPermissionControllerIT` GREEN으로 확인.

추가로 운영 생성자가 필요로 하는 `LedgerSnapshotBatchNoGenerator` bean은 `@Service`로 등록된 동일 컨텍스트에서 정상 주입되었으며, 별도 bean/@Bean/TestConfiguration 수정은 필요하지 않았다.
