## 공통 실행 관찰

- 모든 시나리오는 실제 Electron renderer에서 로그인·기간 입력·조회·행 클릭·인쇄 버튼 클릭으로 수행했다.
- 공통 콘솔에는 정적 파일 `ERR_FILE_NOT_FOUND`, 앱 보조 요청 `403`, `500`, `503`가 반복됐다. 원장 목록/상세/인쇄 화면의 오류 배너 여부는 시나리오별로 별도 판정했고, 이 라운드에서 수정하지 않았다.
- 다중 페이지 후보 탐색을 위해 5월 read-only DB 집계로 line 수가 많은 거래처를 고른 뒤, 최종 판정은 반드시 GUI 결과로 했다. DB write/DDL은 없었다.
- 실제 스택의 `samhan-accounting-service`, `samhan-slip-service`, `samhan-api-gateway`, `samhan-postgres`, `samhan-partner-service`는 확인 시 healthy/running이었다. Docker 빌드·재기동은 하지 않았다.
