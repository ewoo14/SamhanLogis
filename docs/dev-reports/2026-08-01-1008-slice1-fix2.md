## 확인 8 — FE 실패 원인 판정 및 수정

실패 원문을 그대로 재현했다.

```text
DailyClosingPage — off-page 상세 요약 (#929 재수렴 4차 ②)
  > 전역DC 미조회 상태를 사유 열에 표시한다
TestingLibraryElementError: Unable to find role="button" and name "상세 보기"
```

원인은 구현이 아니라 새 테스트의 화면 전제 오류였다.
같은 describe의 기존 테스트는 `listDailyClosingsMock`으로 목록 행을 공급한 뒤
행 고유 test id인 `daily-closing-detail-button-<date>-<scope>-SALES-TAX_INVOICE`를
찾는다. 반면 실패 테스트는 목록 mock을 설정하지 않아 `listQuery.data`가 없어 상세
버튼이 조건부 렌더되지 않는 상태에서 전역 `상세 보기` role/name을 검색했다.
따라서 단정/skip을 제거하지 않고, 기존 테스트 패턴대로 대상 행 목록 mock과 off-page
전환 응답을 추가하고 대상 행의 고유 test id로 클릭하도록 테스트만 수정했다.

수정 후 대상 테스트 및 파일 전체 원문:
