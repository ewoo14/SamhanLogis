### ④ Electron 기동 명령 원문 · preload 실행 증거

실행한 package script 원문:

```text
cd clients/arologis-desktop
npm run dev
```

`clients/arologis-desktop/package.json`의 script는 다음과 같다.

```text
"dev": "electron-vite dev"
```

실행 로그 원문:

```text
> @samhan/arologis-desktop@1.0.0 dev
> electron-vite dev
build the electron main process successfully
build the electron preload files successfully
dev server running for the electron renderer process at:
  Local: http://localhost:5173/
start electron app...
```

브라우저 Chromium 탭이 아니라 Electron 실제 창(`electron.exe`)의 renderer에 연결했다. 실제 renderer 주소는 로그인 시 `http://localhost:5173/#/login`, 수신 화면 진입 후 `http://localhost:5173/#/dispatches/pre-classify`였다.

renderer에서 확인한 preload bridge:

```text
hasBridge: true
keys: ["getToken", "setToken", "clearToken"]
getToken(): null  // 로그인 전
```

DevTools Console에도 다음을 출력하고 캡처했다.

```text
S13 preload bridge: window.arologisAuth exists; methods=getToken,setToken,clearToken
```

증거: [04-preload-bridge-explicit-real-qa.png](../qa/1039-s13-real-qa/04-preload-bridge-explicit-real-qa.png)

### 수신 화면 실 응답

```text
GET http://localhost:8097/admin/arologis/dispatch-groups?dispatchDate=2026-08-05
HTTP 200
data.length = 1
data[0].groupNo = S11-20260805-01
data[0].carrierCode = AROLOGIS
data[0].vehicleLabel = S11 QA 1톤
```

새로고침 시에도 같은 응답이었다. DB read-only 대조 결과는 다음과 같다.

```text
group_no              carrier_code       is_arologis  transfer_status
S11-20260805-01       AROLOGIS            true         SENT
S11-20260805-EXT-01   S11-EXT-20260805   false        NOT_SENT
```

수신 행은 `TD`로 렌더링되며 `A`, `BUTTON`, `INPUT`, `SELECT`, `TEXTAREA`가 행 내부에 0개였다. 따라서 해당 수신 그룹을 편집·재분류하는 행 진입점은 확인되지 않았다. 상단 공통 메뉴의 `수동 배차`와 `가배차 분류`는 별도 메뉴로 보였으나, 수신 행과 연결된 편집 동작은 실행되지 않았다.

## 콘솔 관찰 사항

수신 기능은 동작했으나 Electron DevTools에 다음 범위 외 경고가 있었다.

- 개발 모드 Electron Security Warning
- Pretendard 폰트 decode/`invalid sfntVersion` 경고
- `GET http://localhost:8080/app/version?...` 503
- React Router v7 future flag warning

이번 ⑥ 판정은 로그인·수신 목록·읽기 전용·중복·필터에 한정했으며, 위 항목은 제품 코드를 수정하지 않고 관찰만 기록한다.
