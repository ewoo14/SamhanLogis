## 2. API 응답 원문 위치

성공 응답은 라인·거래처·감사 필드를 포함해 길기 때문에 축약하지 않고 다음 파일에 그대로 보존했다.

```text
docs/qa-shots/1065-r12-live-qa/observations.json
```

각 성공 응답의 공통 원문 선두는 `{"success":true,"code":"OK","message":"성공","data":...}`이며, 파일에는 각 요청 URL·request body·HTTP status·완전한 response body·`serverAddr`가 함께 있다.
