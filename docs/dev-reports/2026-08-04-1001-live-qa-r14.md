## 이 라운드가 보지 않은 것

- 거래명세서 일괄(`/accounting/statement-batch`) 화면 자체는 이번 라운드에서 열지 않았다. 이번 요청의 세 경로 트랙은 거래처 원장 집계·상세·인쇄로 수행했다.
- 기초 잔액이 0이 아닌 거래처와 기간 수금이 포함된 거래처를 확인하지 못해, 비영(非零) 기초 및 수금 차감 케이스는 미판정이다.
- 화면의 `SALE_SUMMARY` literal 문서 타입 노출 여부는 미판정이다(화면에는 `매출` 및 `판매전표 없음 / 전표 미이관`으로 보임).
- 집계 화면 상단에 실제 백엔드 업데이트 실패 배너가 노출되었다. 원장 조회 HTTP 200 및 금액 결과에는 영향이 없었으나, 배너 원인은 별도 확인하지 않았다.
- R13의 51건과 이번 48건 차이의 데이터 원인 분석은 하지 않았다.
