## GREEN-01/02 — 금액·자동 빈행

- VAT 별도 저장 계산을 `supply=화면 공급가`, `vat=floor(supply*0.1)`, `total=supply+vat`로 분리했다. VAT 포함 기존 계산은 유지했다.
- `clients/desktop/src/renderer/utils/autoBlankRow.ts`는 이 워크트리에 존재하지 않아 직접 import할 수 없었다. 웹 앱에 동일 동작의 순수 계약(`normalizeCustomRows`)을 두고, 입력 이벤트에서 마지막 행에 값이 생기면 빈행을 자동 추가하며 스냅샷 수집에서는 빈행을 제외하도록 했다.
- 커스텀 행의 `+` 행 추가 버튼은 제거하고 초기 빈행 1개를 자동 생성한다.

## GREEN-03 — 작성자 대상자 집합

`quote_snapshots.participant_emails` JSONB를 추가하고 신규 저장 시 작성자 이메일을 집합에 자동 삽입했다. 응답에도 `participantEmails`를 포함해 권한·알림·필터 소비자가 같은 집합을 볼 수 있게 했다.

## GREEN-04 — 화면 저장의 본인 수정 연결

저장 내역에서 복원한 항목의 `id`를 `window.editingSnapshotId`에 보존하고, 같은 `견적저장` 동작이 해당 ID가 있을 때 `PUT /internal/estimates/snapshots/{id}`를 호출하도록 RPC adapter를 연결했다. 타인 항목은 기존 백엔드 소유권 검사로 403을 유지한다. 인앱 브라우저는 연결 가능한 세션이 없어 실제 화면 클릭은 실행하지 못했다.
