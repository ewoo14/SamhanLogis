# #1019 품목명 재사용 차단 — 157쌍 실측 보고서

- 조사 위치: `C:/dev/Samhan-Public/.claude/worktrees/t1019` (지정 워크트리 존재 확인).
- `157`의 출처는 `docs/dev-reports/2026-08-01-1019-product-name-unique-recon.md`와 PR #1024 첫 코멘트이며, **같은 품목명을 공유하면서 서로 다른 모델코드가 2개 이상인 활성 품목들의 품목명 그룹 수**이다.
- PR 출처는 `https://github.com/ewoo14/Samhan-Public/pull/1024#issuecomment-5147878192`이며, 코멘트의 “서로 다른 모델코드를 가진 동명 활성 그룹 157개”를 뒤에서 “157쌍”이라고 줄여 쓴 데서 표현 혼선이 생겼다.
- 따라서 `157쌍`은 엄밀한 1:1 쌍 수가 아니라 **157개 동명 그룹**이며, 한 그룹에 모델코드가 3개 이상일 수도 있다.
- PR #1024 기존 코멘트의 당시 재집계는 모델코드 없는 전표 라인을 `4,196건 = 주문 전표 2,048 + 일반 전표 2,148`로 기록해, 기존 `4,189건`과 7건 차이라고 보고했으며 이번 읽기 전용 SELECT에서도 그대로 재현됐다.
- 현재 스키마에서 눈대중 판별용 양쪽 정보로 `model_code`, `name`, `spec_text`/`specification`, `release_price`·`delivery_price`·`selling_price`와 두 전표 라인 테이블의 품목별 비삭제 사용 건수를 조회할 수 있음을 확인했다.
- 읽기 전용 재집계 결과, 같은 조건의 수는 **157개 그룹으로 기존 값과 일치**한다 (`626`개 활성 품목 행, `626`개 서로 다른 모델코드, 그룹당 최소 2개·최대 14개 모델코드).
- `157`을 모델코드 간 실제 2개 조합 수로 해석하면 값은 **1,498쌍**이므로, PR 코멘트의 `157쌍` 표현은 `157개 그룹`으로 바로잡아 읽어야 한다.
- 모델코드가 NULL인 비삭제 품목은 100개이며, 이를 참조하는 비삭제 전표 라인은 **4,196건 = 주문 전표 2,048 + 일반 전표 2,148**으로 재현됐다. 따라서 이슈 제목의 `4,189건`은 현재 DB 실측보다 7건 적다.
- 157개 그룹의 626개 품목은 규격 필드(`spec_text`, `specification`)가 전부 비어 있어 표에는 `규격 없음`으로 표시해야 하며, 출고가·배송가·판매가·매입가는 626개 모두 존재한다.
- 626개 모두 판매가는 출고가와 같고, 매입가는 625개가 배송가와 같다. 유일한 예외는 `PC6EUCK1NW`(판넬 (360CST / 원형 / 공기청정))로 배송가 556,600원·매입가 678,000원이다.
- 157개 그룹 자체를 참조하는 비삭제 전표 사용은 **2건 = 주문 전표 0 + 일반 전표 2**이며, 사용된 품목 2개가 서로 다른 2개 그룹에 하나씩 있다.

## 읽기 전용 재집계 기준

```sql
SELECT COUNT(*)
FROM (
  SELECT name
  FROM products
  WHERE is_deleted = FALSE AND status = 'ACTIVE'
  GROUP BY name
  HAVING COUNT(*) > 1
     AND COUNT(DISTINCT model_code)
         FILTER (WHERE model_code IS NOT NULL) > 1
) grouped_names;
-- 157
```

모델코드 없는 전표 수는 `products.is_deleted = FALSE AND model_code IS NULL`인 품목의 비공개 내부 관계키 집합을 만든 뒤, 두 전표 DB에서 각각 아래의 읽기 전용 SELECT를 실행해 합산했다. 관계키 값 자체는 보고서에 노출하지 않았다.

```sql
SELECT COUNT(*)
FROM partner_order_lines
WHERE is_deleted = FALSE
  AND product_id = ANY(:비공개_내부_관계키_집합);
-- 2,048

SELECT COUNT(*)
FROM :일반_전표_라인_테이블
WHERE is_deleted = FALSE
  AND product_id = ANY(:비공개_내부_관계키_집합);
-- 2,148
```
