## 새로 가능해진 상태·화면 조합과 결과

1. 자동 규격 표시 50자 + 저장: 견적 품목 확정→저장에서 marker 없는 원문 길이 50, `specificationSource=CATALOG` payload가 생성되는 테스트 PASS. 서버 `specification` 50자 계약은 그대로다.
2. 자동 규격 표시 49자 + 저장: 동일 저장 경로가 marker를 추가하지 않으며 provenance를 별도 전송하는 공통 경계 테스트 PASS. 49자 경계는 S17 실 API 왕복 표본도 확인했다.
3. 저장 후 재조회: 신규 응답의 `specificationSource=CATALOG`를 우선 hydrate하고, 구 U+2060 응답도 CATALOG로 decode한다. 직접 수정 후 되돌린 값은 `USER`로 재조회한다. 관련 EstimateFormPage 회귀 44/44 PASS.
4. 원격 CATALOG 규격 수신→수신 소비자 품목 해제: 화면 규격·provider 규격·provider provenance가 함께 공란으로 수렴한다. 실제 `EstimateFormPage` 소비자 경로 테스트 PASS.
5. 원격 USER 규격/사용자 단가가 있는 행 해제: 기존 S14/S16 단정과 함께 사용자 규격·단가를 보존한다. 기존 회귀 PASS.
6. 판매전표 공용 `ProductAutocomplete`, 후보 모달 취소/단건·다건, BUNDLE 옵션, UUID 비노출: 기존 좁은 회귀 및 격리 Playwright에서 모두 PASS.
