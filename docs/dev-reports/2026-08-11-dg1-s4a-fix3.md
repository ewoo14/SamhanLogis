## 3. RED-A 원문

수정 전 원본에 실제 변이를 넣고 각각 fresh 실행했다.

### A. bucket Set 축약

ACCOUNTANT의 `accounting.sales-commission-settlement`를 `1000000` bucket에도 추가했다. `1110000` bucket의 원행은 유지했다.

```text

```

### B. TypeScript duplicate object key

같은 역할 block에 다음을 삽입했다.

```ts
'accounting.sales-commission-settlement': '0000000',
'accounting.sales-commission-settlement': '1110000',
```

```text
Test Files  1 passed (1)
Tests       10 passed (10)
Vite warning: Duplicate key "accounting.sales-commission-settlement"
exit code 0
```

### C. backend `parseProjection()` Map overwrite

projection source에 같은 role/page를 `0000000` 후 `1110000`으로 두 번 넣었다.

```text
BUILD SUCCESSFUL in 27s
12 actionable tasks: 12 executed
```

수정 후 동일 경계의 자동 회귀는 다음처럼 RED를 잡는다.

```text

AccountingPermissionProjectionFreshnessIT: 2 tests, skipped 0, failures 0, errors 0
```

generator에도 raw 첫 row를 한 번 복제해 입력했고, 임시 PostgreSQL migration 후 artifact 생성 전에 다음으로 중단됐다.

```text
duplicate projection cell ACCOUNTANT|accounting.accounts first/second bits cannot be represented
```

임시 컨테이너·네트워크는 `finally`에서 제거됐다.
