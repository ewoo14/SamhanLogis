# PR #1187 (#1143) 라이브QA 스크린샷 라운드

## 결론

**스크린샷 4장을 새로 남겼으나 머지 게이트 ③을 완전 충족하지는 못했다.**

- 격리 V39 DB·격리 product-service·격리 desktop renderer에서 실제 Playwright Chromium으로 기초품목 세트 구성품 편집 화면을 밟았다.
- 무변경 저장은 HTTP 200이고, 저장 후 `AUTO 4 + AUTO 6`이 그대로 보존됐다.
- 비중 합 9 요청은 HTTP 400이며 화면에 `자동 구성품 비중 합은 10이어야 합니다.`가 표시됐다. 개발자 원문·500이 아니다.
- 신규 `ACD-2558G` 구성품은 `FIXED`, 기본 납품가 `45,375`로 자동 반영됐다. 검증 후 원래 구성 4행으로 복구했다.
- 그러나 현재 HEAD의 구성품 편집 화면에는 `AUTO/FIXED`, 비중, 고정금액, 반올림 단위가 **렌더되지 않는다**. 따라서 `AUTO 4+6`과 FIXED `45,375` 값 자체를 화면으로 찍을 수 없다. 화면에는 모델코드·수량·종류·기본 구성품만 보인다.
- 같은 이유로 견적/전표에서 이 세트를 전개해 금액을 확인하는 화면까지는 도달하지 못했다. 이번 격리 스택은 product-service만 띄웠고, 금액 화면에 필요한 견적/전표 서비스·DB는 구성하지 않았다.

따라서 이 라운드는 “브라우저 없음”으로 건너뛴 것이 아니라 실제 Chromium 캡처까지 수행했으며, 남은 차단점은 **브라우저 환경이 아니라 현재 화면에 가격 배분 UI가 없고 견적/전표 격리 서비스가 없는 것**이다.

## 격리 환경과 데이터 복제

- DB: `w1111-1143-liveqa-pg`, `127.0.0.1:43339`
- product-service: `127.0.0.1:43384`
- desktop renderer: `127.0.0.1:43373`
- 공유 `samhan-*` 서비스는 화면/API 검증에 사용하지 않았다.
- 공유 PostgreSQL은 원본 스냅샷을 읽는 `pg_dump`에만 사용했다. 복제는 파이프 없이 파일을 경유했다.

실행 명령:

```powershell
docker exec samhan-postgres pg_dump -U samhan -d product_db -Fc --no-owner --no-privileges -f /tmp/w1111-1143-liveqa.dump
docker cp samhan-postgres:/tmp/w1111-1143-liveqa.dump .codex-tmp\1143-liveqa\product-v39.dump
docker run -d --name w1111-1143-liveqa-pg -e POSTGRES_USER=samhan -e POSTGRES_PASSWORD=samhan -e POSTGRES_DB=product_db -p 127.0.0.1:43339:5432 postgres:16-alpine
docker cp .codex-tmp\1143-liveqa\product-v39.dump w1111-1143-liveqa-pg:/tmp/product-v39.dump
docker exec w1111-1143-liveqa-pg pg_restore -U samhan -d product_db --clean --if-exists --no-owner --no-privileges /tmp/product-v39.dump
```

## Playwright 실행 결과 원문

인앱 브라우저 연결은 다음과 같았다.

```text
agent.browsers.getForUrl("http://127.0.0.1:43373/")
No browser is available

agent.browsers.list()
[]
```

오늘 다른 워크트리와 달랐던 것은 인앱 브라우저 discovery가 빈 배열이었다는 점이다. 그러나 `clients/desktop/node_modules/playwright`의 Chromium은 정상 실행됐으므로 `.codex-tmp/1143-liveqa/capture.mjs`로 계속 진행했다. 드라이버는 `docs/qa`에 두지 않았다.

```powershell
node .codex-tmp\1143-liveqa\capture.mjs 2>&1 | Tee-Object -FilePath .codex-tmp\1143-liveqa\playwright-raw.txt
```
