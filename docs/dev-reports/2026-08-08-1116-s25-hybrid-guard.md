# #1116 S25 — 정적 + 결과 기반 `docs/qa` 오염 가드

## 결론

정적 가드는 교체하지 않았다. 정적 가드를 1차 방어선으로 유지하고, 실제 테스트가 끝난 뒤 결과 검사를 최종 방어선으로 병행한다.

결과 검사 계약은 다음과 같다.

> **tracked 변경 + non-ignored untracked 잔재 0**

검사는 `git status --porcelain=v1 --untracked-files=all -- docs/qa`를 사용한다. 위반 시 tracked 변경과 non-ignored untracked 항목을 상태 코드와 함께 모두 출력하고 실패한다. Git ignored 파일은 계약상 검사 대상이 아니다.

## 적용 범위

이번 단계에서 결과 검사를 추가한 잡은 다음 세 개다.

- `.github/workflows/ci.yml` — `frontend-desktop`
- `.github/workflows/qa-e2e.yml` — `desktop-playwright`
- `.github/workflows/harness-guard.yml` — `harness-false-green-guard`

각 잡의 테스트 종료 뒤 `if: always()`로 실행한다. 따라서 테스트가 실패해도 잔재 검사와 목록 출력이 수행된다.

아직 적용하지 않은 잡은 그 밖의 모든 CI 잡이다. 이번 S25에서는 조사 보고서 5항 권고에 따라 위 세 잡만 단계적으로 적용했다.

## 정상 예외 확인

현재 워크플로의 실제 `run:`/action 경로를 확인한 결과, 커밋된 증거인 `docs/qa` 추적 파일을 정상적으로 수정하는 CI 경로는 없었다. Playwright 실패 산출물은 `test-results` 또는 `playwright-report`로 가고, QA 스크립트의 정상 출력은 `_local` 격리 경로로 간다.

따라서 이번 적용에 명시적 예외는 없다. 향후 정상적으로 `docs/qa`를 갱신하는 잡을 추가하면 일반 테스트 잡과 분리하거나 사전 baseline을 정의해야 한다.

## 정적 가드 역할과 알려진 한계

정적 가드는 CI에서 실행되지 않는 파일까지 덮는 1차 방어선이다. 결과 검사는 실제로 실행된 테스트가 남긴 최종 상태만 확인하는 최종 방어선이다. 그러므로 앞으로 정적 가드에서 오차단이 나오면 규칙을 더 붙이지 말고 느슨하게 하는 쪽으로 기울인다.

정적 가드가 여전히 정적으로 잡지 못하는 형태는 다음 네 가지다.

- quoted Batch 목적지
- marker와 write가 같은 도움말 문자열에 있는 경우
- Python `Path('docs') / 'qa'` 조립
- Batch `%OUT%` 변수 목적지

이 네 형태가 있는 **미실행 파일**은 여전히 정적 가드의 미탐 범위다. 해당 파일이 이번 적용 잡에서 실제 실행되면 결과 검사가 최종 `docs/qa` 잔재를 받는다.

## RED / GREEN 검증

### RED-A

임시 non-ignored 파일 `docs/qa/s25-post-check-probe.txt`를 생성한 뒤 실행했다.

```text
[docs/qa 결과 검사] 실패: tracked 변경 + non-ignored untracked 잔재 0 계약 위반
[docs/qa 결과 검사] 더럽혀진 항목:
  ?? docs/qa/s25-post-check-probe.txt
```

검사 exit code는 1이었다. 임시 파일은 즉시 제거했다.

### GREEN / RED-B

임시 파일 제거 후 결과 검사 원문:

```text
[docs/qa 결과 검사] 통과: tracked 변경 + non-ignored untracked 잔재 0
```

정상 상태에서 결과 검사는 green이었다.

### RED-C

실행 명령:

```text
npx vitest run src/renderer/test-utils/harness-false-green-guard.test.ts
```

원문 요약:

```text
Test Files  1 passed (1)
Tests       61 passed (61)
Duration    36.38s (transform 71ms, setup 0ms, collect 164ms, tests 35.78s, environment 0ms, prepare 94ms)
```

기존 S13~S24 정적 가드는 `61 passed`를 유지했다. 이번 환경 측정 시간은 기존 기록의 33.44초보다 길었다.

추가 단위 테스트:

```text
node --test scripts/check-docs-qa-clean.test.cjs
2 passed, 0 failed
duration_ms 70.0097
```

변경 검증:

```text
node scripts/check-docs-qa-clean.cjs
[docs/qa 결과 검사] 통과: tracked 변경 + non-ignored untracked 잔재 0
```

커밋과 push는 하지 않았다.
