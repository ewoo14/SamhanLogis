## 3. 동명 집계 기준 확인

게이트웨이 `GET /api/products?size=1000&page=N` 전체 페이지를 수집해 `name` 완전 일치로 그룹화했다.

- 전체 상태 포함: 1,220행, 동명 그룹 **187개**, 동명 행 **700행**. 단종 4행 포함.
- `status=ACTIVE`만 필터: 1,216행, 동명 그룹 **186개**, 동명 행 **696행**.

따라서 1차 보고의 **187그룹/700행**은 전체 상태 집계이고, 적대검증의 **186그룹/696행**은 ACTIVE만 집계한 값이다. 이 이슈의 활성 품목명 재사용 기준에는 **186그룹/696행**이 맞다.
