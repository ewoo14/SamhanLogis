## C. 아로로지스 커스텀 응답 헤더 CORS 미노출

PR #892 의 **결함 계열 전수 sweep** 이 찾아낸 잔여분이다. 그 PR 에서는 범위 동결 원칙에 따라 **보고만** 남겼다.

대상: `X-Copy-Sent-At` · `X-Copy-Recipient-Phone-Masked` — 아로로지스 자체 CORS 설정에 **노출돼 있지 않다**.

📌 **#892 에서 똑같은 구조가 실제 사용자 결함이었다.** 서버는 `X-Has-Next-Page` 를 정확히 냈는데 브라우저가 못 읽어 `다음` 버튼이 영구 비활성이었고, **CI 40/40 · vitest 29/29 · mock Playwright 6/6 · 적대리뷰가 전부 통과한 상태**였다. vitest 는 axios 목이라 CORS 가 없고 mock Playwright 는 동일 출처라 CORS 가 적용되지 않는다.

**불변식 C** — 브라우저 JS 가 읽어야 하는 커스텀 응답 헤더는 **실 브라우저가 교차 출처에서 실제로 읽을 수 있어야** 한다.

🚨 **먼저 도달성을 판정하라.** 아로로지스 클라이언트가 이 두 헤더를 **실제로 읽는 코드가 있는지** 확인하고:
- 읽는 코드가 있다 → **도달가능 결함**. 고치고 CORS 를 우회하지 않는 회귀 테스트를 남긴다
- 읽는 코드가 없다 → 고칠 필요 없음. **근거와 함께 그렇게 보고**하고 넘어간다(예방적 노출은 새 표면 추가다)
