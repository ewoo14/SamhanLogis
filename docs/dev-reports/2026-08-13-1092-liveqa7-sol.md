## 실행 경계

인앱 Browser 런타임은 연결 복구 절차와 가용 브라우저 조회에서도 `[]`를 반환했다. 이를 실행 불가로 판정하지 않고 저장소 Playwright Chromium으로 실제 화면을 실행했다.

로그인은 `last_login_at`을 쓰므로 호출하지 않았다. 공유 `auth_db`를 `BEGIN TRANSACTION READ ONLY`로 조회해 활성 시스템 MASTER의 계정·그룹만 확인하고, 현재 로컬 auth-service와 같은 dev JWT 설정으로 1시간짜리 QA 세션을 만들었다. 브라우저에서는 gateway의 `GET`/`HEAD`/`OPTIONS`만 허용했고 모든 비-GET은 전송 전에 차단했다.

```text

공유 DB 업무 INSERT/UPDATE/DELETE/DDL: 0건
```
