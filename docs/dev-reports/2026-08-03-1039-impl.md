## 3. RED 원문

**미작성/미실행.** 최신 main 기준 rebase가 선행되어야 테스트 파일 충돌과 오답 고정을 피할 수 있다. 또한 현재 upstream 응답에는 창고명 필드가 없으므로, 창고명 필드의 정식 계약(필드명·source/destination 의미)을 PM/통합 기준에서 확정하기 전에는 추측으로 RED 기대값을 만들지 않는다.

확인된 결함 원문은 다음과 같다.

```text
services/arologis-service/.../PreClassifyService.java:137~142
warehouse가 blank이면 true를 반환한다.

services/arologis-service/.../SlipServiceClient.java:139~142
warehouse를 JSON의 warehouse 필드에서 읽지만, 현재 slip-service 실제 응답 DTO에 warehouse가 없다.
```

## 4. 구현

**미착수.** rebase 전에는 production code, migration, test를 변경하지 않았다.

필수 구현 범위는 다음 근거를 유지해야 한다.

1. 창고 판정은 레거시처럼 표시 문자열의 상일/초월 의미를 보존해야 한다.
2. 지방·야적은 주소 접두가 아니라 `REGION`·`STACK` 태그로 판정해야 한다.
3. 레거시 공통 제외, 야적 우선 보존, 모드별 창고 필터를 각각 독립 테스트해야 한다.
4. 창고 필드 계약이 없는 상태에서 blank를 통과시키는 fallback은 완전계승을 입증하지 못한다.

## 6. 불변식 실측

### 6.1 불변식 1 — 8개 모드 결과

레거시 원문 대조상 현재 구현은 1~8 모두 창고 필터의 실계약이 끊겨 있어 결과 동등을 입증하지 못한다. 모드별 원문은 §2에 전부 열거했다.

### 6.2 불변식 2 — 실 데이터 산출 건수

아래 수치는 로컬 공유 PostgreSQL의 **`[DEV-SEED]`/운영 혼합 개발 데이터 읽기 전용 집계**이며, `docs/migration/ecount-data/raw/`의 이카운트 원본 실측이 아니다. 해당 DB에서 활성 OUTBOUND 2,304건을 대상으로 현행 코드의 blank warehouse fallback을 적용해 산출한 진단값이다.

| 모드 | 현행 fallback 진단 건수 | 해석 |
|---:|---:|---|
| 1 | 73 | 창고 필터가 무력화된 값; 레거시 동등값 아님 |
| 2 | 73 | 초월 구분 불가; 레거시 동등값 아님 |
| 3 | 73 | 상일 구분 불가; 레거시 동등값 아님 |
| 4 | 11 | `delivery_tag=STACK` 11건; 창고 필터 미검증 |
| 5 | 12 | `delivery_tag=REGION` 12건; 창고 필터 미검증 |
| 6 | 2,304 | 창고 필터가 무력화된 값; 레거시 동등값 아님 |
| 7 | 2,304 | 초월 구분 불가; 레거시 동등값 아님 |
| 8 | 2,304 | 상일 구분 불가; 레거시 동등값 아님 |

태그 원자료 집계(`[DEV-SEED]`, `slip_db.slips`, `deleted_at IS NULL`, OUTBOUND): 무태그 2,261건(OUTBOUND 2,239건 중 20건은 PARTNER_ORDER 포함 여부에 따라 집계 기준 차이 확인 필요), `DAY=52`, `REGION=12`, `RETURN_RENTAL=10`, `STACK=11`. 최신 직접 query로 확인한 OUTBOUND 조합은 MANUAL 2,284건, PARTNER_ORDER 20건이며, 창고 표시명 `destination_warehouse_name`은 2,304건 모두 NULL이다.

### 6.3 불변식 3 — 정상 경로 차단 여부

`warehouseAllowed()`의 blank fallback은 정상 경로를 차단하지 않지만, 그 대가로 2·3·7·8의 선택 범위를 모두 통과시킨다. 즉 “차단되지 않음”은 확인되나, 기능 계승을 만족하지 않는다. 현재 실측에서 `REGION=12`, `STACK=11`은 태그 기반 집합으로 보존되고, 주문 발행 20건은 두 태그가 모두 0건이다. 자동 태깅의 완전성은 확인할 수 없으므로 단정하지 않는다.

### 6.4 불변식 4 — REGION/STACK 태그 대조

- `[DEV-SEED]` DB: `REGION=12`, `STACK=11`.
- 주소 접두를 사용해 태그 집합을 대체 판정하지 않았다.
- raw 이카운트 원본과의 독립 대조는 이번 세션에 수행하지 않았으므로 “실 원본과 일치”라고 단정하지 않는다.
