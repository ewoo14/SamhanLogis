## 확인 5 — C 최초 라이브 결과 및 보완

최초 타인 수정 시 backend 403을 estimate-app RPC가 500으로 감싸는 전달 결함을 확인했다.

```text
C_TAINT_STATUS=500
C_OWNER_STATUS=200
```

본인 수정은 200이었고 타인 수정은 backend에서 403이었으므로, RPC가 upstream HTTP 상태를 보존하도록 보완한다.

보완 후 재실행 원문:

```text
C_TAINT_STATUS=403
C_OWNER_STATUS=200
```
