# PR #1078 · 이슈 #1075 — S12 fix 보고서

## 판정

F1/F2를 수정했다. 모달 취소 시 blur exact lookup을 호출하지 않으며, 견적 확정 품목을 삭제하면 판매전표와 같은 공란 상태를 유지한다. blur lookup, 단일 후보 자동확정, coedit 계약은 유지했다.

## 변경

- `AsyncAutocomplete`: 결과 모달 전환용 blur에서는 `onInputBlur`를 호출하지 않음.
- `EstimateFormPage`: `null` 선택을 실제 해제로 처리해 `productId`, `modelName`, `productName`, `productType`, `catalogUnitPrice`, 자동가격 상태와 coedit 필드를 정리함.
- 회귀 스펙: 모달 취소, 확정 품목 Delete 후 blur, 자동 빈행 계약을 추가함.

## RED-first 증거

수정 전 신규 Chromium 회귀 2건이 실패했다.

```text
모달 취소: 기대 품목명 "" / 실제 "(샘플) AJ"
확정 품목 삭제: 기대 모델명 "" / 실제 "AJ040RXH4BC1"
2 failed
```

공용 컴포넌트 테스트는 jsdom에서 실제 모달 focus 이동이 자동 발생하지 않아 blur를 명시적으로 발생시키도록 보강했다.
