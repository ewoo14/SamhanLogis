# PR #1126 R14 fix 지시서 — 분기관·발통 옵션 우선순위

## ① 좌표

- `clients/web/estimate-app/views/index.ejs:8281-8339` — `recomputeHomeBranches()`가 `#home_no_branch`를 읽어 분기관 수량을 결정한다.
- `clients/web/estimate-app/views/index.ejs:7960-7970` — `recomputeFootAll()`이 `#home_foot`를 읽어 발통 수량을 결정한다.
- `clients/web/estimate-app/views/index.ejs:8393-8423` — 서버 규칙 target을 기존 수량 위에 적용한다.
- `clients/web/estimate-app/views/index.ejs:8426-8452` — 서버 규칙 적용 뒤 호스·리모컨·판넬만 옵션 계약으로 재수렴하고 분기관·발통은 빠져 있다.
- `clients/desktop/src/renderer/routes/EstimateItemsCatalogPage.tsx:1004-1032,1153-1158` — 관리자 UI가 검색한 품목을 `HOME_MULTI` 규칙 target으로 저장하는 실 사용자 진입점이다.

현재 재현값:

```text
분기관 제외=true · source AM020BN1PBH1=2 · target AXJ-YA1509N
  규칙 0건  0
  규칙 1건  2   ← 옵션 위반

발통포함=false · source AJ060MXHNBC1=2 · target 발통세트
  규칙 0건  0
  규칙 1건  2   ← 옵션 위반
```

## ② 불변식

1. 유효한 `HOME_MULTI` 규칙과 화면 옵션이 같은 품목군 수량을 동시에 결정하면 명시적인 화면 옵션이 최종 계약이다.
2. `분기관 제외=true`이면 수동 잠금되지 않은 홈 분기관 수량은 규칙 유무와 무관하게 0이다.
3. `발통포함=false`이면 수동 잠금되지 않은 홈 발통 수량은 규칙 유무와 무관하게 0이다.
4. 제외하지 않은 분기관과 포함한 발통에서는 유효한 서버 규칙 소비가 살아 있어야 한다.
5. 규칙 0건의 결과는 순수 레거시와 exact diff 0이어야 하며, 기존 수동 수량 잠금 계약은 바뀌지 않아야 한다.

## ③ 양방향 RED

### RED-A — 옵션이 규칙보다 우선

- `AM020BN1PBH1=2`, target `AXJ-YA1509N`, `분기관 제외=true`이면 최종 `AXJ-YA1509N=0`이어야 한다. 현재 HEAD는 2다.
- `AJ060MXHNBC1=2`, target `발통세트`, `발통포함=false`이면 최종 `발통세트=0`이어야 한다. 현재 HEAD는 2다.

### RED-B — RED-A의 반대급부: 규칙 소비 유지

- 같은 분기관 규칙에서 `분기관 제외=false`이면 target 수량이 규칙 계산값으로 남아야 한다.
- 같은 발통 규칙에서 `발통포함=true`이면 target 수량이 규칙 계산값으로 남아야 한다.
- 규칙 0건에서는 `H-07-NO-BRANCH`, `H-08-NO-FOOT`를 포함한 기존 estimate golden 기대값이 한 건도 바뀌면 안 된다.
- 호스 제외·리모컨 제외·판넬 제외와 규칙 target의 현재 옵션 우선 결과도 그대로 유지되어야 한다.
