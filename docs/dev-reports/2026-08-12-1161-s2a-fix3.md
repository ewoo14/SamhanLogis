## 측정 2 — D-1·D-2 최소 구현 후 GREEN

변경 요지:

- API Gateway에 `ForwardedClientIp` route filter 추가. 신뢰 ingress peer일 때만 `X-Real-IP`/X-Forwarded-For에서 첫 client IP를 `X-Audit-Client-IP`로 전달하고, 비신뢰 peer의 기존 내부 헤더를 peer 주소로 덮는다.
- `partner-auth-service`는 명시된 gateway peer에서 온 `X-Audit-Client-IP`만 사용한다. 직접 요청의 XFF와 내부 헤더 위조는 사용하지 않는다.
- `MethodArgumentNotValidException`을 `HttpServletRequest`와 함께 처리해 PIN validation HTTP 400을 중앙 감사로 발행한다. 메시지는 field/constraint만 포함하며 PIN 원문은 포함하지 않는다.
