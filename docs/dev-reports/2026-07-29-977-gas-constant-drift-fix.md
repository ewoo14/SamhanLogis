## 2. 이 슬라이스가 먼저 답해야 하는 것

둘 다 **조건부**입니다. 고치기 전에 **도달성부터** 판정합니다.

- fallback `0.47` — 설정이 실제로 누락될 수 있는가? 누락되면 어느 화면에서 어떤 금액이 나오는가?
- `AXJ-YA1509N` — 이 모델이 실 카탈로그에 있는가? 있다면 DB 납품가는 얼마이고 차액은 얼마인가?

**도달 불가로 판정되면 고치지 않고 근거를 남깁니다.** 도달 가능하면 그때 fix 합니다.

## 3. 불변식

1. 레거시 GAS 정본이 내는 금액과 제품이 내는 금액이 같다 — 같은 입력에 대해
2. 정본과 다르게 가는 곳이 있으면 **그것이 의도된 결정인지 문서에 근거가 있어야 한다**
3. 고칠 때 **다른 5건(기존 불일치)의 현재 동작이 바뀌지 않는다**

## 4. 검증

- **RED-first** — 도달 가능 판정이 난 건에 대해 골든/회귀 테스트를 먼저 RED 로
- 골든 fixture 는 **실 카탈로그가 만들 수 있는 상태**만 (`legacy-quantity-golden/fixtures.js` 의 합성 상업 카탈로그 공백은 별건 이월)
- `estimate-app` 은 로컬에 `node_modules` 가 없어 `npm ci` 선행 — 안 하면 견적 골든 RED 를 CI 에서야 본다
