## 수정 내용

1. `V21__harden_room_chat_sequences.sql`을 추가했다. V20은 수정하지 않았다. 방 코드는 DB sequence(`chat_room_code_seq`)에서 발급하고, V20이 이미 만든 당일 최대 번호 다음 값으로 초기화했다. 메시지는 방별 JVM 직렬화와 PostgreSQL transaction advisory lock을 거친 뒤 저장하며 `(room_id, sequence_no)` UNIQUE 제약을 추가했다.
   soft-delete 행의 sequence 재사용도 막도록 `MAX(sequence_no)`는 native query로 전체 이력을 읽는다.
2. room/message 응답에 UUID 없이 발신자 이름·부서·사번과 `mine`, DIRECT 상대 정보를 추가했다. 내부 user-service 조회는 서버 내부에서만 수행한다.
3. desktop에 `/chat` 방 목록, 새 대화 검색·생성 UI, 사이드바 진입점을 추가하고 `/chat/:roomCode` 화면에 상대·발신자 정보를 표시했다. React key는 `sequence` 단독이 아닌 `sequence-sentAt` 조합으로 바꿨다.
