## 도달 가능한 결함 1 — `size=50` 절단 뒤 한 글자 검색 모달에서 실제 품목이 사라진다

실 사용자 경로:

1. `/#/products/estimate-items`의 `기초품목 선택`에 `A` 한 글자를 입력한다.
2. debounce 뒤 검색 선택 모달이 열린다.
3. 실 API에는 `A` 일치 품목이 2,686건 있으나 클라이언트는 첫 50건만 요청한다.
4. 50건 밖의 실제 추가 가능 품목 `AP110BAPPBH2S`는 모달에 없고, 열린 모달은 받은 50건 안에서만 필터링하므로 사용자가 그 품목까지 입력을 이어갈 수 없다.

원문 근거:

```text
BROAD_A_TOTAL=2686 FIRST_PAGE=50 OUTSIDE_50_MODEL=AP110BAPPBH2S
UNREACHABLE_OUTSIDE_50_MODEL=AP110BAPPBH2S
```

캡처: `docs/qa/1152-r6-sol-reconv-real-qa/_local/01-size-50-outside-unreachable.png`. 화면 고유 요소 `estimate-items-category-tabs`를 먼저 단정했으며, 모달의 50건 목록에 대상 코드가 없음을 DOM으로 단정했다.

## 도달 가능한 결함 2 — Product 직접 응답 DTO는 4종인데 1종이 `goodsType` 없이 남았다

`Product` 엔티티를 직접 받는 `from(Product ...)` 응답 DTO를 다시 전수 검색한 결과는 4종이다.

| DTO | 노출 경로 | `goodsType` | 직렬화 RED |
|---|---|---:|---:|
| `ProductSummaryResponse` | `GET /products`, lookup 계열 | 있음 | `@JsonProperty` 제거 시 1/1 RED |
| `ProductCatalogResponse` | `GET/PATCH /api/v1/products` | 있음 | record component `@JsonIgnore` 시 1/1 RED |
| `ProductResponse` | 상세/create/update/price/tags | 있음 | record component `@JsonIgnore` 시 1/1 RED |
| `ProductByCodeResponse` | `GET /api/products/by-code/{code}` | **없음** | 기대 테스트 추가 즉시 1/1 RED |

남은 실 경로는 품목 코드 alias를 product ID로 해소해 재고 등 후속 호출로 넘기는 클라이언트 경로다. 현재 응답은 `id/modelCode/name`만 반환한다. 이번 지시의 “남은 품목 응답 DTO가 있으면 결함” 기준을 충족하지 못한다.

RED 원문은 네 경우 모두 다음 형태였다.

```text
ProductResponseGoodsTypeSerializationTest > <해당 case>() FAILED
java.lang.NullPointerException at ProductResponseGoodsTypeSerializationTest.java:42 (by-code는 :47)
1 test completed, 1 failed
BUILD FAILED
```

세 production DTO mutation과 임시 by-code 기대 테스트는 모두 원복했다. 원복 후 기존 DTO 묶음은 9/9 GREEN이다.

## ⑤ `usage_scope=NONE` 신규 기초품목 도달성

공유 product DB를 `BEGIN READ ONLY`로 조회한 최신 비자재 NONE 품목:

```text
S3-1111-GUARD-API-20260807-S3
usage_scope=NONE
product_category=SINGLE_SET
created_at=2026-08-07 21:59:31.961188
```

견적품목 관리 화면에서 정확 검색해 선택 칩까지 도달했다. 추가 버튼은 누르지 않았다. 캡처: `docs/qa/1152-r6-sol-reconv-real-qa/_local/02-newest-none-searchable.png`.

즉 정확한 모델 코드까지 빠르게 입력할 수 있으면 신규 NONE 품목은 검색된다. 다만 결함 1처럼 흔한 한 글자에서 모달이 먼저 열리면 50건 밖 품목은 도달하지 못한다.
