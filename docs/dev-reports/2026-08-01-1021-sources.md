# #1021 거래처 원천 조사

- "거래처 원천이 이원화됐다"는 말은 `estimate-app`이 사용하는 `partner-service` 원천과 `order-app`이 사용하는 `dc-config-service` 원천이 서로 따로 존재한다는 뜻이다(근거: Issue #1021 본문 및 PR #1029 보고서).
- 2026-08-01 조회 시 PR #1029의 일반 코멘트와 리뷰 코멘트는 각각 0개였으며, PR 본문이 가리킨 `docs/dev-reports/2026-08-01-1021-partner-source-gas-compare.md`를 PR head에서 읽었다.

## 원천별 행 수와 거래처코드 표본

- 원천 1은 PostgreSQL `partner_db`의 `partners` 테이블이다(`partner-service` datasource 기본 DB: `services/partner-service/src/main/resources/application.yml:17`, entity table: `services/partner-service/src/main/java/com/samhanair/logis/partner/domain/Partner.java:38`).
- 읽기 전용 `SELECT` 결과 `partner_db.partners`는 물리 행 7,260개이며, 서비스가 사용하는 soft-delete 제외 활성 행은 7,259개이다.
- `partner_db.partners` 활성 거래처코드 정렬 표본 5개: `000011111111`, `00011241415`, `000191919`, `0004`, `00040000`.
- 원천 2는 PostgreSQL `dc_config_db`의 `partners` 테이블이다(`dc-config-service` datasource 기본 DB: `services/dc-config-service/src/main/resources/application.yml:12`, entity table: `services/dc-config-service/src/main/java/com/samhanair/logis/dcconfig/domain/Partner.java:30`).
- 읽기 전용 `SELECT` 결과 `dc_config_db.partners`는 물리 행과 soft-delete 제외 활성 행이 모두 210개이다.
- `dc_config_db.partners` 활성 거래처코드 정렬 표본 5개: `1012555999`, `1018187629`, `1021573652`, `1023108393`, `1060121111`.

## 앱별 사용 원천

- `estimate-app`은 `clients/web/estimate-app/lib/code.js:1953-1956`에서 `directory.fetchPartners('')`로 거래처 목록을 적재한다.
- 그 함수는 `clients/web/estimate-app/lib/directory.js:12-19`에서 `partner-service`(기본 `http://localhost:8095`)를 지정하고, `clients/web/estimate-app/lib/directory.js:56-65`에서 `GET /internal/partners/list`를 호출하므로 `estimate-app`의 거래처 원천은 `partner_db.partners`이다.
- `order-app`은 `clients/web/order-app/src/samhanApi.ts:281-295`에서 `POST /auth/partner-login` 응답의 `config`를 저장하여 거래처와 DC 설정에 사용한다.
- 로그인 백엔드는 `services/partner-auth-service/src/main/java/com/samhanair/logis/partnerauth/service/PartnerAuthService.java:269-271`에서 `dcConfigClient.findByBizNo` 결과를 응답 `config`로 넣는다.
- `services/partner-auth-service/src/main/java/com/samhanair/logis/partnerauth/client/DcConfigClient.java:52-58`이 `dc-config-service`의 `GET /internal/partners/by-bizno/{bizNo}`를 호출하고, 해당 endpoint는 `services/dc-config-service/src/main/java/com/samhanair/logis/dcconfig/web/InternalDcConfigController.java:75-78`에서 거래처와 DC 설정을 반환하므로 `order-app`의 거래처 원천은 `dc_config_db.partners`이다.
