## 구현 내용

- `groupware-service`에 `ChatRoom`, `ChatRoomParticipant`, room 기반 `Message.roomId/sequence`를 추가했다.
- `V20__add_room_based_internal_chat.sql`에서 기존 `messages`의 sender/recipient pair마다 DIRECT room과 양쪽 실제 참여자를 만들고 room/sequence를 backfill한다.
- 기존 메신저 5개 API는 유지했다. 신규 room REST는 room 생성·목록·메시지 조회·발송과 참여자 권한 검사를 제공한다.
- 기존 `RealtimeBroker`를 사용하고 commit 이후 `chat:message-created`를 발행한다. RabbitMQ/WebSocket은 추가하지 않았다.
- 데스크톱에 `/chat/{roomCode}` 화면과 `chatRealtimeClient`를 추가했다. `createRealtimeClient`의 재연결·heartbeat·backoff를 재사용한다.
- 화면 URL/응답은 `roomCode`를 사용하며 신규 채팅 API에서 내부 room UUID를 경로/화면 텍스트로 내보내지 않는다.
