# PR #1174 fix2 — 표시 경계 구조화·actorId 역추적 복원 보고서

작성일: 2026-08-12

## 판정 요약

이번 fix2는 `resolveName/resolveActorName` 호출부를 하나씩 추가하는 방식으로 끝내지 않고, 표시 문자열을 만드는 소스 경계를 검사하는 계약으로 바꿨다.

- renderer: desktop · 아로로지스 desktop · mobile-staff · design-system 전수 검사
- backend: slip-service의 감사/이력/협업/삭제/수정요청 응답 DTO 전수 검사
- raw `actorName`, `actorFullName`, `authorName`, `requesterName`, `deletedByName` 등 표시 필드를 resolver 없이 읽으면 테스트가 RED가 된다.
- 의도적으로 만든 raw TSX 출구와 raw Java 응답 출구가 실제로 RED가 되는 원문을 확보했다.
- resolver를 통과한 임시 renderer는 GREEN이다.

이 구조가 새 출구를 막는 이유는 “현재 알려진 출구 목록”을 비교하는 것이 아니라, 표시 영역의 파일을 매 실행마다 스캔하여 원시 표시 필드 read 자체를 실패시키기 때문이다. 새 화면 파일이나 DTO가 추가되어도 목록에 수동 등록하지 않아도 검사 대상에 들어온다. resolver-backed local helper는 구현 안에서 공통 resolver를 호출하는 경우에만 허용했다.

## 1. 정규화 기반 표시명 판정

`shared/common`의 `ActorDisplayName`과 web/mobile resolver의 판정을 다음 순서로 통일했다.

1. Unicode NFKC 정규화
2. 모든 Unicode format/invisible category(`Cf`, U+2063 포함) 제거
3. Unicode dash를 ASCII `-`로 접기
4. UUID에 사용되는 Greek/Cyrillic 유사문자를 ASCII 비교 문자로 폴딩
5. 정규화 결과가 canonical/brace/URN/raw32 UUID 형태인지 판정

정상 이름은 비교용 폴딩 결과로 바꾸지 않고 원문 표시를 보존한다. `system`과 system actor는 표시 경계에서만 `시스템`으로 바꾸며, 저장소 내부 token은 바꾸지 않는다. UUID·공백/포맷문자 오염값은 기존 표현인 `변경자 미상` 또는 해당 화면의 `삭제됨`/`업로더 확인 필요`를 사용한다.

## 3. RED-A ②와 RED-B actorId 보존

fix1의 과잉 차단을 되돌려 표시명과 내부 식별자를 분리했다.

- `RolePagePermission`, `RolePagePermissionTemplate`, `AccountPagePermission`, `AccountPermissionOverride`, `GroupPagePermission`에 `actorId` 컬럼을 추가했다.
- `V101__preserve_permission_change_actor_id.sql`로 다섯 테이블에 migration을 추가했다.
- 권한 변경·삭제·계정 matrix·template·group matrix·delegation의 원 actorId를 저장한다.
- `EffectivePermissionMaterializer`가 actorId를 유지해 account page permission으로 전달한다.
- 다섯 repository에 `findByActorId`를 제공해 역추적 조회가 가능하다.
- 응답/화면에는 표시명만 resolver 결과로 제공한다.

따라서 `actorId`, `callerId`, soft-delete key는 내부 join/audit key로 유지되고, 화면 UUID만 차단된다. 정상 이름은 원문을 보존하고, 이름이 없는 경우는 기존 `변경자 미상` 표현을 유지한다. `DepositMatchAuditRecorder`는 caller-name 헤더가 없는 별도 감사 기록기로 그대로 분리 유지했다.

## 4. 구조 검사와 mutation 증명

검사 파일: `clients/desktop/scripts/actor-display-boundary.test.cjs`
