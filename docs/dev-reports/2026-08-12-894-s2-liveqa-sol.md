# #894 S2 독립 앱 셸 실사용 Live QA — CODEX SOL

검증 시각: 2026-08-13 KST  
대상: `feat/894-internal-chat` · PR #1193  
제약: git 변경 명령 미사용 · 공유 DB 쓰기 미수행 · 구현 코드 미수정

## 결론

**실행으로 확인된 실사용 경로 결함은 0건이다.** 패키징된 독립 앱은 본체가 꺼진 상태에서 창이 열렸고, X로 닫은 뒤 트레이에 상주했으며, 트레이에서 다시 열리고 `종료` 후 프로세스가 0개가 됐다. PNG 삼한이 아이콘도 실제 Windows 트레이에서 식별됐다.

다만 전체 판정을 `PASS`로 닫을 수는 없다.

- **증거 무결성 불일치 1건:** 선행 보고서가 통과로 제시한 `clients/desktop`의 `npm test`가 재현되지 않았다. 전체 2,239개 중 1개가 실패했고, 해당 테스트만 좁혀 다시 실행해도 동일하게 실패했다.
- **미수행 1건:** 본체의 사내 채팅 사이드바 숨김을 로그인 후 실화면으로 확인하지 못했다. 본체는 로그인 화면까지 정상 기동했지만, 로그인은 공유 DB의 `last_login_at`을 쓰므로 이번 라운드의 DB 쓰기 금지 조건을 우선했다.

테스트 실패는 이번 라운드에서 UI 사용자 경로로 직접 재현한 결함 수에는 넣지 않고, 지시된 **증거 무결성 예외**로 별도 기록한다.
