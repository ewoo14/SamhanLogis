슬1 (#984)  — 모델코드가 일치하는 시트 계보 품목과 이카운트 계보 품목을 같은 품목으로 병합한다.   [이미 진행 중 / 데이터 대기]
대상: product-service · 관리자 이카운트 품목 임포트 화면.
슬2         — 노출용 품목코드를 모델명과 같게 전환하고 기존 순번코드는 품목 alias로 보존하되 내부 서버키는 변경하지 않는다.
대상: product-service · 품목코드가 노출되는 품목 화면·문서(구체 화면명 미확인).
슬3         — 기존 재고가 고아가 되지 않도록 재고 인스턴스의 품목코드 참조 키를 새 모델명 기반 품목코드로 이관한다.
대상: 재고 담당 서비스(정확한 서비스명 미확인) · 기존 재고 조회 및 QR 스캔 화면.
슬4         — 모델명과 중복되는 모델코드 컬럼을 계속 둘지 정리할지 판단한다.
대상: product-service · 직접 대상 화면 미확인(중복 데이터 컬럼 정리 판단).
슬5         — 웹 견적서와 주문서의 품목 식별 라벨이 모두 "모델명"으로 표시되는지 확인하고 통일한다.
대상: 견적서·주문서 담당 서비스(정확한 서비스명 미확인) · 웹 견적서 및 주문서 화면.
