## 3. 실행 방식

- `:services:product-service:bootJar --no-daemon`으로 이 worktree의 jar를 재빌드했습니다. 결과는 `BUILD SUCCESSFUL`입니다.
- `clients/web/design-system`에서 `npm install` 후 `npm run build`를 실행했습니다.
- `clients/desktop`에서 `npm install`을 실행했습니다.
- product-service는 공유 Docker 이미지를 재빌드하지 않고 별도 포트 `18421`에 standalone으로 기동했습니다.
- `spring.flyway.enabled=false`, `spring.jpa.hibernate.ddl-auto=validate`, Eureka 및 동기화 scheduler 비활성으로 실행했습니다.
- 로그와 pid는 저장소가 아닌 임시 scratch 경로에만 보관했습니다.
- 화면은 `clients/desktop/node_modules/.bin`의 Playwright를 사용한 headless Chromium으로 열었습니다.
- `vite.web.config.ts`의 BrowserRouter를 사용해 `http://127.0.0.1:5191/products/catalog` 및 상세 경로를 실제 화면으로 렌더링했습니다.
- 제품 관련 API 요청은 standalone `18421`, 공통 셸 요청은 실제 gateway `8080`으로 연결했습니다. 화면 캡처에는 JSON/API 응답 또는 터미널을 포함하지 않았습니다.
