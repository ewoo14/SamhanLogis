## #714 — 분개 상세 1024px 메모열 소실
- **원인**: JournalDetailPage DataTable=`table-layout:fixed`·`width:100%`인데 메모 열만 폭 미지정 → 컨테이너 좁아지면 고정열 합(680px) 뒤 메모가 0폭 눌림. DataTable `.wrapper`가 `overflow:hidden`만 → 스크롤 수단 없음.
