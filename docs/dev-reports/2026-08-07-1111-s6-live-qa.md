### 5.2 sync 실측

`POST /api/v1/products/admin/sync`는 HTTP 200을 반환했지만 내부 결과는 다음과 같았다.

```text
제품/lookup 탭 9/9 error
구성품 탭       2/2 error
totalUpdated=0
totalComponentsLinked=0
totalPreservedManual=0
구성품 탭 preservedManual 합=0
오류: Service Account JSON 키가 존재하지 않습니다: /etc/samhan/sa-key.json
```

컨테이너 inspect에서 `/etc/samhan/sa-key.json` mount가 없고 `GOOGLE_SERVICE_ACCOUNT_KEY` 설정도 없었다. mount는 이카운트 raw와 로그 두 개뿐이었다.

따라서 다음은 모두 **판정 불가**다.

- manual=true 편집분을 실제 sheet sync가 보존하는가.
- 손대지 않은 세트가 실제 sheet sync로 갱신되는가.
- `preservedManual` 카운트가 active manual=true 1건과 맞는가.

손대지 않은 대조군 `AM220AXVUHH1SY`는 구성품 2행과 digest가 유지됐지만, 이것도 정상 갱신 성공이 아니라 sync 미실행 결과다. `manual=false` 세트 digest 변경은 0건이었다.
