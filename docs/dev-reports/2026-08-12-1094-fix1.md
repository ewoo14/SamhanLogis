# PR #1179 (#1094) fix1 — 문서번호 링크·목록 복귀 재수렴

일시: 2026-08-12 (Asia/Seoul)  
작업 브랜치: `feat/1094-docno-hyperlink-and-back`  
대상 모듈: `clients/desktop`

## 결론

`#1175`의 DS `Card + detail-grid` 셸은 유지한 채, 견적·주문 표면에 #1094 계약을 다시 결합했다.

- 견적번호·주문번호를 문서번호 기반 native `Link`로 복구했다.
- 견적 DS 상세에 `← 목록`을 추가했다.
- 주문 DS 상세의 모든 목록 복귀 경로를 공통 history 복귀 계약으로 통일했다.
- 목록 링크 클릭 시 `returnTo`, `returnEntryKey`, scroll anchor를 전달·저장한다.
- 유효한 history entry는 `navigate(-1)`로 돌아가 검색 URL과 스크롤 identity를 보존한다.
- 직접 상세 진입은 안전한 canonical 목록 경로로 replace 이동한다.
- UUID를 문서 상세 이동 경로로 사용하지 않는다.

변경 파일:

- `clients/desktop/src/renderer/routes/EstimateListPage.tsx`
- `clients/desktop/src/renderer/routes/EstimateDetailPage.tsx`
- `clients/desktop/src/renderer/routes/SalesPartnerOrderListPage.tsx`
- `clients/desktop/src/renderer/routes/SalesPartnerOrderDetailPage.tsx`
- 각 대상 화면 테스트 4개
