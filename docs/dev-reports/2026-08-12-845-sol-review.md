### 결함 D-1 — 참조 전표 품목이 실제 인쇄 미리보기와 PDF에 전혀 표시되지 않음

재현 경로:

1. MASTER로 로그인한다.
2. 결재 `2026/06/14-1`의 인쇄 미리보기를 연다.
3. 첨부 표에 출고전표 `2026/08/07-20`이 표시되고, 네트워크에서도 exact query와 상세가 모두 HTTP 200인지 확인한다.
4. 격리 DB에서 이 전표의 활성 라인이 12건임을 확인한다.
5. 화면과 PDF에서 품목 표·모델명 `AJ060MXHNBC1`을 찾는다.

실제 결과는 `detailLayer=0`, `detailRows=0`, `modelNameVisible=false`이며 PDF도 `MODEL_AJ060=False`다. 화면에는 첨부의 전표번호만 있고 품목은 한 줄도 없다. 원인은 현재 사용 가능한 기본 양식 `GROUPWARE_DEFAULT`의 BODY가 `CONTENT_PARAGRAPHS`, `FIELD_TABLE`, `ATTACHMENT_TABLE`만 포함하고 `DETAIL` 요소를 포함하지 않기 때문이다. 구현은 `slipLineItems`를 render model에 넣지만, 실제 양식이 이를 소비하지 않는다.

이 결함 때문에 “라인 다수 전표의 페이지 넘김·잘림”도 실사용 경로에서 품목이 0행으로 소실되어 기능 요구를 충족하지 못한다. PDF는 1페이지로 생성됐지만 이는 12라인을 정상 분할한 결과가 아니라 12라인을 전부 누락한 결과다.
