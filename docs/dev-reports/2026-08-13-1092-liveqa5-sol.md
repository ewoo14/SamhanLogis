## 실행 경계와 공유 DB 읽기 전용 보장

인앱 Browser 런타임은 연결 복구 절차 후에도 `[]`였으며, 지시대로 저장소 Playwright Chromium을 사용했다. 로그인은 `last_login_at`을 쓰므로 호출하지 않았다. 실행 중 gateway가 사용하는 JWT 구성과 활성 MASTER 계정을 읽어 1시간짜리 로컬 QA 쿠키를 만들고 `GET /auth/me`로만 세션을 복원했다.

브라우저 route에서 gateway의 `GET`/`HEAD`/`OPTIONS`만 허용했다. `POST /logs/front`와 협업 presence join/leave 등 비-GET 21건은 전부 `READ_ONLY_BLOCK`으로 차단했다. 저장·편집값 변경·발송·전표 변환·복원·코멘트 등록 버튼은 누르지 않았다. DB SQL은 모두 `BEGIN TRANSACTION READ ONLY` 안에서 실행했다.

```text
로그인 호출: 0회
브라우저 gateway 비-GET 허용: 0건
브라우저 gateway 비-GET 차단: 21건
공유 DB INSERT/UPDATE/DELETE/DDL: 0건
저장 버튼 클릭: 0회
```

### A2~A6. 코멘트·presence·stream·coedit·revision

`2026/08/10-9` 상세에서 자동 또는 실제 버튼으로 발생한 원문이다.

```text
GET /api/v1/slips/estimates/2026-08-10-9/collab/comments?limit=20 HTTP 400 | 132 bytes
GET /api/v1/slips/estimates/2026-08-10-9/collab/presence          HTTP 400 | 132 bytes
GET /api/v1/slips/estimates/2026-08-10-9/collab/stream            HTTP 403
GET /api/v1/slips/estimates/2026-08-10-9/collab/edits             HTTP 400 | 132 bytes
GET /api/v1/slips/estimates/2026-08-10-9/collab/coedit            HTTP 400 | 132 bytes
GET /api/v1/slips/estimates/2026-08-10-9/revisions                HTTP 400 | 132 bytes
```

화면 원문:

```text
코멘트를 불러오지 못했습니다.
버전 이력을 불러오지 못했습니다.
```

코멘트·presence·stream 실패는 확인한 상세 5/5에서 반복됐다. `버전이력` 버튼을 실제 클릭해 revision `400`을 확인했다. `edits`와 `coedit` GET은 같은 인증 쿠키의 화면 컨텍스트에서 직접 조회해 각각 `400`을 확인했다.

편집 버튼 실제 클릭은 coedit 요청 전에 별도 결함으로 막혔다.

```text
상세 화면 편집 클릭
→ /sales/estimates/2026/08/10-9/edit
→ SPA 404 "페이지를 찾을 수 없습니다"
```

대상 사용자 흐름 동안 gateway 전체 응답을 관찰하고, 문서번호 계열과 목록 보조 요청을 중복 제거했다.

## 증거 무결성 — 보고서의 25개 경로와 실제

보고서가 열거한 서버 endpoint 수 `10 + 2 + 13 = 25` 자체는 반증되지 않았다. 그러나 보고서의 **25개 전수 처리 완료** 주장은 실 gateway 결과와 다르다. 읽기 가능한 7개 표면 중 상세 GET만 `200`이고 comments·presence·stream·edits·coedit·revision 6개 표면이 `400/403`이다.

또한 프런트 요청 표에는 실제 사용자 진입점인 `상세 → /sales/estimates/:id/edit` SPA 경로가 없다. 이 경로는 원문 슬래시 문서번호를 그대로 붙여 404가 되며 coedit 화면에 도달하지 못한다. 따라서 실제 사용자 경로 기준 sweep은 불완전하다.

25개 중 DB 쓰기를 수반하는 나머지 18개 endpoint(수정·상태전이·delete/restore·owner·revision restore·코멘트/edits/coedit/presence mutation)는 공유 DB 읽기 전용 지시 때문에 실행하지 않았다. **쓰기가 필요해 미검증**이다.

### 데이터 자리 `?`

## 도달 가능한 결함

1. **문서번호 협업·revision GET 계열이 실 gateway에서 처리되지 않는다.** 상세 본문은 하이픈 path id로 `200`이지만 comments·presence·edits·coedit·revision은 `400`, stream은 `403`이다. 코멘트와 버전이력 오류가 화면에 표시되며 5개 상세에서 반복됐다.
2. **상세의 편집 버튼이 원문 슬래시 문서번호를 SPA path에 그대로 붙여 404로 이동한다.** 사용자는 coedit 편집 화면에 도달할 수 없다. 이 실제 GUI 경로는 25개 요청 표에 없었다.

**도달 가능한 결함: 2건. 머지 불가.**
