# 2026-08-13 #1090 라이브 QA — CODEX SOL

## 결론

**견적 작성 화면에서 사용자가 보는 금액은 V42 전/후 및 분류 저장 후 모두 동일했다.**

- `AC023BN1DBC1`, 거래처 없음: **316,800원 → 316,800원 → 분류 저장 후 316,800원**
- 옵션 DC 50,000원 거래처 `환경시스템공조-김진혁대표님`: **316,800원 → 316,800원 → 분류 저장 후 316,800원**
- 옵션 DC 60,000원 거래처 `(주)삼한공조시스템`: **316,800원 → 316,800원**
- 이미 분류된 `AC023CN1DBC1`, 옵션 DC 50,000원 거래처: V42 후 화면 **316,800원**

그러나 **주문 작성 화면에서는 V42 전·후·분류 저장 후 모두 `AC023BN1DBC1`이 네 카테고리와 bootstrap 응답에 존재하지 않아 금액을 화면에 올릴 수 없었다.** 따라서 질문 전체(견적+주문)에 대한 답은 **“견적은 같다. 주문은 미도달이라 같다고 판정할 수 없다.”** 이며, **머지 불가**로 판정한다.

> 참고: 직전 DB/API 전수 대조의 옵션 DC 결과 `266,800원`과 별개로, 이번 실제 견적 GUI는 전/후 모두 `316,800원`을 표시했다. 본 보고서는 요청대로 화면에서 실제 읽은 숫자만 판정 근거로 삼는다.
