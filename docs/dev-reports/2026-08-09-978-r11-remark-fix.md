# PR #1127 R11 — 오류 탭 비고 카운트 표시 fix

## 범위

SOL R10에서 정상으로 확인한 API 응답·집계·DB·구성품 연결·배포 산출물은 건드리지 않고, `SheetSyncPage.tsx`의 비고 문자열 투영만 수정했다.

## 원인 확인

수정 전 [clients/desktop/src/renderer/routes/admin/SheetSyncPage.tsx:336-341](../../clients/desktop/src/renderer/routes/admin/SheetSyncPage.tsx)의 `formatTabRemark()`는 다음 순서였다.

```ts
if (result.error) return result.error
const parts: string[] = []
if (result.unchangedRows) parts.push(`변경 없음 ${result.unchangedRows}`)
if (result.skippedOccurrences) parts.push(`skip occurrence ${result.skippedOccurrences}`)
```

따라서 `error`와 `unchangedRows`가 동시에 있으면 오류 문자열에서 즉시 반환되어 카운트가 사라졌다. SOL의 지목이 맞으며, R10이 확인한 API `unchangedRows=32`와 화면 미표시는 별도 FE 표시 우선순위 결함이었다.

## 수정

`result.error`를 즉시 반환하지 않고 `parts`의 첫 항목으로 추가했다. 그 뒤의 기존 `unchangedRows`·`skippedOccurrences` 조합과 오류 없는 문자열은 그대로 유지했다.

결과적으로 오류 탭은 다음처럼 둘 다 표시된다.

```text
추천실외기 natural key 중복: key=HOME_MULTI|null|7|2.5HP, firstRow=3, duplicateRow=4 / 변경 없음 32 / skip occurrence 1
```

- `git commit`, `git push`는 하지 않았다.
