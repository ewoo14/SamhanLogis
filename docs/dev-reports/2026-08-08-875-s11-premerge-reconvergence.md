## 결함 S11-875-01 — 네 입력 탭 모두 탭 합계가 실제 화면에 없음

### 재현

1. 홈멀티·싱글중대형·상업멀티·구형 각 탭에서 운임 `1,000`, 절삭 `500`을 입력한다.
2. 행 수량 `1`, 행 소계 `1,000`과 `-500`을 확인한다.
3. 각 표 하단에서 탭 합계를 찾는다.

### 실제 결과

- 홈·싱글·상업: 합계 마크업은 있으나 `index.ejs:105`의 `#wrapHome tfoot, #wrapSingle tfoot, #wrapComm tfoot { display:none!important; }` 때문에 PC에서 표시되지 않는다.
- `index.ejs:561`은 모바일에서도 세 `tfoot`을 다시 숨긴다.
- 구형: `index.ejs:1597~1603`의 `tfoot` 전체가 주석이라 `#oldTotal`이 DOM에 존재하지 않는다.
- 실제 Chromium에서 `tfoot`/`#singleTotal`의 bounding box는 `0 × 0`, computed `display`는 `none`이었다. 구형은 `tfootCount=0`, `oldTotalCount=0`이었다.

즉 “상업 탭 합계 금액이 뜨고 라벨 중복이 없다”는 요구에서 라벨 중복 DOM은 해소됐지만 **금액이 뜬다**는 전제 자체가 성립하지 않는다. 상업의 숨은 DOM은 `합계` 라벨 1개와 숫자 `500` 1개로 정리되어 있었다.
