# #1113 S10 — CI red 2건 수정

## 결론

S9 후속 CI red 2건의 원인을 각각 환경 불일치와 낡은 문서 계약 단정으로 분리해 수정했다.
코드 기능이나 가드를 약화하지 않았고, commit·push·컨테이너 재빌드는 수행하지 않았다.

## ① Local Stack Port Resolver Guard

`.github/workflows/ci.yml`의 `local-stack-port-guard` 잡을 `ubuntu-latest`에서
`windows-latest`로 옮겼다. 가드 스캔은 기존처럼 `shell: pwsh`로 실행하고, S7 회귀
스크립트는 `shell: powershell`로 실행해 GitHub Actions의 Windows PowerShell 5.1을
명시적으로 사용한다. 잡 timeout은 5분을 유지했다.

따라서 다음 두 단계가 같은 Windows runner에서 실제 실행된다.

```powershell
./scripts/check-local-stack-port-literals.ps1 -Root $PWD
./tools/operational-validation/test-s7-axis-redefined.ps1
```

### 5.1 실행 근거

개발 PC의 실제 실행기는 다음과 같았다.

```text
Windows PowerShell 5.1.26100.8972
S7 axis regression tests passed.
Local-stack port literal guard passed: all tracked .ps1 consumers use the resolver.
```

`test-s7-axis-redefined.ps1`는 0/1/다건 `Measure-Object`, resolver 기본값/override,
unknown service throw, 그리고 임시 git repository에 새 tracked `bad.ps1`와
`localhost:8080`을 주입하는 mutation을 실행한다. mutation에서 guard가 비-0으로
끝나는 것을 확인했으므로 발견 기반 스캔과 RED-B가 실제로 살아 있다.

## ② 문서 본문 단언 스펙

S9에서 `import-notion-csv.ps1`의 `Resolve-ImportServicePort`, fallback health probe,
분산 `SAMHAN_*_PORT` 단정을 제거하고 `scripts/lib/local-stack-port.ps1`의
`Get-LocalStackPort`를 사용하도록 바꿨다. 그러나 `clients/desktop/playwright/
sp-06-notion-db-crud/sp-06-notion-db-crud.spec.ts`의 문서 계약 테스트는 이전 본문을
계속 요구하고 있었다.

해당 단정을 삭제하지 않고 현재 계약을 검증하도록 갱신했다. 테스트는 resolver 파일
경유, 네 직접 호출 service의 `Get-LocalStackPort -Service` 매핑, gateway resolver
호출을 단정하며, 옛 `Resolve-ImportServicePort`와 fallback probe가 다시 살아나는 것도
실패시킨다. 문서 본문과 운영 스크립트가 어긋나지 않게 하는 원래 목적은 보존했다.

## RED-A / RED-B

| 판정 | 결과 | 근거 |
|---|---|---|
| RED-A | GREEN | `local-stack-port-guard`가 Windows runner에서 실제 5.1 테스트를 실행하도록 변경했고, 로컬 5.1 실행 결과가 `S7 axis regression tests passed`였다. 문서 계약 mock도 10/10 passed다. |
| RED-B | GREEN | 정상 가드는 tracked `.ps1` 전체를 발견해 통과했고, mutation의 새 tracked port literal은 비-0으로 거부됐다. resolver 호출·17 service 매핑·기존 S1~S9 대상은 변경하지 않았다. |

## 검증 명령과 결과

```text
powershell.exe -NoProfile -NonInteractive -ExecutionPolicy Bypass -File .\tools\operational-validation\test-s7-axis-redefined.ps1
  PASS — S7 axis regression tests passed.

  PASS — Local-stack port literal guard passed: all tracked .ps1 consumers use the resolver.

npx playwright test playwright/sp-06-notion-db-crud/sp-06-notion-db-crud.spec.ts --reporter=line
  PASS — 10 passed (3.6s)

git diff --check
  PASS — 출력 없음
```

Playwright 실행 전 `clients/desktop`의 lockfile 기준 `npm ci --ignore-scripts`를 수행했다.
감사 경고 33건은 기존 의존성 감사 결과이며 이번 변경의 테스트 실패가 아니다.
