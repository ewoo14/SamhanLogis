## 1. 판정

**병합 차단 결함 0건이다. PM 머지 보고 가능하다.**

`ProductCatalogResponse`의 record 선언과 두 생성 경로를 위치별로 대조하고, 임시 Spring Boot/MockMvc probe에서 서로 다른 boolean 값을 넣어 실제 JSON 값까지 확인했다. `#1126` 수량동기화 판정과 `#1132` 정액DC·V37 경로는 함께 남아 있다. 양쪽이 모두 수정한 파일은 LUNA 보고서의 자동 병합 5개가 아니라 **충돌 파일 2개 + 자동 병합 7개 = 총 9개**이며, 누락됐던 두 파일까지 본 R3에서 독립 검토했다.

비차단 보고 편차 1건은 있다. LUNA 보고서의 자동 병합 표에는 `productCatalogApi.ts`, `EstimateItemsCatalogPage.tsx`가 빠져 있다. 최종 코드의 기능 누락은 아니며, 아래 4절에서 실제 7개 전부를 검토해 보고 범위를 교정했다.

### 2.2 실제 응답 값 검증

임시 `@SpringBootTest` + Testcontainers + MockMvc probe에서 boolean을 의도적으로 서로 다르게 구성했다.

## 3. 두 기능군 보존 검토

### 3.1 #1126 수량동기화

- `ProductCatalogResponse.from`이 `QuantitySyncRuleValidator.isValidTargetRole(...)`를 호출한다.
- 위 실제 JSON에서 판정 결과가 `quantitySyncTargetEligible=true`로 직렬화됐다.
- `EstimateItemsCatalogPage.test.ts`에 quantity-sync 409 rule key 추출과 활성 source 모델코드 편집 대상 해석 검사가 남아 있다.
- 최종 충돌 파일 표적 실행은 8/8 통과했다.

### 3.2 #1132 정액DC

- catalog 응답과 internal catalog 응답 모두 raw `getFixedDiscountRate()`가 아니라 `resolveFixedDiscount().rate()`를 사용한다.
- desktop은 `resolveEstimateCatalogPrice`를 통해 정액DC를 적용한다.
- 표적 단위 테스트에서 `495,000`, `15%`가 `420,750`으로 계산되는 경우와 할인 없음 `495,000` 유지 경우가 2/2 통과했다.
- 실제 JSON에서 분류 L의 `15.00`과 출처 `L`이 각 필드에 정확히 들어갔다.

### 3.3 #1132 V37와 BundleExpander

- V37 migration의 활성 `BUNDLE` 대상 backfill 및 audit 경로가 병합 후에도 존재한다.
- `BundleExpander`는 활성 구성품 중 `isDefault=true`만 전개하는 계약을 유지한다.
- `ProductSheetSyncService`의 V37 부모 단위 기본값 보존 정책과 #1126 수량동기화 참조 보호가 함께 남아 있다.
- fresh product 전체 suite에서 `BundleExpanderIT` 25/25, `ProductSheetSyncServiceIT` 46/46을 포함해 통과했다.

PM이 실 서버에서 확인한 다음 값은 **병합 전 배포본의 RED-B 기준선**으로만 사용했다. 이번 R3은 배포된 product-service 응답을 병합 후 검증이라고 주장하지 않는다.

```text

AM120AXVHHR1 qty 1.00 단가 5,808,000
V37 기준: 72세트 / 137구성품
```

이번 라운드에서는 공유 DB를 쓰지 않았고, 배포 전 병합 작업 트리 백엔드를 공유 DB에 연결해 위 실값을 재실행하지 않았다. V37 수치 자체는 R2의 격리 PostgreSQL/Flyway 검증 결과를 RED-B로 삼고, R3에서는 migration·호출 경로 검토와 fresh Testcontainers suite로 회귀 여부를 확인했다.

## 8. 이 라운드가 보지 않은 표면

- 병합 작업 트리의 product-service를 실제 배포하지 않았으므로, 배포 후 `/products/internal/expand`의 PM 기준선 2라인을 재측정하지 않았다.
