- 캡처: `r31-step1-A-1-X.png`

### 2단계 — B 날짜로 변경 후 X 미존재

- 판정: PASS
- 관찰: `2026-08-01`로 변경 후 미리보기. 날짜별 연락처 입력행은 비어 있고 X=`010-2026-0803`가 B의 메시지에 노출되지 않음. B 실데이터는 4건이며 `2026/08/01-5`~`-8`로 확인됨.
- 캡처: `r31-step2-B-no-X.png`

### 3단계 — B에서 Y 입력 후 A 복귀 시 X 유지

- 판정: 조건부 PASS / 데이터 제약
- 관찰: B에서 순번 `1`, Y=`010-2026-0801`을 입력한 입력행은 B 날짜에 유지됨. 그러나 실 B 전표 4건에 `2026/08/01-1`이 없어 미리보기 메시지에는 Y가 매칭되지 않음. A로 복귀하면 입력행은 X=`010-2026-0803`으로 복원되고 Y가 섞이지 않음. 교차 날짜 섞임 결함은 재현되지 않음.
- 캡처: `r31-step3-B-1-Y.png`, `r31-step3-A-return-X-not-Y.png`

### 4단계 — 날짜 변경 후 새 연락처 반영

- 판정: PASS
- 관찰: 날짜를 `2026-07-27`로 변경한 뒤 새 입력 `1 + 010-2026-0727`을 추가하고 미리보기. 66건 중 `2026/07/27-1` 메시지에 신규 연락처가 반영됨.
- 캡처: `r31-step4-new-contact-after-date-change.png`

### 5단계 — 순수 숫자 순번 `1` 매칭

- 판정: PASS
- 관찰: A에서 순수 숫자 `1` 입력이 `2026/08/03-1`에 매칭되고 연락처 X가 메시지에 반영됨.
- 캡처: `r31-step5-pure-number-1.png`

### 6단계 — 연락처 없는 전표 fallback

- 판정: PASS
- 관찰: A의 6건 중 매칭된 `-1`을 제외한 5건이 `기사번호 없음 확인요망!` fallback을 유지함.
- 캡처: `r31-step6-fallback.png`

### 7단계 — 자동 SMS 미발송

## 종합 판단

- 머지 가능 여부: **조건부 가능** — R30 핵심인 날짜별 X/Y 상태 분리·A 복귀 X 유지와 R21 신규 입력 반영은 PASS. 단, B의 `-1` 전표 부재로 “B `1 + Y` 미리보기 매칭” 자체는 실증 불가.

## 섞임 재현 절차

- 이번 실측에서는 섞임이 재현되지 않음.
- 재현 확인 절차는 A=`2026-08-03`에서 `1 + X` 입력·미리보기 → B=`2026-08-01`로 변경·미리보기 → B에서 `1 + Y` 입력·미리보기 → A로 복귀·미리보기 후 A의 `-1` 메시지가 Y로 바뀌는지 비교하는 순서임.
