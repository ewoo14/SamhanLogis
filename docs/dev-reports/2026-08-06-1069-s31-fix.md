## API 누출 경로 전수표

git diff origin/main...HEAD -- clients/desktop/src/renderer/api 기준 이 PR에서 추가·변경된 호출은 1건이다.

| 호출 | 호출자 | mock handler | 결과 |
|---|---|---|---|
| POST /slips/expand-line | slip.ts:319 expandBundleLine | mock.ts:1763–1830, dispatcher 3517–3518 | 고정 응답. 미사용 API 주소로 실제 요청 누출 없음 |

관련 기존 호출도 대조했다. GET /api/products?q=는 mock.ts:3353 handler, GET /slips/lookup-product는 mock.ts:3524 이후 handler가 있다. 이번 PR에서 변경되지 않은 호출이며 누락 경로는 추가로 확인되지 않았다. mock fixture 모드는 명시값(KEEP 기본, EXPAND, NULL)만 사용하고 외부 응답으로 결정하지 않는다.
