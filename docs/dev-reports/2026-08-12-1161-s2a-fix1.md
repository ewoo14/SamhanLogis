## 결론

① Spring 설정 연결 재사용과 JSON converter를 복구했다. Rabbit이 중단된 경우 publisher worker 예외는 기존 fail-soft 경계에서 유지된다.

② 실제 격리 RabbitMQ 왕복에서 dc-config mutation과 partner-auth B_FAILURE 두 이벤트가 모두 수신됐다.

③ partner-auth controller/security-chain 이전 400 이상 실패를 최우선 filter에서 B_FAILURE로 발행한다. filter 이벤트에는 비밀번호·토큰·User-Agent·UUID를 넣지 않는다.
