# #1123 S12 gateway 라우트 fix 보고서

## 결론

S11 라이브QA의 404 원인은 `slip-service` 컨트롤러가 아닌 gateway의 `slip-dispatch-admin-noprefix` Path 목록 누락이었다. `application.yml`과 대응 계약 테스트에 `/admin/slip-closing-baselines` 및 `/admin/slip-closing-baselines/**`를 추가했다. 컨트롤러 매핑은 변경하지 않았다.

변경 파일:

- `services/api-gateway/src/main/resources/application.yml`
- `services/api-gateway/src/test/java/com/samhanair/logis/gateway/it/ApiGatewayContextLoadIT.java`
- `docs/dev-reports/2026-08-08-1123-s12-gateway-route.md` (신규)

신규 production/test 소스 파일은 없다.

## 전제 검증과 원인

컨트롤러는 다음 풀패스를 사용한다.

```java
@RequestMapping("/admin/slip-closing-baselines")
```

기존 정본 선례인 `/admin/slip-cutoffs`와 동일하게 prefix를 제거하지 않고, `JwtAuthentication`만 적용하는 `slip-dispatch-admin-noprefix`에 경로를 넣는 것이 최소 변경이다. 수정 전 계약 RED는 실제 route definition의 Path 목록에 신규 두 패턴이 없음을 보여 주었고, 필터·서비스 등록·컨트롤러 로딩 문제가 원인이라는 증거는 확인되지 않았다.

## 메서드·경로 대조표

| 메서드 | 프런트 호출 경로 | 컨트롤러 매핑 | gateway 라우트 | 계약테스트 |
|---|---|---|---|---|
| GET | `await call(request, manager, '기준선 목록', 'GET', '/admin/slip-closing-baselines')` | `@GetMapping` + `/admin/slip-closing-baselines` | `slip-dispatch-admin-noprefix` / `/admin/slip-closing-baselines` | `provisionalDispatchAdminRoutes_areAuthenticatedNoStripAndReachable`의 base Path |
| POST | `await call(request, manager, 'OUTBOUND 오늘 기준선 생성', 'POST', '/admin/slip-closing-baselines', {...})` | `@PostMapping` + `/admin/slip-closing-baselines` | `slip-dispatch-admin-noprefix` / `/admin/slip-closing-baselines` | 동일 테스트의 base Path |
| DELETE | `await call(request, manager, 'OUTBOUND 익일 기준선 삭제', 'DELETE', \`/admin/slip-closing-baselines/${outboundId}\`)` | `@DeleteMapping("/{id}")` + `/admin/slip-closing-baselines` | `slip-dispatch-admin-noprefix` / `/admin/slip-closing-baselines/**` | 동일 테스트의 wildcard Path |

프런트 호출 원문 출처는 `clients/desktop/test-results/1123-s11-live-real-qa-1123-9e08d-al-qa-PR-1124-S11-라이브-적대-검증-renderer/error-context.md`이다. `clients/desktop/src`에는 이 문자열을 직접 호출하는 현재 소스가 없고, 위 QA renderer 산출물에는 세 메서드 호출이 모두 남아 있다. 따라서 소스 구현과 QA 실행 산출물을 구분한다.

## 새로 가능해진 경로·권한 조합과 결과

- `GET /admin/slip-closing-baselines` + JWT + `slip.closed-date-admin` VIEW: gateway Path 계약 통과. 컨트롤러 `@GetMapping`에 도달 가능한 경로가 열렸다.
- `POST /admin/slip-closing-baselines` + JWT + `slip.closed-date-admin` CREATE: gateway Path 계약 통과. 컨트롤러 `@PostMapping`에 도달 가능한 경로가 열렸다.
- `DELETE /admin/slip-closing-baselines/{id}` + JWT + `slip.closed-date-admin` DELETE: wildcard Path 계약 통과. 컨트롤러 `@DeleteMapping("/{id}")`에 도달 가능한 경로가 열렸다.
- 권한 없는 계정: gateway route에는 계속 `JwtAuthentication`이 적용되고, slip-service의 기존 `@RequirePermission`이 남아 있으므로 우회 경로를 추가하지 않았다. 실서버 HTTP 호출은 요청대로 하지 않았다.
- 기존 `/admin/slip-cutoffs`와 기존 route 목록·필터는 변경하지 않았고, 같은 route의 no-strip 및 Jwt 계약을 함께 통과했다.
