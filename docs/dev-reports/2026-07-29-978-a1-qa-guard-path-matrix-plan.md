# #978 A-1 QA 증거 오염 가드 — 경로 표기 형태별 판정표 (조기 PR)

> 연관 Issue: #978 (항목 A-1)

## 왜 하는가

QA 증거 오염 가드는 테스트가 **커밋된 QA 스크린샷을 덮어쓰거나 지우는 것**을 막는 장치다(`clients/desktop/scripts/qa-output-path-guard.test.cjs`).

직전 라운드에서 CODEX SOL 이 **판정 실패-개방 6건**을 찾아 10사본 fail-closed 로 전환했다. 그런데 **SOL 브리핑을 완주 가능한 크기로 좁히느라 경로 표기 형태별 판정표가 빠졌다.**

이 항목은 **#957 SOL 라운드를 두 번 타임아웃시킨 원인**이다. 그래서 이번에 **단독 라운드**로 배정한다.

## 불변식

1. **같은 실제 위치를 가리키는 경로는 어떻게 적든 같은 판정을 받는다.** 저장소 안 QA 경로는 표기 형태와 무관하게 차단
2. **저장소 밖 경로는 통과한다** — 과차단은 그 자체로 결함이다
3. 판정 근거는 **실제 실행**

## 세울 판정표

| 형태 | 기대 |
|---|---|
| 평범 `D:\dev\...\docs\qa\...` | 차단 |
| UNC — `\\localhost\D$\...` | 차단 |
| UNC — `\\127.0.0.1\D$\...` | 차단 |
| UNC — `\\<컴퓨터명>\D$\...` | 차단 |
| UNC — **`\\<자기 LAN IP>\D$\...`** | 차단 |
| 슬래시 / 혼합 `D:/dev/...`, `D:\dev/...` | 차단 |
| **subst** 드라이브 (`subst X: D:\dev`) | 차단 |
| **크로스드라이브 junction** (`mklink /J`) | 차단 |
| `-ProjectRoot` 타 체크아웃 | 차단 |
| **과차단 대조군** `\\203.0.113.77\share\...` | **통과** |

마지막 행이 핵심이다. 전부 막는 가드는 판정하는 게 아니라 그냥 끄는 것이다.

## 🚨 이 트랙 자체의 사고 위험

**삭제를 다루는 가드를 시험하므로 시험자가 사고를 낼 수 있다.** 과거에 `rm -rf docs/qa/<슬러그>` 로 **커밋 파일 33개가 삭제**된 실측 사고가 있었다.

브리핑에 못박은 제약:
- 저장소 안 파일 삭제·덮어쓰기 **일절 금지**. 특히 `docs/qa/**`, `clients/desktop/playwright/**/screenshots/**`
- 임시물은 **`os.tmpdir()` 아래에만**
- 지우기 전 **`git ls-files <경로>` 로 추적 여부 선확인**
- `subst`/`mklink` 는 **끝나고 반드시 해제**하고 출력으로 확인
- 종료 시 `git status --porcelain` 에 예상 밖 `D`(삭제)가 하나라도 있으면 즉시 원복·보고
