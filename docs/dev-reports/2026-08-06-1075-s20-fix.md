# PR #1078 · 이슈 #1075 — S20 fix (LUNA)

## 판정

S19 결함을 수정했다. `EstimateSnapshot.Line` 마지막에 nullable `specificationSource`를 추가하고, 캡처→JSONB→역직렬화→복원과 revision diff에 규격 출처를 연결했다. 협업 snapshot write에도 두 필드를 함께 기록한다. 구 JSONB의 source 부재는 `null`로 유지하며, 화면의 기존 decode 정책이 marker 없는 평문을 `USER`, U+2060을 `CATALOG`로 처리한다. 새 migration은 만들지 않았다(V113 기존 파일 사용).
