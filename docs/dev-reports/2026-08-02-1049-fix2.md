## 1. 결함 2 판단 — ① 스펙 갱신

기존 스펙은 옛 UI를 단언하는 단순 표현 변경이 아니라, `/products/estimate-items`에서 기초품목을 검색·선택하고 `PATCH /usage`로 현재 카테고리에 추가한 뒤 토글과 카테고리 칩이 나타나는 실제 기능 경로를 검증한다. 따라서 `기초품목 선택 추가` 자체가 막혔다면 스펙 갱신 대상인 ①이 아니라 정상 경로를 차단한 구현 결함 ②로 판정한다.

실행으로 가른 결과는 **①**이다. 현재 구현은 추가 경로를 제공하며, `AJ036NCH3CH` 검색 결과 1건은 새 UI 계약에 따라 dropdown 후보를 노출하지 않고 즉시 선택 칩으로 확정한다. 기존 스펙의 `li[role=option]` 클릭은 옛 UI 표현이고, 기능 자체가 차단된 것이 아니다. 스펙은 모델코드 검색 → `1개 선택됨` 칩 → 추가 버튼 → 토글·현재 카테고리 칩을 확인하도록 갱신했다.
