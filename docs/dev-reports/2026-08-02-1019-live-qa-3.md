정리 후 확인:

```text

```

시나리오 2의 임시 설명은 저장 후 빈 문자열로 제거했다. 현재 `UpdateProductRequest`에서 `description: null`은 “미변경” 의미라 원래 `NULL`로 되돌릴 수 없었다. 따라서 대상 기존 행의 설명은 **NULL → 빈 문자열**로 남아 있으며, 이 잔여 차이는 완전한 데이터 원상복구가 아니다. 행 수와 상태 수는 실행 전과 동일하다.
