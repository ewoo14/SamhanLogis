## 3. 수정 내용과 타입 완화 여부

변경 파일은 `clients/desktop/src/renderer/routes/SlipFormPage.tsx` 하나다.

1. `modelCode: line.modelCode ?? null`
   - `LineDraft` 계약이 허용하는 실제 `undefined`를 스냅샷 계약이 사용하는 `null`로 정규화한다.
   - 값이 없을 때의 기존 의미(식별자 없음)를 명시한 것이며, 타입을 넓히거나 값을 단언하지 않았다.

2. `firstComponentLine`을 변수로 받고 `undefined`를 명시적으로 검사
   - 구성품 배열이 비어 있으면 옵션 컨텍스트를 붙이지 않는다.
   - 구성품이 있을 때만 첫 행 ID를 사용한다. `!`, `as`, `any`, `@ts-ignore`, `@ts-expect-error`를 사용하지 않았다.
   - KEEP/EXPAND/NULL 정책을 변경하지 않고, 기존의 “첫 구성품에 컨텍스트 연결” 동작을 안전하게 표현했다.

3. `const resolvedLines: LineDraft[] = linesRef.current.map((current): LineDraft => ...)`
   - 가격 갱신 객체가 실제로 `LineDraft` 필드를 모두 유지하도록 반환 타입을 명시했다.
   - `priceSource`를 `string`으로 넓히지 않고 `LineDraft`의 `'CATALOG' | 'REMEMBERED'` 계약 안에서 추론하게 만든다.
   - `LineDraft` 타입 자체를 넓히지 않았고, state setter를 우회하지 않았다.
