# PR #1173 fix2 — S1 저장소 메타 가드 G12 배선

## 결론

`docs/local-stack/README.md` 본문을 단언하는
`scripts/lib/s1-logging-opt-in-contract.test.cjs` 자체는 적절한 계약 검사다.
README의 opt-in 실행 명령이 바뀌면 실제 동작 안내와 계약이 어긋나므로,
문서 본문을 단언하는 현재 구조를 유지하고 실행 관할만 보강했다.

## 원인

G12 도출 결과는 다음 두 문서를 S1 계약 테스트의 관할로 식별했다.

- `docs/local-stack/README.md`
- `docs/operational-validation/boot-and-smoke-validation.md`

기존 `docs-guard.yml`에는 `docs/local-stack/**` 트리거와
`scripts/lib/s1-logging-opt-in-contract.test.cjs` 실행 스텝이 모두 없었다.
따라서 문서만 변경한 PR에서 해당 계약 테스트가 실행되지 않는 G12 실패였다.

## 변경

`.github/workflows/docs-guard.yml`만 변경했다.

- `pull_request`와 `push` 양쪽에 `docs/local-stack/**` 추가
- `pull_request`와 `push` 양쪽에 S1 계약 테스트 파일 경로 추가
- 별도 경량 `s1-logging-opt-in-contract` 잡 추가
- 잡에서 `node --test scripts/lib/s1-logging-opt-in-contract.test.cjs` 실제 실행

기존 `harness-guard.yml`, `ci.yml`, `qa-e2e.yml` 관할은 변경하지 않았다.
