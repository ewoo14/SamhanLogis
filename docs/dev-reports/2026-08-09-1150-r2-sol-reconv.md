## 결함 1 — IME 조합 중 Escape가 상위 병합 모달을 닫는다

### 실 사용자 경로

1. 주문서 관리 → `판매전표 병합 전환`을 연다.
2. 출고 창고에서 실제 한글 IME 조합으로 `본`을 입력한다.
3. 조합 중에는 값이 `본`, selection `1..1`로 유지된다. 자동확정은 끼어들지 않았다.
4. 조합을 확정하면 `HQ-001 · 본사창고`로 자동확정되고 selection은 `10..13`이다. 접두 `HQ-001 · 본`은 유지되고 suffix `사창고`만 선택됐다.
5. 선택된 suffix 위에서 실제 IME 조합으로 `가`를 입력한다. 값은 `HQ-001 · 본가`, 이벤트는 `insertCompositionText`, `isComposing=true`다.
6. 조합을 취소하려고 Escape를 누른다.
7. Escape 이벤트는 `keydown`, `isComposing=true`, `key=Escape`로 관측됐지만, 직후 창고 input과 병합 dialog가 모두 DOM에서 사라졌다.

반복 결과: **2/2 재현**.
