## RED 증거

원문은 [2026-08-06-1069-s35-fix-red.txt](2026-08-06-1069-s35-fix-red.txt)에 보존했다. 기존 화면 테스트는 EXPAND 저장 payload가 구성품만 보내고 `setHead`·`parentSetModel`·부모 productId를 보내지 않는 것을 재현했다.

## 구현 요약

- `BundleModePolicy.shouldExpand()`를 추가해 `KEEP`만 부모 1행으로 유지하고 `EXPAND`/`NULL`만 전개하도록 생산 입구 판정을 통일했다.
- 모바일 주문, 발행 공통 resolver 3경로, 견적→전표, 견적 revision 복원은 KEEP을 허용하고 EXPAND/NULL만 차단한다.
- 전표·견적·모바일 견적 전개 결과는 `componentKind == null`인 KEEP에 계보를 부여하지 않는다.
- EXPAND 화면 구성품은 `setHead`, `parentSetModel`, 부모 productId/입력단가, 옵션 문맥을 저장 payload에 전사한다.
- 서버는 이 계보를 `SlipLine`에 저장하고 head에서만 부모 `SOURCE_BUNDLE_SET` 가격기억을 수집한다. 구성품별 `SOURCE_LINE_SAVE`는 만들지 않는다.
- 기존 생성자 호환을 유지했고, 지연 응답 snapshot 비교 축은 변경하지 않았다.
