# #1021 거래처 원천 중복 조사

- 활성 거래처코드는 `partner_db` 7,259행/고유 7,259개, `dc_config_db` 210행/고유 210개이며 빈 코드는 양쪽 모두 0개다.
- 정규화 전 비교는 DB에 저장된 거래처코드 문자열의 완전 일치이며, 정규화 후 비교는 양끝 공백 제거 → ASCII 하이픈(`-`) 제거 → 앞 0 제거 순서다.
- ① 양쪽에 다 있는 거래처코드: 정규화 전 210개, 정규화 후 210개.
- ② `partner_db`에만 있는 거래처코드: 정규화 전 7,049개, 정규화 후 7,043개.
- ③ `dc_config_db`에만 있는 거래처코드: 정규화 전 0개, 정규화 후 0개.
- ④ `dc_config_db` 활성 210행 중 `partner_db`에 없는 행: 정규화 전 0건, 정규화 후 0건.
- 정규화로 `partner_db` 고유 코드는 7,259개에서 7,253개로 6개 줄었고, `dc_config_db` 고유 코드는 210개로 변하지 않았으나 양쪽 교집합과 `dc_config_db` 누락 수는 변하지 않았다.
- 판정: 정규화 전후 모두 ④가 0이므로, 거래처코드 기준으로 `dc_config_db.partners`의 활성 210건은 `partner_db.partners` 활성 원천의 부분집합이다.
