# #1091 버전이력 → 버튼·모달 · 카드 안 변경항목 접기 — 기획

## 개발책임자 결정
> "전표와 문서 내 버전이력의 경우 바로 노출하지 않고 '버전이력'이라는 버튼을 통해 모달로 보여주는 것으로
>  변경. 한꺼번에 있으므로 가독성이 떨어짐. **시간 순에 따라 내림차순.**"
> **모달 + 카드 안 변경항목도 함께 접기.**

## 착수 전 확정할 것 (구현자가 실측할 것)

1. **버전이력 패널을 쓰는 화면 전수** — 전표·견적·주문서 외에 또 있는가
   (`SlipVersionHistoryPanel` · `PartnerOrderVersionHistoryPanel` · 견적 쪽)
2. 각 패널의 **현재 정렬**이 내림차순인가 (결정 사항)
3. 카드 한 장의 **행 수 분포** — 이슈 실측(전표 CREATE 최대 78행 · 평균 14.1행)을 재현
4. 모달 컴포넌트는 design-system 것을 재사용 (자체 신규 작성 금지)

## 불변식 (수단은 구현자가 정한다)
- RED-A 버튼 → 모달로 버전이력 전체를 볼 수 있고 **시간 내림차순**이다
- RED-B 🚨 **복원·비교 등 기존 기능이 모달 안에서 그대로 동작**한다
  (오늘 `#1051` 에서 복원 관련 결함 2건이 나왔다 — 이 표면은 예민하다)
- RED-C 카드 안 변경항목 접기가 **기본 접힘**이고 펼칠 수 있다
- RED-D 세 화면(전표·견적·주문서) 모두 같은 규칙
