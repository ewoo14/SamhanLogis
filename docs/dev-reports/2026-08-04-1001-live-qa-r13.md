## 실 DB 발화 SQL

측정 전 동일 SQL을 실 DB에 실행하고 출력 원문을 아래에 append한다.

```sql
SELECT s.status, COUNT(DISTINCT s.id) AS 전표, COUNT(l.id) AS 라인,
       COALESCE(SUM(l.supply_amount + COALESCE(l.vat_amount,0)),0) AS VAT포함금액
FROM slips s LEFT JOIN slip_lines l ON l.slip_id=s.id AND l.is_deleted=false
WHERE s.is_deleted=false AND s.slip_type='OUTBOUND'
  AND s.status IN ('CONFIRMED','DELIVERED','COMPLETED','INSPECTING','SHIPPING')
GROUP BY 1 ORDER BY 1;
```
