## 도달 결함 1 — 화면의 `—`와 달리 VIRTUAL 수량을 복사하면 `0`이 나옴

### ① 사용자 조작 순서

1. `dev_manager`로 로그인한다.
2. `창고 운영 → 재고 현황`으로 이동한다.
3. 창고 필터에서 `가상창고`를 선택하고 `조회`를 누른다.
4. VIRTUAL 행의 `가용재고`, `예약재고`, `실재고` 세 셀을 선택하고 `Ctrl+C`를 누른다.
5. Excel 또는 메모장에 붙여넣는다.

### ② 기대

화면과 같은 수량 없음 의미가 유지되어 `—\t—\t—`가 복사되어야 한다. VIRTUAL은 실제 0재고가 아니라 “수량 개념 없음”이라는 이번 PR 계약이다.

### ③ 실제(원문)

실 배포 API VIRTUAL 행 원문:

```json
{"warehouseCode":"VR-001","warehouseType":"VIRTUAL","availableQty":0,"reservedQty":0,"totalQty":0,"version":null}
```

화면 원문은 세 셀 모두 `—`지만, 복사 경로는 `render`를 사용하지 않고 원시 필드를 `String(v)`로 바꾼 뒤 TSV를 쓴다. 따라서 붙여넣기 결과는 다음과 같다.

```text
0\t0\t0
```

브라우저 조작 연결은 이 세션에서 제공되지 않았지만, 실 배포 응답값과 production 복사 함수의 무조건 분기로 결과가 결정된다: `0` → `String(0)` → `navigator.clipboard.writeText(tsv)`. 즉 실제 화면에서 사용자가 실행할 수 있는 도달 경로이며 mock/테스트 가정이 아니다.
