1. **거래처코드 열이 실제 partnerCode가 아닌 사업자번호를 표시한다.** `/accounting/partner-ledger`에서 기간 조회 후 master row를 보면 열 제목은 `거래처코드`인데 값은 `1653510155` 등 bizNo 숫자다. 집계 API 응답의 `partnerCode`는 `P-2026-0005`이므로 화면 라벨/표시 계약 불일치다.
2. 실 GUI 각 화면 상단에 공통 `업데이트 실패: 업데이트에 실패했습니다...` 배너와 반복 React duplicate-key console warning이 나타났다. 원장 기능 자체는 렌더됐지만 라이브 QA 화면 품질 결함으로 기록한다.
