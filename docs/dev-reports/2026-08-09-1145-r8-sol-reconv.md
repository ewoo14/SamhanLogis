## 4. `master` 정규식 수정의 회귀

수정 전 `mock-account-master`는 정규식 미일치로 `MANAGER`, 수정 후 `MASTER` 매트릭스를 받는다. 122 page × 7 action을 전수 비교했다.

```text
수정 전 허용 → 수정 후 거부: 0 action bit
수정 전 거부 → 수정 후 허용: 151 action bit
권한 차이로 새로 막히는 화면: 0
```

따라서 코드/매트릭스 수준에서 차단 회귀는 없다. 다만 §5의 브라우저 부재 때문에 “실 GUI에서 막히는 화면 0”은 관측하지 못했으며, 위 0은 권한 비트 비교값으로만 한정한다.
