> 대상: PR #1168 / worktree `wdg1s3` / 기준 HEAD `0838d6e56`
> 
> 범위: `DocumentReferencePicker` 공통 경로, 그룹웨어 결재 작성·상세 화면. S4 화면·route·기존 라벨은 변경하지 않았다.

## 1. 결론

검색 결과를 `document.body`로 portal하고 `position: fixed`로 picker의 viewport 좌표에 배치했다. picker 본체의 `overflow-x: hidden`은 그대로 두어 부모 overflow를 전역 완화하지 않았다.

Playwright Chromium 실측은 DOM 존재나 자동 스크롤이 아니라 bounding box와 중앙점 hit-test를 모두 통과해야 하는 gate로 바뀌었고, 7개 문서 유형에서 `5 passed`, 모든 gate가 `inViewport: true`, `optionContainsHit: true`였다.

## 3. portal 설계와 좁은 overflow 해소

- `<ul role="listbox">`만 `createPortal(..., document.body)`로 이동했다. picker의 입력·select·layout은 기존 DOM 경계를 유지한다.
- dropdown은 `position: fixed`, `z-index: 1100`, viewport 좌우 8px inset, picker 폭 기준으로 배치한다.
- 아래 공간이 `160px`보다 작고 위 공간이 더 크면 위로 flip한다. 사용 가능한 공간으로 `max-height`를 제한하고 최대 `240px`로 둔다.
- `overflow-x: hidden`은 picker에 남아 있다. 따라서 다른 화면의 부모 overflow를 통째로 풀지 않았다.

## 4. portal이 만드는 3개 표면

| 표면 | 실제 처리 | 검증 |
|---|---|---|
| 뒤 화면 scroll | `window`뿐 아니라 picker의 computed `overflow/overflow-y`가 `auto·scroll·overlay`인 모든 조상에 직접 scroll listener를 등록한다. 실제 scroll owner는 `main.app-main`이었다. anchor가 viewport 밖으로 나가면 dropdown을 닫는다. | 하단에서 연 뒤 `main.app-main.scrollTop`을 변경하고 재배치/닫힘 정책을 확인. 최종 통과 |
| modal z-index | `rg`로 `DocumentReferencePicker` 소비자를 전수 확인한 결과 `GroupwareApprovalCreatePage`, `GroupwareApprovalDetailPage` 2곳뿐이며 둘 다 modal 내부 사용처가 아니다. 따라서 존재하지 않는 운영 modal을 만들어 검증하지 않았다. dropdown `1100`은 page content보다 높고 기존 lightbox `1200`, 전역 modal 계층 `9999`보다 낮다. | 두 실제 consumer route를 열어 확인. modal consumer 없음이 점검 결과 |
| 창 크기 변경·하단 열기 | `resize`, `visualViewport.resize`, `ResizeObserver`에서 좌표를 재계산한다. responsive reflow로 anchor가 viewport 밖으로 이동하면 닫는다. 충분한 위 공간이 있으면 bottom 대신 top을 사용한다. | 1280×480 하단 flip, 480×640 신규 open, 열린 상태 resize 조합 통과 |

## 5. 7유형 가시성 gate

모든 유형에서 click 전에 다음을 먼저 단정한다.

1. `toBeVisible()`
2. `getBoundingClientRect()`가 viewport 안에 있음
3. option 중앙점 `document.elementFromPoint()` 결과가 option 자신 또는 자손임
4. gate 통과 뒤에만 일반 `click()` 수행

`force`, 수동 `scrollIntoViewIfNeeded()` 후 click, DOM text-only 판정은 gate에 사용하지 않았다.
