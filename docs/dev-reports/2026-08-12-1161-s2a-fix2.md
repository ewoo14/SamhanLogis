## 최종 집계

Gradle XML의 깨진 한글 testcase name은 XML parser가 읽지 못해 정규식으로 집계했다.

```text
tests=183 failed=0 skipped=0 passed=183
```

별도: desktop typecheck passed, skipped 0, failed 0.

실제 격리 RabbitMQ는 Testcontainers `rabbitmq:3.13-management-alpine`에서 publisher worker → JSON converter → `samhan.audit.exchange` topic binding → 임시 queue 수신까지 통과했다. publisher가 없는 상태를 이용한 우회가 아니다.

구현 요점:

- Spring `ConnectionFactory` 주입 사용. 서비스 `spring.rabbitmq.*`가 연결 대상을 결정하며 localhost 고정 생성 제거.
- publisher bean은 pilot context에 항상 존재한다. CF/설정이 없으면 `[AUDIT_DISABLED]` WARN으로 눈에 띄게 비활성 상태를 알리고 서비스 업무 기동은 유지한다.
- RabbitTemplate에 `Jackson2JsonMessageConverter`를 명시 연결했다.
- partner-auth는 `X-Forwarded-For`를 감사 IP로 신뢰하지 않고 servlet peer 주소만 사용한다.
- 예외 handler 감사 이벤트는 실제 HTTP 400과 거부 사유를 `httpStatus/errorCode/errorSummary`로 보존한다.
- 기존 서비스별 감사 저장·durable queue argument·12개 비활성 원칙은 변경하지 않았다.

라운드 종료 확인: git 명령은 사용하지 않았으며, 변경 대상 추적 파일 8개와 보고서 파일은 모두 존재한다. git index 기반 삭제 목록은 사용자 금지 규칙 때문에 실행하지 않았고, 본 라운드에서 의도적으로 삭제한 파일은 없다.
