## 실행 경계와 증거 무결성

인앱 Browser 런타임이 `No browser is available`을 반환해 지시대로 Playwright Chromium을 사용했다. 현재 브랜치 renderer와 공유 gateway·서비스를 사용했으며 fixture·mock·응답 대체는 사용하지 않았다.

로그인은 `last_login_at`을 갱신하므로 호출하지 않았다. 공유 환경에 이미 설정된 JWT 서명 구성과 활성 MASTER 계정을 읽어 1시간짜리 로컬 QA 쿠키를 만들었고, 브라우저에서 gateway 대상 비-GET을 전부 차단했다. 저장·편집·복원·발송·전환 버튼은 누르지 않았다. DB 집계와 내부 식별자 확인은 모두 `BEGIN TRANSACTION READ ONLY`로 실행했다.

```text
브라우저 gateway 허용: GET / HEAD / OPTIONS
차단: POST /logs/front 5회
차단: 견적 collab presence join/leave 4회
공유 DB INSERT/UPDATE/DELETE/DDL: 0건
저장 버튼 클릭: 0회
```

## 9. 견적 목록·상세·중첩 line API UUID 비노출

실 GUI에서 발생한 견적 API 응답 본문 전체를 UUID 정규식으로 전수 검사했다. 실패 상세만으로는 line 응답을 검사할 수 없으므로, 직전 라이브QA에서 사용한 기존 비공개 식별 deep-link를 값 비공개 상태로 한 번 열어 성공 상세와 중첩 `lines`도 검사했다.

```text
UUID 정규식: [0-9a-f]{8}-[0-9a-f]{4}-[1-5][0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}

GET /slips/estimates?page=0&size=50       HTTP 200 | 18,297 bytes | UUID 0
GET /slips/estimates?page=0&size=10000    HTTP 200 | 18,303 bytes | UUID 0
GET /api/v1/estimates/web-snapshots       HTTP 200 |    783 bytes | UUID 0
클릭 상세 2026/08/10-9 응답              HTTP 500 |    128 bytes | UUID 0
기존 비공개 식별 deep-link 상세 응답      HTTP 200 |    913 bytes | UUID 0
성공 상세 data.lines 1건 전체 JSON                                 | UUID 0
```

**PASS.** 목록·상세·중첩 line 응답의 UUID는 0건이다. 단, 현재 문서번호 클릭 상세가 실패한다는 1번 결함과는 별개다.
