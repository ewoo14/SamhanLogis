## 1. 이 트랙이 "완전계승" 으로 삼는 것

개발책임자 확정 정의(2026-07-31):

> 완전계승이란 그 **기능 및 표현 데이터를 그대로 복사**한다는 뜻이나, 반드시 같은 디자인을 유지할 필요 없음. 우리 프로그램에 맞는 디자인 사용도 가능.

| 반드시 같아야 하는 것 | 달라도 되는 것 |
|---|---|
| 견적 **계산 규칙** — 단가 출처, 할인 적용 순서, 부가세 처리, 반올림 단계·자릿수 | 레이아웃 · 색 · 컴포넌트 |
| **표현 데이터** — 화면에 나오는 항목 · 값 · 집계 결과 | 그 항목을 어떻게 보여줄지 |

⚠️ **인쇄 양식**(전표 · 거래명세서 · 세금계산서)은 기존 규율대로 legacy 100% 매칭을 유지합니다. 위 디자인 자유는 **조회 · 분석 · 관리 화면**에만 적용됩니다.

## 2. 계승하지 않는 것 — **저장소가 바뀌었기 때문**

레거시는 견적을 **Notion 에 base64 로 압축 저장**했습니다. 우리는 **DB 에 저장**합니다.

⟹ 다음은 **계승 대상이 아닙니다.** 다시 만드는 것은 계승이 아니라 **퇴행**입니다.

- `compressString` / `decompressString` — base64 압축 **수단**
- `*Notion*` 계열 helper — 저장소가 Notion 이라서 필요했던 것

🔑 helper 를 **미대응 개수로 세지 않습니다.** 그것이 담은 **업무 규칙**으로 가릅니다.

| 질문 | 계승 여부 |
|---|---|
| **무엇을** 저장했는가 (필터 단어 · 거래처 코드 집합 · 분류 규칙) | ✅ 계승 |
| **어디에 어떻게** 저장했는가 (Notion · base64) | ❌ 아님 |

## 3. `견적서` 메뉴 사양 — 레거시보다 **개선**입니다

개발책임자 확정:

> `견적서` 메뉴의 경우 종합견적서에서 `견적저장` 시 DB(레거시는 base64 형태로 저장)의 역할을 하나, **현 GAS 와 달리 해당 견적서 목록에서 내가 수정 가능**(다른 사람들 것도 조회 가능).

| | 레거시 | 이번 |
|---|---|---|
| 저장 위치 | Notion (base64) | **DB** |
| 본인 견적 수정 | 불가 | **가능** |
| 타인 견적 조회 | — | **가능** |

⟹ 레거시에 없던 동작이므로 **계승 판정 대상이 아니라 신규 사양**입니다. 별도로 설계합니다.

## 4. 불변식

이 트랙이 완료 판정을 받으려면 **넷 모두** 참이어야 합니다.

| | 불변식 |
|---|---|
| **A** | 같은 입력에 대해 견적 **금액·할인·부가세·반올림 결과가 레거시와 같다** — 숫자로 대조 |
| **B** | `견적저장` 이 DB 에 저장되고, 목록에서 **본인 수정 · 타인 조회**가 동작한다 |
| **C** | 레거시 helper 가 담고 있던 **업무 규칙 데이터**(필터 단어 · 코드 집합 등)가 우리 쪽에 존재한다 |
| **D** | 🚨 **정상 경로가 막히지 않는다** — 기존에 발행되던 견적이 이 변경으로 거부되지 않는다. **실 데이터에서 몇 건이 막히는지 세어 확인한다** |

불변식 D 를 명시하는 이유: 이 저장소에서 **fix 가 결함이 아니라 정상 경로를 막은 사례가 최근 열 번** 나왔습니다(#984 정상 주문 3,489건 거부 · #996 25,000원 정상 주문 차단 · #994 재초대 차단 · #1007 `422` 로 정상 편집 차단 · #991 배포 전 키 replay 차단). 계산 규칙을 바꾸는 트랙은 특히 이 형태를 만들기 쉽습니다.

## 5. 착수 순서

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | **정찰** — 레거시 금액 산출 규칙 전수 추출 + 현행 대조 (`2026-08-01-1009-estimate-recon.md`) | 🔄 진행 중 |
| 2 | 대조 결과로 **갭 확정** — 같음 / 다름 / 확인불가 3분류, 다른 것은 양쪽 숫자 명시 | 대기 |
| 3 | 갭 구현 (계산 규칙 우선, 화면 나중) | 대기 |
| 4 | `견적서` 메뉴 신규 사양 (DB 저장 · 본인 수정 · 타인 조회) | 대기 |

**1단계를 끝내기 전에 구현에 들어가지 않습니다.** 무엇이 다른지 숫자로 확정되지 않은 상태에서 고치면, 이미 맞는 것을 바꾸게 됩니다.

## 6. 알려진 제약

- live 원본(`clasp` 사본)은 `.gitignore` 대상이며 **현재 로컬에 없습니다.** 이번 정찰은 **tracked 사본**(`tools/legacy-gas/종합견적서/Code.js`)을 근거로 합니다.
- tracked 사본은 3,204행, live 는 3,577행으로 알려져 있습니다. **차이분은 이 정찰이 보지 못한 범위**이며, 결과를 집계할 때 "0건" 으로 세지 않습니다.
- 레거시 `doGet` 이 `:10` 과 `:379` 에 **중복 정의**돼 있습니다 — 뒤의 정의가 이깁니다. 어느 쪽이 실제 동작인지 대조 시 유의합니다.
