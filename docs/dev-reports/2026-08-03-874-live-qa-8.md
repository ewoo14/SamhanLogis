## 1. 출고 상태 전이

대상 `2026/08/03-6` (slip id는 화면에 노출하지 않음), 계정 `dev_manager`.

| 현재 상태 | 화면 버튼 | 실제 호출 | 결과 |
|---|---|---|---|
| PROCESSING | `완료 (검수 시작)` | `POST /slips/{id}/complete` | 200, `INSPECTING` 전환 성공 |
| INSPECTING | `완료 (처리 완료)` | `POST /slips/{id}/complete` | **409** |

409 원문:

`전이 가능한 상태가 아닙니다: 현재 검수중, 필요 처리중`

BE 테스트/도메인 계약상 INSPECTING → COMPLETED는 `inspect`이며, FE 화면 버튼이 `complete`를 호출하는 정합성 결함이다. 직접 API 우회는 하지 않았으므로 이후 COMPLETED → SHIPPING → DELIVERED → CONFIRMED는 중단.

캡처: `docs/qa/874-riusage-global-dc-real-qa/01-processing-to-inspecting.png`, `02-inspecting-to-completed-409.png`
