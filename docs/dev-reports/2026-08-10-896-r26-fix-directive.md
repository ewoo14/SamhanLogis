### 분리할 것

- **업무 의미론 선택**: 활성 `AJ060MXHNBC1 -> SI-AL600A`에서 같은 실외기의 원형발통을 0으로 만드는 현재 계약은 R21의 “규칙 source 단독 legacy 기여 제거”와 일치하므로 결함으로 지시하지 않는다.
  - 대체 계약 유지: `SI-AL600A=1 · 발통세트=0`. 한 실외기에 평발과 원형발통이 중복되지 않고 현재 R21/R25 수렴 결과를 유지한다.
  - 가산 계약 선택: `SI-AL600A=1 · 발통세트=1`. “비소유 모델은 규칙 포함 전 순수 legacy 그대로”라는 문자 해석에는 맞지만 한 실외기당 발통이 두 세트가 되고, R21 source 기여 제거 계약을 다시 정의해야 한다.
  - 다만 어느 계약을 선택해도 **비규칙 실외기 `AJ040MXHNBC1=2`의 원형발통 2는 보존**되어야 한다. 현재 HEAD는 이 부분을 만족한다.
- 빈 `targets` 또는 빈 `sources`는 저장 API가 `QuantitySyncRuleValidator.java:212-214`에서 거부하므로 실 사용자 경로가 아니다. 이 라운드에서 malformed 응답 복구 정책을 별도 결함으로 지시하지 않는다.
- R24에서 이미 분리한 분기관 비가산성, HOME_MULTI 비노출 `SI-AL700a`, fixture 미존재 모델 3개, 모델 상수 하드코딩은 범위 밖이다.

## ② 불변식

1. 유효한 규칙이 실제 HOME_MULTI 주품목을 target으로 만들면, 그 최종 수량을 입력으로 하는 모든 홈 파생 계열 결과가 같은 사용자 계산 안에서 완결되어야 한다.
2. 같은 입력과 옵션에서 첫 계산·후속 계산·반복 계산의 최종 수량은 동일해야 한다.
3. 파생품 target은 자신의 품명 때문에 원시 source로 재유입되지 않아야 하지만, 실제 실내기·실외기 target의 정당한 downstream 기여는 사라지지 않아야 한다.
4. `enabled=false` 규칙은 규칙 0건과 수량 결과가 exact 동치여야 하며, 같은 응답의 활성 규칙 소비를 막지 않아야 한다.
5. 활성 발통 규칙은 선택된 대체/가산 업무 계약을 일관되게 따르되, 그 규칙 source가 아닌 실외기의 legacy 발통 기여·수동 잠금·옵션 결과를 바꾸지 않아야 한다.

## ③ 양방향 RED

### RED-A — 규칙 target의 역할별 downstream 고정점

- 실제 119행 카탈로그에서 `AJ020BN1PBC1=2 -> AJ040MXHNBC1=2` 규칙과 발통 포함 옵션을 한 번 계산하면 `AJ040MXHNBC1=2 · 발통세트=2`여야 하며, 2·3·5·7회에도 같아야 한다.
- 실제 `AIM-H04N=2 -> AJ020BN1PBC1=2` 규칙과 기존 `AJ040MXHNBC1=1`에서 첫 계산부터 호스 2·판넬 2·분기관1509 1이어야 하며, 후속 계산에도 같아야 한다.
- 같은 두 표본을 구현자가 사용하지 않은 계열 처리 순열 3개 이상으로 실행해도 첫 계산과 반복 결과가 모두 같아야 한다.

**RED-A 반대급부**

- 실제 파생품 규칙 `AJ060MXHNBC1=1 -> SI-AL600A=1`은 평발이 다시 실외기 source로 유입되어 원형발통을 만들면 안 된다. 대체 계약을 유지한다면 1·2·3·5·7회 모두 `SI-AL600A=1 · 발통세트=0`이어야 한다.
- 같은 표본에 비규칙 실외기 `AJ040MXHNBC1=2`를 더하면 1·2·3·5·7회 모두 `SI-AL600A=1 · 발통세트=2`여야 한다. 주품목 target을 살리는 과정에서 파생품 self-feed를 되살리거나, 반대로 전체 실외기 기여를 없애서는 안 된다.

### RED-B — 비활성 규칙의 완전한 무효성

- `AJ060MXHNBC1=1`에서 규칙 0건 결과와 동일 규칙 `enabled=false` 결과의 전체 `homeQty`가 exact 같아야 한다. 최소 관측값은 양쪽 모두 `SI-AL600A=0 · 발통세트=1`이다.
- 활성 `AIM-H04N=2 -> AXJ-YA1509N=2`와 비활성 발통 규칙을 함께 주입해도 활성 규칙 결과 `AXJ-YA1509N=2`와 순수 legacy `발통세트=1`이 유지되어야 한다.

**RED-B 반대급부**

- 동일 발통 규칙을 `enabled=true`로 바꾸면 규칙값이 실제 소비되어야 한다. 대체 계약에서는 단일 `AJ060MXHNBC1=1`이 `SI-AL600A=1 · 발통세트=0`이고, 비규칙 `AJ040MXHNBC1=2`를 함께 두면 `SI-AL600A=1 · 발통세트=2`여야 한다.
- 규칙 0건의 순수 legacy 전체 Map, 발통 제외 옵션, 다섯 계열 수동 잠금은 기존 결과와 exact 같아야 한다.

## ④ 범위 밖

- 활성 발통 규칙을 대체로 볼지 가산으로 볼지에 대한 업무 결정 자체. 위 두 선택지와 대가만 기록하며 구현 방향은 PM·개발책임자가 결정한다.
- 분기관 비가산성, `SI-AL700a` 노출 정책, fixture 미존재 모델, 모델 상수 하드코딩.
- 주문 앱, quantity-sync 스키마 전면 재설계, DB seed 생성, malformed 직접 SQL 데이터 복구.
- Docker 재배포·서비스 재시작·브라우저 라이브 QA.
