## 1. R3 BLOCK과 레거시 원문 대조

`docs/dev-reports/2026-08-03-874-r3-reconvergence.md`의 BLOCK을 먼저 재현했다. Q형 수량이 `(used=1,total=2)`이고 sibling REMOTE가 `(1,1)`이면 현행은 REMOTE를 `false`, 레거시는 `true`로 만들었다.

레거시 원문은 두 자리를 분리한다.

| 원문 | 의미 | 현행 반영 |
|---|---|---|
| `tools/legacy-gas/일마감 프로그램/Code.js:697-700` | 부속의 `hasFailedMain`은 `INDOOR` 또는 `OUTDOOR`이고 usage 미완료인 행만 검사 | `isFailedMain()`은 `INDOOR/OUTDOOR`만 반환 |
| `Code.js:702-707` | 부속 자신이 완전 소비되면 먼저 `true`; 그 뒤 failed main이면 `false`; 그 밖은 가격 fallback | 부속 자신 완전 소비를 먼저 `true`, 그 다음 failed main, 마지막 `null` |
| `Code.js:709-710` | `INDOOR/OUTDOOR/SUB_INDOOR` 자기 행은 usage 완전 소비 여부 | `isMain()`은 세 kind를 유지 |

따라서 `SUB_INDOOR`는 자기 행 판정의 main 집합에는 남기고, sibling 부속을 거짓으로 만드는 failed-main 집합에서는 제거했다.

## 3. 구현과 권위

### 3.1 교차 판정

`RiUsageDecision`에 판정 집합을 분리했다.

- `isMain`: `INDOOR`, `OUTDOOR`, `SUB_INDOOR` — 자기 행 완전 소비 판정.
- `isFailedMain`: `INDOOR`, `OUTDOOR` — 부속의 `hasFailedMain` 교차 검사.
- 부속 자기 usage가 완전하면 failed-main 검사보다 먼저 `true`.
- 자기 usage 미완료이며 failed main이 있으면 `false`.
- main이 없으면 `true`.
- main은 있으나 모두 완전하고 자기 usage가 미완료면 `null`로 기존 가격 판정 유지.

### 3.2 계열 sweep 보완

`LegacyModelKindClassifier`를 `Code.js:190-211`과 대조했다.

- `Code.js:190`: `PC -> PANEL` 추가.
- `Code.js:192`: `^A[CP]\d{3}`로 수정하여 `AC`와 `AP` 모두 처리.
- `Code.js:193-196`: 7번째 문자 `N/X`를 각각 `INDOOR/OUTDOOR`로 유지.
- `Code.js:198-203`: AR 12번째 문자 `N/X/Q` 규칙 유지.
- `Code.js:205-210`: AF 12번째 문자 `N/X` 규칙 유지.

카탈로그 권위 경계는 R2와 동일하다. 카탈로그가 `PANEL`, `REMOTE`, `INDOOR`, `OUTDOOR` 등 구체 kind를 주면 재분류하지 않는다. 카탈로그가 generic `ACCESSORY`이고 레거시 결과가 `INDOOR/OUTDOOR/SUB_INDOOR`일 때만 레거시 결과를 `riUsage` main 입력으로 사용한다. generic `ACCESSORY`의 레거시 `PANEL`, `REMOTE`, `MATERIAL` 결과는 `ACCESSORY`로 유지한다.

## 5. 불변식 및 변경 행 측정

### 5.1 부속 교차 범위 양방향

`[DEV-SEED/단위 fixture]` Q partial `(1/2)` + sibling REMOTE complete `(1/1)`에서 fix 전 `확인=false`, fix 후 `확인=true`로 **1행 변경**했다. 레거시 `hasFailedMain`이 Q를 보지 않고, REMOTE 자신은 완전 소비됐으므로 `true`여야 한다.

`[DEV-SEED/단위 fixture]` Q partial `(1/2)` + sibling REMOTE incomplete `(0/1)`에서는 REMOTE가 `false`를 유지한다. 이 행은 레거시 failed-main 범위에 `INDOOR/OUTDOOR`가 있으면 거짓이어야 하는 경로다. `SUB_INDOOR`를 failed-main에서 제거하면서 이 정당한 차단을 제거하지 않았다.

`[실데이터/로컬 read-only]` R3의 active catalog sweep에서 Q 모델 8종·67 links, Q와 PANEL/REMOTE/MATERIAL sibling을 가진 모델 8종이 확인됐다. 현재 `accounting_db` 모델 보유 원천은 tax invoice 0행/22행, sales slip 0행/0행이므로 영속 응답의 fix 전후 변경 행은 **0행 관측**이다. 0행은 규칙 정확성의 증거가 아니라 모델 보유 전표 데이터 부재다.
