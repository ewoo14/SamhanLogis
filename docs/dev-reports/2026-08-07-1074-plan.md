1. 출고일을 잠근 **이유**를 코드·주석·과거 PR 에서 찾아라. 잠금이 다른 계약을 지키고 있으면 그것도 지켜야 한다
2. 마감 규칙 전수 — `REGION` 12:00 외에 `STACK` 14:00 등 **네 출고구분 전부** 같은 구조인지
3. 마감 후 실제로 몇 건이 막히는지 실 데이터로 세라 (표본 0 이면 만들 수 있는지도)
