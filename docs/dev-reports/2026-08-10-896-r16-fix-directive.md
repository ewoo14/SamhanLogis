# PR #1126 R16 fix 지시서 — 규칙 소비 재수렴·실 카탈로그 발통 누락

## ① 좌표

- `clients/web/estimate-app/public/quantitySync.js:23-70` — 유효한 `HOME_MULTI` 규칙의 source 수량을 target 수량으로 계산한다.
- `clients/web/estimate-app/views/index.ejs:8393-8422` — evaluator 결과를 `homeQty`에 적용하고 규칙 소유 target 집합을 반환한다.
- `clients/web/estimate-app/views/index.ejs:8442-8458` — 규칙 적용 뒤 호스·리모컨·판넬을 무조건 레거시 계산으로 재수렴해, 방금 적용한 target 수량을 다시 지울 수 있다.
- `clients/web/estimate-app/views/index.ejs:4516-4525,8444-8450` — 분기관·발통 계열 소유 여부를 네 모델 상수로만 판정한다. 회사 PC 활성 `HOME_MULTI` 실측은 분기관 2개(`AXJ-YA1509N`, `AXJ-YA2512N`)와 발통 2개(`발통세트`, `SI-AL600A`)이며, `SI-AL600A`는 열거에 없다.
- `clients/desktop/src/renderer/routes/EstimateItemsCatalogPage.tsx:1004-1032,1153-1159` — 사용자가 실제 품목을 검색해 source별 target을 활성 규칙으로 저장하는 진입점이다. UI 저장값은 `factor=1`, `multiplier=1`이다.

현재 재현값은 모두 회사 PC 활성 `HOME_MULTI`에 노출된 실 모델 코드로 구성했다.

```text
source AJ020BN1PBC1=2 · 옵션 기본/비제외 · multiplier=1

계열     규칙 target       evaluator   최종 target   최종 레거시 대체품
호스     FH-LFHLN                 2             0   FH-LFHLF=2
판넬     PC6NUDK1NW               2             0   PC1NWSK3NW=2
리모컨   AWR-WE13N                2             0   AR-EC05=2

source AJ060MXHNBC1=2 · target SI-AL600A · 발통포함=false
evaluator=2 · 최종 SI-AL600A=2
```

실 카탈로그 확인 명령:

```powershell
docker exec samhan-postgres psql -U samhan -d product_db -P pager=off -F "|" -Atc "SELECT p.model_code,p.name,p.status,p.product_category,e.estimate_category FROM products p JOIN product_estimate_exposure e ON e.product_id=p.id AND e.is_deleted=false WHERE p.is_deleted=false AND p.status='ACTIVE' AND e.estimate_category='HOME_MULTI' AND (p.name ~* '(분기관|발통|일자발)' OR p.model_code ~* '^(AXJ-YA|SI-AL)') ORDER BY p.model_code;"
```

## ② 불변식

1. 품목 메뉴에서 저장되어 서버가 유효한 활성 규칙으로 반환한 target은, 화면 옵션이 그 계열을 제외하지 않은 상태에서 최종 수량 계산에 관찰 가능한 규칙 값을 남겨야 한다.
2. 화면 옵션의 우선권은 그 옵션이 명시한 제외·치환 계약에 한정되어야 하며, 같은 옵션 갈래에 속한 유효 target을 하드코딩된 다른 모델 매핑으로 조용히 대체해서는 안 된다.
3. 화면 옵션과 양립할 수 없는 target을 활성 규칙으로 취급하면서 최종 결과에서 조용히 0으로 만드는 상태가 있어서는 안 된다.
4. `발통포함=false`의 제외 계약은 현재 활성 `HOME_MULTI` 카탈로그에 실제로 노출되는 모든 비수동 발통 품목에 동일하게 적용되어야 한다.
5. 규칙 0건의 순수 레거시 exact 결과와 수동 수량 잠금은 바뀌지 않아야 하며, 옵션이 계열을 제외하지 않을 때의 규칙 소비도 함께 살아 있어야 한다.

## ③ 양방향 RED

### RED-A — 옵션 우선권이 필요한 방향

- `AJ020BN1PBC1=2`, target `FH-LFHLN`, `유연호스 제외=true`이면 최종 비수동 호스 수량은 0이어야 한다.
- 같은 source, target `PC6NUDK1NW`, `판넬제외`이면 최종 비수동 판넬 수량은 0이어야 한다.
- 같은 source, target `AWR-WE13N`, `리모컨 제외`이면 최종 비수동 리모컨 수량은 0이어야 한다.
- `AJ060MXHNBC1=2`, target `SI-AL600A`, `발통포함=false`이면 최종 `SI-AL600A=0`이어야 한다. 현재 HEAD는 2다.

### RED-B — RED-A의 반대급부: 규칙 소비 유지

- `AJ020BN1PBC1=2`, target `FH-LFHLN`, `유연호스 제외=false`·L형 갈래이면 최종 `FH-LFHLN=2`가 남아야 한다. 현재 HEAD는 0이다.
- 같은 source, target `PC6NUDK1NW`, 기본 판넬 갈래이면 최종 `PC6NUDK1NW=2`가 남아야 한다. 현재 HEAD는 0이다.
- 같은 source, target `AWR-WE13N`, 기본 리모컨 갈래이면 최종 `AWR-WE13N=2`가 남아야 한다. 현재 HEAD는 0이다.
- `AJ060MXHNBC1=2`, target `SI-AL600A`, `발통포함=true`이면 최종 규칙 계산값 2가 남아야 한다.
- 규칙 0건의 기존 estimate fixture 65개는 직전 production 소스와 exact diff 0이어야 하고, 분기관·발통 수동 잠금값 77은 옵션·규칙 재계산 뒤에도 77이어야 한다.
