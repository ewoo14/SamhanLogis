### 13. API 응답 UUID 0건 — 결함 재현

제품 상세 화면을 실제로 열어 발생한 응답 중 아래 상세 API에서 audit UUID가
노출됐다.

```text

COUNT=2
00000000-0000-0000-0000-000000000001
00000000-0000-0000-0000-000000010001

```

한 응답에 UUID 필드 2개가 있으며, 전체 GUI 시나리오에서 이 상세 응답이 반복돼

결함이 아니라 동일한 상세 응답 표면의 반복 노출이다. 함께 호출된 아래 5개

