## 환경·스택 이상 관찰

- PM 배포 컨테이너는 재빌드·재기동하지 않았다. QA 종료 후 내가 기동한 로컬 renderer `127.0.0.1:5175`만 종료했고, gateway/slip/accounting/partner 컨테이너는 건드리지 않았다.
- 최초 로컬 준비에서 `clients/desktop` 의존성과 `@samhan/design-system/dist`가 없어 웹 renderer가 500을 냈다. lockfile 의존성 설치·디자인 시스템 build 후 실제 Electron renderer로 전환해 QA를 완료했다. 서비스 배포나 DB 변경은 없었다.
- 실제 Electron renderer의 일반 부팅 중 `app-version` 403, `app-notice` 500, `activity-log` 503 콘솔 오류가 반복됐으나 로그인·거래처 원장 화면은 렌더됐다. 이 이상은 수정하지 않았다.
- code-only `QA-GATE-A` 행을 클릭한 상세 조회는 HTTP 422 오류 배너가 나타났다. 오류 화면은 `07-uuid-hidden.png`에 남겼다.
- `인쇄 미리보기` 버튼 클릭 후 새 창이 열리지 않았다. 인쇄 양식 검증을 다른 경로로 대체하지 않았다.
