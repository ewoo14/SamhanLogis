## 4. `tools/`·`scripts/` 계열 전수

`tools/`와 `scripts/`의 PowerShell 파일을 `Join-Path` 축으로 전수 검색했다.

| 분류 | 결과 | 판정 |
|---|---|---|
| `operational-validation.ps1` 항목 4 | 4개 호출 모두 괄호로 독립 문자열 생성 | 결함 없음 |
| `scripts/lib/local-stack-port.ps1:24-26` | 배열 안에 독립적인 `Join-Path` 3개 | 배열을 `ChildPath`로 전달하지 않음 |
| `scripts/lib/qa-shots-dir.ps1:173` | `foreach`에서 단일 `$part`를 전달 | 정상 |
| `scripts/repair-flyway-checksums.ps1:151` | 중첩 호출의 각 호출이 단일 child path | 정상 |
| 그 밖의 `tools/`·`scripts/` 호출 | 단일 `ChildPath` 인자 | 정상 |

쉼표가 같은 소스 라인에 있는 검색 결과도 확인했으며, 나머지는 반환 배열의 다른 값, 주석/문자열, 또는 독립 배열 원소였다. `Join-Path`에 배열 또는 다중 `ChildPath`를 넘기는 추가 소스는 발견되지 않았다.
