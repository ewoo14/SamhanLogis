## 확인 3 — 원인 추적

- `performSearch`가 결과 1건을 받으면 `resultSelectionMode === 'multiple'`에서 `onResultsConfirmed?.(results)`만 호출한 뒤 즉시 `return`한다.
- 이 분기에는 `open=false`, `status='idle'`, 검색 후보 초기화가 없어 `open=true`와 `status='loading'`이 유지된다.
- 2건 이상 모달 분기는 기존에 일부 상태를 정리하지만, 모달 확인·취소 공통 콜백인 `closeSelection`은 `selectionOpen`과 후보만 정리하고 검색 표면(`open/status/searchState/error`)을 보장하지 않는다.
- 따라서 즉시 확정·모달 확정·모달 취소·Esc를 하나의 상태 정리 계열로 다루는 것이 결함의 근본 원인에 맞다.
