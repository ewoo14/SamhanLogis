## 6. 실행 중 경로 진단

인앱 Browser binding은 `No browser is available`, 목록 `[]`였지만 이는 `clients/desktop/node_modules/playwright` Chromium 실행 가능 여부와 무관했다. standalone Playwright Chromium은 정상 실행됐다.

초기 스크립트는 `vite.web.config.ts`의 BrowserRouter에 HashRouter URL(`/#/chat`)을 사용해 대시보드에 남았다.

```text

```

진단 probe에서 `/chat` 사용 시 `CHAT_URL http://127.0.0.1:42375/chat`과 `채팅 / 새 대화`가 확인됐다. 이어 로그인 helper의 hash 기반 완료 조건도 pathname 기반으로 바로잡았다. 변경 대상은 `C:\Temp\liveqa894\liveqa.cjs`뿐이며 저장소 구현 코드는 변경하지 않았다.
