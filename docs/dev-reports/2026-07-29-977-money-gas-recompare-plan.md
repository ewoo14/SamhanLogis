# #977 금액 계열 GAS 전수 재대조 — 기획 (조기 PR)

> 연관 Issue: #977

## 왜 하는가

`tools/legacy-gas/**` 는 SP-08 동등성 검증의 **정답지**다. PR #974 가 이 정본을 Drive 라이브에서 갱신하며 대조 보고서를 함께 남겼는데, 그 **§4 요약이 실제보다 크게 축소돼 있었다.**

`거래처 발송 주문서/index.html` 은 unified diff 가 **501줄**이었는데 §4 는 *"버튼 라벨 간소화 · 분기계산 라벨 · CSS 보강"* 으로만 적혀 있었다. 실제로는 금액에 직접 닿는 변경이 **최소 4건** 있었고, 그중 하나가 아래 연쇄를 만들었다.

```text
저장소 정본이 ACL-KORGHP06 으로 낡음
  → order-app 이 낡은 값을 따라감
    → 카탈로그에 06 이 없어 find() 가 undefined
      → if(!row) return; 으로 에러 없이 스킵
        → 골든이 C-08 = {} 로 "아무 품목도 안 나옴" 을 정답으로 고정
          → 6,710,000원 품목이 GHP 주문마다 누락
```

**1개를 파 보니 4건이 나왔다. 나머지는 안 파 봤다.**

개발책임자 결정 ③(*"금액에 닿는 프로젝트만 골라 돌릴지"*)에 대해 **PM 이 금액 계열 우선으로 결정**했다. 전체 24개가 아니라 아래 4개다.

## 판정 기준

1. PR #974 의 unified diff 를 **전수** 확인한다. **요약을 믿지 않는다** — 요약이 축소돼 있었다는 것이 이 조사의 출발점이다
2. 각 변경이 **단가 · 모델코드 · 기준일 · 비율 · 임계값 · 품목 코드 하드코딩** 중 하나에 닿는가
3. 제품(`order-app` / `estimate-app` / `services`)에 대응 구현이 있는가, **낡은 값과 새 값 중 어느 쪽을 따르는가**
4. `if(!row) return;` 계열을 **파일명이 아니라 단정 내용으로 전수** 센다

## 이 트랙의 격리 조건

다른 트랙 4개가 동시에 돌고 있다. 이 트랙은 **읽기 전용**으로 못박았다.

- **코드 수정 0** — 산출물은 보고서뿐이다. `clients/web/order-app/**` 은 #987 트랙이 쓰고 있다
- **Docker·DB·`services/**` 빌드 금지** — #984 #985 트랙이 공유 스택을 쓰고 있어, 건드리면 그쪽 검증이 무효가 된다

도달 가능 결함이 나오면 **그때 정밀 경로로 승격**하고 별도 라운드에서 고친다.
