## 수정 내용

1. DIRECT 방을 shell로 먼저 `saveAndFlush`한 뒤 참여자를 저장해 FK 순서를 보장했다. 참여자 ID는 수동 UUID를 제거하고 JPA UUID 생성에 맡겨 detached merge를 방지했다.
2. `pg_advisory_xact_lock` native repository 반환형을 `Long`에서 `void`로 변경했다. V21 sequence와 unique 제약은 변경하지 않았다.
3. PostgreSQL Testcontainers IT의 Hikari pool을 test-only 5로 제한해 10개 Spring context가 `max_connections`를 넘지 않게 했다. production datasource는 변경하지 않았다.
4. 방 생성·메시지 발송 mutation 실패를 사용자 문구로 화면에 표시하고 개발자 예외 원문은 노출하지 않게 했다.
5. user-service 내부 단건 직원 응답에 `departmentName`, `ecountCode`를 추가해 groupware profile API와 화면까지 전달되게 했다.
