# #999 S2a 품목리스트 모달 라이브 QA — CODEX SOL

## 결론

**실 사용자 경로에서 재현되는 결함: 0건.**

`재고관리 → 품목코드 010001 클릭 → 품목리스트 모달`을 Playwright Chromium으로 실행했다. 화면 데이터 자리에 `?`는 나타나지 않았다.

## 증거 무결성

- 공유 DB에는 쓰지 않았다. `inventory_db`와 한글 검증용 `partner_db`를 `pg_dump -Fc` 파일로 덤프한 뒤 격리 PostgreSQL `sol999-pg-20260812224109`에 `pg_restore`했다.
- 현재 브랜치의 `inventory-service.jar`를 격리 DB에 연결해 실행했고 Flyway V26, V27을 복제본에만 적용했다.
- GUI의 인증, 권한, 재고 현황 첫 목록은 격리 응답으로 고정했다. 검증 대상인 `GET /inventory/instances/product-list`와 `PATCH /inventory/instances/quality`는 모두 격리 서비스 `http://127.0.0.1:41885`에 실제 왕복했다.
- 인앱 Browser 런타임은 `[]`였으나 실행 불가로 판정하지 않고 저장소 설치본 `@playwright/test`의 Chromium을 사용했다.

복제 직후 한글 확인 원문:
