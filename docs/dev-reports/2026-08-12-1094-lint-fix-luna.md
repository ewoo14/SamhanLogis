## 수정 전 원문과 동작

### `clients/desktop/src/renderer/routes/EstimateListPage.tsx:122`

```tsx
    for (const [key, value] of Object.entries(values)) value ? next.set(key, value) : next.delete(key)
```

각 검색 조건을 순회하면서 값이 있으면 해당 URL query parameter를 설정하고, 빈 값이면 기존 parameter를 삭제해 검색 상태를 주소창과 동기화합니다.

### `clients/desktop/src/renderer/routes/SalesPartnerOrderListPage.tsx:113`

```tsx
    for (const [key, value] of Object.entries(values)) value ? next.set(key, value) : next.delete(key)
```

각 주문 목록 검색 조건을 순회하면서 값이 있으면 해당 URL query parameter를 설정하고, 빈 값이면 기존 parameter를 삭제해 검색 상태를 주소창과 동기화합니다.

## 수정 내용

두 줄의 조건부 부수효과 표현을 동작이 동일한 명시적 `if/else` 문으로 변경했습니다. 빈 검색어 제거, 검색어 유지, URL replace 동작은 그대로 보존합니다.

### Before

```tsx
for (const [key, value] of Object.entries(values)) value ? next.set(key, value) : next.delete(key)
```

### After

```tsx
for (const [key, value] of Object.entries(values)) {
  if (value) next.set(key, value)
  else next.delete(key)
}
```
