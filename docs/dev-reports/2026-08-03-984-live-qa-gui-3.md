## 결함

- [P1] 임포트 `product_code=010004`가 품목 조회/자동완성 계약에 보존되지 않음.
- 재현: `GET http://127.0.0.1:8080/api/products?q=010004&size=20&page=0` → HTTP 200이지만 `totalElements=0`; 동일 데이터의 모델명 `AR09TXEAAWKNEU-04` 검색은 1건이며 응답 `productCode`도 `AR09TXEAAWKNEU-04`임.
- 영향: 품목 목록에서 요구된 품목코드 `010004`로 검색·표시할 수 없고, ①의 품목코드 표시 판정이 실패함. 모델명 기반 자동완성·선택만 정상.
