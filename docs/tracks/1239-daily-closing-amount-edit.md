# 트랙 #1239 — 일마감 금액 편집 + 양방향 할인율 동기화

## 확정 (개발책임자 2026-08-16 Ⓒ축 ②)

> 레거시처럼 **사람이 완료를 각인**할 수 있고, **검증 예외를 고를 수 있게** 한다.
> 현행은 상태 전이가 규칙으로만 일어나고 예외를 고를 버튼이 없다.

## 불변식

```text
누가 · 언제 · 왜 예외를 줬는지 남는다
  유연성을 여는 대신 추적이 없으면 금액 검증이 무력해진다
자동 전이를 없애는 것이 아니다 — 수동 각인이 그 위에 얹히는 것이다
일마감 가격검증 예외(할인제외 정액DC 0원 · 멀티 할인율 미적용)도 이 축이다
```

## 양방향 할인율 동기화

금액을 고치면 할인율이, 할인율을 고치면 금액이 따라간다.

```text
한쪽만 RED 로 검증하면 반대 방향이 깨진 채로 통과한다 — 양방향 RED 를 쓴다
반올림 자리가 왕복에서 보존되는지 확인한다 (한 자리만 달라도 청구액이 달라진다)
```

## 완료 조건

편집 → 저장 → 재조회 왕복 GUI 스크린샷 + 예외 각인 기록이 남은 것을 보인 실측 원문.
