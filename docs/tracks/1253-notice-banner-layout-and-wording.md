# 트랙 #1253 — 상단 알림 배너가 화면을 밀어낸다 + 용어 변경

## 개발책임자 보고 (2026-08-16 실사용)

> "상단 신뢰 루트 설치 문구로 인해 전체 화면이 아래로 밀리는 상황이 계속 발생.
> 그리고 신뢰 루트라는 표현은 이해하기 어려우므로 보안인증서로 변경요망."

## 실측 위치

```text
clients/arologis-desktop/.../common/AppVersionGate.tsx:196-204   trustRootNotice
clients/web/design-system/.../AppUpdateNotice.stories.tsx:43-44
```

배너가 `versionPolicyNotice` · `statusNotice` 와 함께 본문 앞에 **문서 흐름으로** 렌더되어
아래 콘텐츠 전체를 밀어낸다. 삼한 데스크톱 일마감 화면의
`업데이트 서버에 연결하지 못했습니다` 배너도 같은 계열이다.

## 불변식

- 배너 유무와 관계없이 **본문 첫 요소의 좌표가 같다**
- 알림은 여전히 **눈에 띄어야 한다** — 안 보이게 숨기는 것은 해결이 아니다
- 사용자에게 보이는 「신뢰 루트」 문구를 전부 「보안인증서」로 바꾼다 (제목·설명·버튼)
- 내부 식별자(`testId` · 함수명 · 타입 `trustRoot*`)는 바꾸지 않는다 — 회귀 위험만 늘린다
- 인쇄 시 배너가 나오지 않던 동작(`no-print`)을 잃지 않는다

## 완료 조건

배너 有/無 두 상태의 GUI 스크린샷 + 본문 첫 요소 좌표 동일 실측.
