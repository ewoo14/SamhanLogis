# 트랙 #1234 — 레거시 CSV(Notion) 전체 적재

## 확정 (개발책임자 2026-08-16 아침 ②)

```text
확정   누락 92코드 + drift 43코드/67필드를 **한 번에** 적재한다
정본   CSV(Notion)
```

Ⓒ축 ① 과 충돌하지 않는다 — CSV 는 **이관을 마저 끝내는 원천**이고,
적재가 끝나면 **DB 가 정본**이다. 적재 후 CSV 를 다시 보지 않으며 원천 추종 구조도 만들지 않는다.
