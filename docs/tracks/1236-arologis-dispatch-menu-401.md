# 트랙 #1236 — 아로로지스 배차 하위 메뉴가 안 뜬다 (menu-catalog 401)

## 확정 (개발책임자 2026-08-16)

> 아로로지스 401 → **게이트웨이에 열쇠를 준다**

선택지 6개 중 이 방향으로 확정. 프런트가 토큰을 흉내내거나 인증을 우회하는 방향이 아니다.

## 증상

```text
아로로지스 배차 화면에서 하위 메뉴가 렌더되지 않는다
원인   menu-catalog 호출이 401
```

## 불변식

- 게이트웨이가 정당한 자격으로 menu-catalog 를 호출한다 — 인증 우회·익명 허용이 아니다
- 자격은 **환경변수**에서만 온다. 코드·설정 파일에 평문 금지
  (실측 사고: 자격이 휘발성 셸 환경에만 있어 재기동 시 전부 날아갔다 → `infrastructure/.env.local` 에 남긴다)
- 다른 서비스의 mesh 를 깨지 않는다 — compose 가 `:?required` 로 요구하는 키가 늘면 `.env.local` 도 함께 갱신
- 401 이 해소된 뒤 **하위 메뉴가 실제로 보이는 것**까지가 완료다 (200 응답만으로는 부족)

## 완료 조건

실서버에서 아로로지스 배차 하위 메뉴가 펼쳐진 GUI 스크린샷.
