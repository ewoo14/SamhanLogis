# 트랙 #1240 — 외부 도메인 TLS 주체 불일치 + 주문서웹 504

## 증상

```text
외부 도메인   TLS 인증서 주체가 실제 호스트와 불일치
주문서웹      504 — 거래처가 주문을 보내지 못한다
```

**거래처가 실제로 막혀 있는 경로**다. 도달성 기준으로 최우선.

## 개발책임자 확정 (2026-08-16)

> 외부 도메인 → **제가 고치기까지**

## 불변식

- 인증서 검증을 끄거나 우회하는 방향은 fix 가 아니다
- 504 는 어느 홉에서 나는지 **실측으로 특정**한다 (프록시 / 게이트웨이 / 업스트림) — 추정 금지
- 자격·인증서 경로는 환경변수/볼륨으로만. 코드에 평문 금지
- 다른 서비스 mesh 를 깨지 않는다 — compose `:?required` 키가 늘면 `.env.local` 도 함께 갱신
- 고친 뒤 **외부에서 실제로 주문이 접수되는 것**까지가 완료다

## 완료 조건

외부 도메인 TLS 검증 통과 원문 + 실제 주문 접수 성공 GUI 스크린샷.
