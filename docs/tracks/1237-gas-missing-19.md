# 트랙 #1237 — GAS 격차 '없음' 19개 업무 구현

## 확정 (개발책임자 2026-08-16)

> "내가 필요없다고 한 GAS는 빼고 나머지는 모두 누락된 기능이라든지 결과 표시방식이
> 모두 동등해야해. UI디자인을 그대로 따라갈 필요는 없어."

```text
동등해야 하는 것   기능 · 결과 표시방식
                   (금액 포맷·반올림 자리 · 항목 분류 · 정렬 축 · 합계 산출 · 라벨 의미)
동등할 필요 없음   UI 디자인 (배치 · 색 · 폰트 · 버튼 위치)
제외               에어디자이너 · 제이시스템 OCR
```

판정 단일 질문: **"사용자가 그 화면을 보고 내리는 판단이 달라지는가"**

## 범위

'없음'(현행에 기능 자체가 부재) 19개 — 그중 **금액에 닿는 7개**를 먼저 낸다.

확정 결정은 **프로그램 단위**다. 같은 용어라도 종합견적서 / 주문서웹 / 배차의 규칙이 다르다.
결정을 인용하기 전에 그 결정의 근거 원문이 어느 프로그램 파일인지 확인한다.
(실측 사고: "운임·절삭은 제외 대상이 아니다" 는 종합견적서 결정인데 주문서웹에 적용해 되돌렸다)
