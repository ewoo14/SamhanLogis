# 트랙 #1243 — 발송내역에서 삭제된 원본을 취소선·회색으로 남긴다

## 배경 (실측)

`docs/dev-reports/2026-08-16-send-history-snapshot-semantics.md`

```text
종합견적서 발송내역   live join · 주문 변경이 현재값으로 반영 · soft delete 시 행이 사라짐
주문서웹 발송내역     동일
실데이터              확정 1,994건 중 활성 4건 · 삭제로 숨은 기록 1,990건
                      CREATE 스냅샷 대비 내용 불일치 4건 (활성 주문 3건 포함)
```

## 확정 (개발책임자 2026-08-16)

> "soft delete 시 발송내역에서 아예 사라지게 보다는 취소선으로 회색처리 하면 좋을 것 같아."
> "발송 내역은 원본을 지우면 원래 사라지는게 맞잖아."
> "아니 원래는 사라지는게 맞는데 live join이라서 지금은 취소선으로 바꾼다는거지."

```text
레거시   발송내역은 원본을 지우면 사라지는 게 맞다
현행     live join 이라 역시 사라진다  ⟹ 이 점에서는 레거시와 동등
확정     그럼에도 취소선 + 회색으로 남기는 쪽으로 바꾼다
         = 파리티 fix 가 아니라 레거시보다 나은 쪽으로의 의도적 이탈
```

## 불변식

- 삭제된 원본의 발송 기록이 **목록에서 사라지지 않고** 취소선 + 회색으로 보인다
- 이 예외는 **발송내역 조회 경로에서만** 적용한다 — 다른 목록/집계의 soft delete 필터를 풀지 않는다
- 삭제행은 **복원·재발송 등 조작 대상이 아니다** (누르면 안 되거나 명확히 막힌다)
- 삭제 여부가 **데이터에 실려야 한다** — 프런트가 추측하지 않는다
- 금액 합계·건수 집계가 삭제행 때문에 달라지지 않는다
  (달라진다면 그것이 의도임을 화면이 말해야 한다)
