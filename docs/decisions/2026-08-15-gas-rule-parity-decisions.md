## ① 선결제 할인 — **레거시가 맞다. 표기만 바꾼다** (견적서 R-04)

```text
레거시   선결제를 골라도 금액은 그대로. 결제 표기만 바뀐다
현행     음수 할인행을 더해 견적 총액이 내려간다
확정     레거시 쪽. 견적 총액은 그대로 두고 결제방법만 표시한다
```

🔑 **할인은 수금·정산 단계에서 처리한다.** 견적서가 미리 깎아 두면 실제 수금액과 어긋난다.

### 🚩 구현 시 주의

```text
현행 음수 할인행을 제거해야 한다 — "설정이 0이면 안 뜬다" 로 끝내지 마라
   설정에 값이 들어가 있으면 다시 깎인다
기존 견적서에 이미 붙은 할인행을 어떻게 할지 확인이 필요하다
```

## ② 구제품 할인율 · 카드 수수료 — **설정 유지 · 레거시 값으로 맞춤** (견적서 R-01 · R-03)

```text
레거시   구제품 할인율 0.5 · 카드 수수료 3% 를 코드 상수로 고정
현행     운영 설정값을 따른다 (설정이 다르면 견적가가 달라진다)
확정     구조는 설정 기반 그대로 두고, 현재 설정값이 0.5 / 3% 인지 확인해 다르면 맞춘다
```

🔑 **요율이 바뀔 때 배포가 필요 없는 구조를 지킨다.** 다만 지금 값이 레거시와 같아야 한다.

### 🚩 구현 시 주의

```text
현재 설정값을 먼저 읽어 보고 보고할 것 — 이미 0.5 / 3% 면 변경 없음
설정이 비어 있을 때 무엇이 되는지도 확인해야 한다
   레거시는 항상 0.5 / 3% 였다. 현행이 "설정 없으면 0" 이면 금액이 달라진다
```
