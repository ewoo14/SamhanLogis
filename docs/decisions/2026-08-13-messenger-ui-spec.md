지시 원문을 그대로 구조화한 것입니다. **추론해서 채운 곳은 없습니다.** 안 적힌 것은 아래 §4 에 질문으로 남깁니다.

## 1. 상단 전환 — `개별` / `그룹별`

**좌측 상단에 버튼 2개.** 이 둘로 페이지를 바꿉니다.

```
┌──────────────────────────────┐
│ [개별] [그룹별]              │   ← 좌측 상단
├──────────────────────────────┤
│ (선택된 페이지 내용)          │
└──────────────────────────────┘
```

## 2. `개별` 페이지

```
┌──────────────────────────────────────┐
│ [개별] [그룹별]                       │
├──────────────────────────────────────┤
│ ● 나          홍길동    부장          │   ← 내 상태 아이콘 · 이름 · 직책
├──────────────────────────────────────┤
│ ● 김대표      김대표    대표          │   ← 대표부터
│ ● 이이사      이이사    이사          │   ← 직급 순
│ ○ 박부장      박부장    부장          │
│ ● 최과장      최과장    과장          │
│ …                                     │
└──────────────────────────────────────┘
```

### 규칙

```
① 대표부터 시작해 직급별로 정렬한다
② 각 직원은 상태 아이콘 + 이름 + 직책 으로 표시한다
③ 내 정보(상태 아이콘·이름·직책)가 직원 리스트 위에 온다
④ 직원을 클릭하면 말을 걸 수 있고, 그때 대화창이 생성된다
⑤ 🚨 대화 기록은 보존한다
```

### 접속 상태 아이콘

> **데스크탑이든 모바일이든 하나 이상 접속 시 아이콘이 `접속` 으로 나온다.**

⟹ 기기별로 따로 보여 주지 않고, **어느 기기든 하나라도 붙어 있으면 접속**입니다.

## 3. `그룹별` 페이지

```
┌──────────────────────────────────────┐
│ [개별] [그룹별]                   🔍  │   ← 우측 상단 돋보기
├──────────────────────────────────────┤
│ ● 나          홍길동    부장          │   ← 개별과 동일하게 내 정보가 위
├──────────────────────────────────────┤
│ 영업2팀 단톡방                    ③   │   ← 안읽음 먼저
│ 회계 마감 공유방                  ①   │
│ 물류 배차                             │   ← 그 다음 최신순 내림차순
│ 개발팀                                │
│ …                                     │
└──────────────────────────────────────┘
```

### 규칙

```
① 내 상태 아이콘·이름·직책이 위에 온다 (개별 페이지와 동일)
② 그 아래는 카카오톡 단톡방 리스트처럼 보인다
③ 안읽은 메시지 숫자를 카카오톡처럼 표시한다
④ 🚨 정렬 — 안읽음이 먼저, 그 다음은 최신순 내림차순
⑤ 어떤 단톡방인지 알 수 있게 나온다
```

### 우측 상단 돋보기 🔍

```
클릭 → 모달
        · 검색
        · 복수 선택
        · 단톡방 생성
```

## 4. 🔴 추가 결정 (2026-08-13, 실측 위에서 결정)

### 실측 — 지금 있는 데이터

```
user_db.employees
  job_title          대표 · 전무 · 이사 · 부장 · 차장 · 과장 · 주임 · 사원 · 개발자
                     🚩 순서표가 없다. 그냥 문자열이고 '개발자' 는 직급이 아니라 직무다
  is_team_lead       팀장 여부 (boolean)
  department_id      부서
  termination_date   퇴사일
auth_db.accounts
  enabled            계정 활성 여부
```

### 결정 1 — 직급 순서표를 **새로 만든다**

```
대표 > 전무 > 이사 > 부장 > 차장 > 과장 > 주임 > 사원
직급이 아닌 직무('개발자' 등)는 맨 뒤
```

🔑 **한 곳에만 정의**해 순서가 바뀌면 그 한 곳만 고치면 되게 합니다.
🚩 위 목록에 없는 `job_title` 이 나오면 **지어내지 말고** 맨 뒤로 보내고 보고하십시오.

### 결정 2 — 상태 아이콘은 **S4 부재중까지 한 번에**

```
접속 · 자리비움 · 부재중 · 오프라인
```

- **접속** — 데스크탑이든 모바일이든 **하나 이상 접속** 시
- **자리비움** — 자동 판정
- **부재중** — 사용자가 직접 설정
- **오프라인** — 접속 0

⟹ **S4(부재중)가 이 단계로 들어옵니다.** 화면을 두 번 고치지 않기 위한 결정입니다.

⏳ *자리비움 자동 전환의 기준 시간*은 아직 안 정해졌습니다. §5 참조.

### 결정 3 — 퇴사자·비활성 계정은 **목록에서 숨긴다**

```
숨김 조건   employees.termination_date 가 있거나 accounts.enabled = false
🚨 단, 이미 있는 대화방과 기록은 그대로 보존한다 — 과거 대화를 읽을 수 있어야 한다
```

### 결정 4 — 단톡방 표시는 **이름 있으면 이름, 없으면 참여자 나열**

카카오톡과 같은 방식입니다.

```
방 이름이 있으면    그 이름을 쓴다
없으면              참여자 이름을 나열한다
참여자가 많으면      "홍길동, 김철수 외 3명" 처럼 줄인다
```

## 5. ⏳ 아직 안 정해진 것

**지어내지 않고 남깁니다.**

```
① 동일 직급 안에서의 정렬 — 이름순인가, 입사순(hire_date)인가
② 개별 페이지에서 이미 대화 기록이 있는 직원의 표시
   마지막 메시지·안읽음 수를 함께 보여 주는가, 이름·직책만 보여 주는가
③ 자리비움 자동 전환의 기준 시간 (몇 분 무입력이면 자리비움인가)
```
