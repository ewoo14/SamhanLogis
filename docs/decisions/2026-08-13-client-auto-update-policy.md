## 결정별 의미와 그에 따라 바뀌는 것

### 1. 강제 즉시 설치 — 현행 유지

적대검증이 `1-1`(아로로지스가 작업 중 강제 종료)·`1-9`(삼한이 stall 시 최대 180초 로그인 차단)를 결함으로 올렸으나, **버전 파편화를 막는 것이 우선**이라는 판단이다.

⟹ **이 둘은 결함이 아니라 의도된 동작이다.** 게이트 ①에서 제외한다.

🚩 다만 화면 문구가 동작과 어긋나는 것은 **여전히 결함**이다.
```
아로로지스 화면의 "나중에" 버튼은 배너만 닫고 자동 설치를 취소하지 않는다
  AppVersionGate.tsx:157-168
⟹ 누를 수 있는데 아무 효과가 없다. 문구/버튼을 실제 동작에 맞출 것.
```

### 2. 사내 메신저 업데이트 경로 신설

서버 enum · `V8` · 관리자 목록에는 있는데 앱에 `electron-updater` 의존성, `/app/version` 호출, updater IPC, UI 가 **전부 없다**. 관리자가 릴리스를 등록·배포해도 사용자는 아무 안내를 못 받는다.

⟹ 다른 Electron 앱(삼한 데스크톱 · 아로로지스 데스크톱)이 이미 쓰는 경로를 그대로 이식한다. **새 방식 발명 금지.**

### 3. `allowDowngrade=true`

두 Electron 앱 모두 현재 `false` 라 장애 버전 배포 시 updater 로 되돌릴 수 없다.
```
삼한 auto-update.ts:68-71 · 아로로지스 auto-update.ts:60-62
```
⟹ 둘 다 `true` 로. 사내 메신저 신설분도 같은 설정.

🚨 **강제 즉시 설치(결정 1)와 함께 걸리면 주의가 필요하다** — 서버 최신 버전을 낮추면 사용자가 자동으로 즉시 다운그레이드된다. 그것이 이 결정의 목적이지만, 실수로 낮은 버전을 게시하면 전체가 즉시 내려간다는 뜻이기도 하다.

1-7  모바일 3앱이 OTA 완료 시 작업 중 즉시 reload (조건부 — EAS 활성 시)
