## 결정 1 — `#1162`: **rotation 을 먼저 하고, 머지는 그 후**

### 배경 — 조사가 오탐보다 큰 것을 찾았다

`#1162` 의 GitGuardian FAILURE 자체는 **근거가 확인된 false positive** 였다(env key 이름을 값으로 오인 — [`2026-08-13-1162-gitguardian-recon.md`](../dev-reports/2026-08-13-1162-gitguardian-recon.md)).

그러나 같은 조사에서 별개의 것이 나왔다.

```
PR 이 소스에서 삭제한 13자 개발 스택 공통 비밀번호
PR 이 소스에서 삭제한 28자 내부 서비스 토큰
  → 현재 실행 중인 컨테이너 값과 exact match
  → origin/main 과 2026-05-04 이후 git 이력에 평문 존재
  → ensure-local-env.ps1:121~124 는 실행 컨테이너가 있으면 기존 값을 재사용
```

⟹ **머지만으로는 노출된 자격이 폐기되지 않는다.** 오히려 새 gitignored `.env` 로 **승계**된다.

### 🔴 결정

> **rotation 을 먼저 실행하고, `#1162` 머지는 그 후에 한다.**

노출된 값이 실제로 죽어야 이 PR 이 의도한 보안 이득이 성립한다. 소스에서 문자열이 사라지는 것만으로는 아무것도 폐기되지 않는다.
