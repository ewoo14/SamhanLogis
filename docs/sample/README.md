# 양식 샘플 드롭 폴더

레거시 양식 이미지(출고전표/거래명세서 등)를 여기에 넣으면 Claude 가 양식 재현 작업에 사용합니다.

⚠️ **이 폴더의 파일은 git 에 커밋되지 않습니다** (`.gitignore` — README 제외 전체 무시).
샘플에 실거래처명·전화번호·주소·계좌번호 등이 포함되는데 본 repo 는 **public** 이므로
원본은 로컬에만 두고, 재현 mock 은 익명화 데이터로 `docs/qa/<slice>/mocks/` 에 작성합니다.

- 양 PC 간 공유가 필요하면 카톡/드라이브 등 외부 채널 사용 (git 경유 금지)
- 작업 완료된 샘플은 `.claude/tmp/` 로 옮겨 보관해도 됨 (동일하게 비커밋)
