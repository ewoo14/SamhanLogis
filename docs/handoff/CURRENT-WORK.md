## 0. 🚨 집PC 에서 가장 먼저 할 것

### 🔥 최우선 — 이름 파싱을 버리고 **세트 구성품** 기반으로 (D11)

개발책임자 정정: *"이름 기준으로 파싱할 게 아니라 **세트이므로 세트 구성품을 보게 해야 함.
그 구성품대로 받침이 들어가야**."*

**착수 전에 이것부터 세십시오** (회사PC 는 Docker API 오류로 못 쟀습니다):

```sql
WITH paren AS (
  SELECT p.id FROM products p
  JOIN classification c ON c.id=p.cat_l_id AND c.is_deleted=false
  WHERE p.is_deleted=false AND p.name LIKE '%(%' AND p.name LIKE '%HP%'
    AND c.estimate_category='COMMERCIAL_MULTI')
SELECT (SELECT COUNT(*) FROM paren) AS 괄호표기,
       (SELECT COUNT(DISTINCT b.bundle_product_id) FROM bundle_component b
          JOIN paren ON paren.id=b.bundle_product_id WHERE b.is_deleted=false) AS 구성품있음;
```

```text
구성품이 다 있다      → D11 대로 구성품 기반 규칙
구성품이 없거나 일부  → 🚨 D11 을 그대로 실행 불가. 개발책임자께 올릴 것
                        🚫 이름 파싱으로 되돌아가지 말 것 — 기각된 방식이다
```

### ① 홈멀티 리모컨 `기본` 은 `무선` 이 아니다

```js
// index.ejs:8252-8267
if (opt === '기본') {
```
