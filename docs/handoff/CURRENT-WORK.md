**PM 권고 순서**

```

D  서버 BundleExpander · 데스크톱 정합
```

🚫 **A·B 없이 C 부터 하면 안 됩니다.**

## 이 세션에서 굳힌 절차

### 🚨 식별자·경로·필드명을 바꾸면 **의존 측 전수 표**를 요구한다

같은 실수를 네 번 했습니다 — 전부 한 모양입니다.

```
resolveQaShotsDir   파일에 "있는지" 만 확인   ·  모든 경로 상수 경유 미확인
partnerCode         write 축만 확인          ·  read 축 미확인
multiselect testid  고친 지점만 확인         ·  소비자 미확인
Option 타입         고친 파일만 확인         ·  같은 타입 쓰는 테스트 미확인
```

**"고친 곳" 은 봤는데 "그것에 의존하던 곳" 은 안 봤습니다.** 넷 다 CI 가 찾았습니다.

### 🚨 QA 증거 커밋 전 확인 2줄

```bash
grep -nE "path\.(join|resolve)\([^)]*docs/qa" <spec> | grep -v resolveQaShotsDir   # write 면 격리 필요
git check-ignore -v <캡처 경로>                                                     # _local 이면 커밋 안 됨
```

오늘 `_local` 로 증거가 날아갈 뻔한 것이 **다섯 번**이었습니다(과거 라운드 10개 포함 소급 회수 완료).
