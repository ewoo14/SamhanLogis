# 입금 트랜잭션 목록 목업

대상 화면: `CashReceiptListPage`  
경로: `/accounting/admin/cash-receipts`

---

## 1. 레이아웃

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 회계 관리자 / 현금 입금                                      [새로고침]     │
├──────────────────────────────────────────────────────────────────────────────┤
│ [거래처명 ________] [전표번호 ________] [구분 ▼ 전체] [기간 ____ ~ ____] [검색] │
│ 적용 필터: 전표번호: SLP-202605                         [초기화]            │
├──────────────────────────────────────────────────────────────────────────────┤
│ 전표번호        거래처        구분        거래일       금액        연결 분개번호 │
│ SLP-202605-021  삼한공조      입금보고서  2026-05-19   2,480,000   JRN-202605-49 │
│ SLP-202605-017  한빛상사      수기 입금   2026-05-18     760,000   JRN-202605-45 │
│ SLP-202605-011  세진산업      통장연계    2026-05-15     510,000   -             │
├──────────────────────────────────────────────────────────────────────────────┤
│ 총 84건 · 50건씩 보기                                   처음 이전 1 2 다음   │
└──────────────────────────────────────────────────────────────────────────────┘
```

현금 지출 화면과 같은 패턴을 사용해 사용자가 두 화면을 전환해도 필터와 표 위치가 바뀌지 않게 한다.

---

## 2. 필터

| 필터 | 입력 방식 | 동작 |
|---|---|---|
| 거래처명 | 텍스트 | `partnerName` 부분 일치 |
| 전표번호 | 텍스트 | `slipNo` 정확 또는 부분 일치 |
| 구분 | 선택 | 전체 / 입금보고서 / 수기 입금 / 통장연계 |
| 기간 | 날짜 범위 | `transactionDate` 기준 |

---

## 3. 컬럼

| 컬럼 | 데이터 | 표시 규칙 |
|---|---|---|
| 전표번호 | `slipNo` | 링크, UUID 표시 금지 |
| 거래처 | `partnerName` | 18자 이후 말줄임 |
| 구분 | `kind` | CashReceiptKind badge. `DEPOSIT_REPORT`=`입금보고서`, `MANUAL_RECEIPT`=`수기 입금`, `BANK_LINKED`=`통장연계` |
| 거래일 | `transactionDate` | `YYYY-MM-DD` |
| 금액 | `amount` | 우정렬, 천 단위 쉼표 |
| 연결 분개번호 | `journalNo` | 값 없으면 `-` |

---

## 4. 상태

- 빈 결과: `조건에 맞는 입금 자료가 없습니다.` + `필터 초기화`
- 오류: `입금 자료를 불러오지 못했습니다.` + `다시 시도`
- 권한 없음: `현금 입금 화면을 볼 권한이 없습니다.`
- 로딩: 표 skeleton 8행, 마지막 검색 조건 chip은 유지한다.
