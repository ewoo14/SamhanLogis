# 주문서 상세 목업

대상 화면: `OrderDetailPage`  
경로: `/accounting/admin/orders/{orderNo}`

---

## 1. 레이아웃

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 회계 관리자 / 주문서 / ORD-202605-041                         [목록으로]   │
├──────────────────────────────────────────────────────────────────────────────┤
│ 주문번호 ORD-202605-041        진행상태 [진행 중]     주문일 2026-05-18     │
│ 거래처 삼한공조                매니저 김영수           연결 전표 SLP-202605-018 │
├──────────────────────────────────────────────────────────────────────────────┤
│ 품목명                    규격          수량      단가        공급가액       │
│ 냉난방기 실외기           SH-ODU-20      2     850,000     1,700,000       │
│ 설치 부자재               기본형         1     180,000       180,000       │
│ 배송비                    수도권         1      60,000        60,000       │
├──────────────────────────────────────────────────────────────────────────────┤
│ 합계 수량 4                         공급가액 1,940,000     부가세 194,000 │
│ 총액 2,134,000                                                             │
└──────────────────────────────────────────────────────────────────────────────┘
```

상단 요약은 2행 grid로 유지한다. 주문번호, 거래처, 매니저, 연결 전표번호는 복사 가능한 텍스트로 제공한다.

---

## 2. 진입과 탐색

- 목록의 `orderNo` 또는 행 클릭으로 진입한다.
- `목록으로` 버튼은 이전 필터와 페이지를 유지한다.
- 상세 경로의 표시값은 `orderNo`이며 UUID를 노출하지 않는다.

---

## 3. 상세 필드

| 영역 | 데이터 | 표시 규칙 |
|---|---|---|
| 주문번호 | `orderNo` | 헤더와 요약 모두 표시 |
| 거래처 | `partnerName` | 업무 명칭 |
| 매니저 | `managerName` | 이름 |
| 진행상태 | `progressStatus` | OrderProgressStatus badge. `DRAFT`=`초안`, `CONFIRMED`=`확정`, `IN_PROGRESS`=`진행 중`, `COMPLETED`=`완료`, `CANCELLED`=`취소` |
| 연결 전표 | `linkedSlipNo` | 없으면 `-` |
| 라인 | `lines[]` | 품목명, 규격, 수량, 단가, 공급가액 |

---

## 4. 상태

- 빈 라인: `주문 품목이 없습니다.` 단, 주문 요약은 유지한다.
- 오류: `주문서 상세를 불러오지 못했습니다.` + `다시 시도`
- 권한 없음: `이 주문서를 볼 권한이 없습니다.`
- 찾을 수 없음: `주문번호에 해당하는 주문서가 없습니다.` + `목록으로`
