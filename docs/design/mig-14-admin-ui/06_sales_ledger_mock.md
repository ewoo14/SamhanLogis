# 매출 원장 목업

대상 화면: `SalesLedgerPage`  
경로: `/accounting/admin/ledger/sales`

---

## 1. 레이아웃

```
┌────────────────────────────────────────────────────────────────────────────────────┐
│ 회계 관리자 / 매출 원장                                           [새로고침]        │
├────────────────────────────────────────────────────────────────────────────────────┤
│ [거래처명 ________] [전표번호 ________] [기간 ____ ~ ____] [대조결과 ▼ 전체] [검색] │
│ 적용 필터: 대조결과: 차이                                          [초기화]        │
├────────────────────────────────────────────────────────────────────────────────────┤
│ 전표번호        거래처       매출일       원장금액      결산금액       차이     대조결과 │
│ SLP-202605-018  삼한공조     2026-05-18  1,250,000    1,250,000        0     일치 │
│ SLP-202605-014  한빛상사     2026-05-16    760,000      750,000   10,000     차이 │
│ SLP-202605-008  세진산업     2026-05-13    510,000            -        - 결산 없음 │
├────────────────────────────────────────────────────────────────────────────────────┤
│ 총 156건 · 50건씩 보기                                      처음 이전 1 2 3 4 다음 │
└────────────────────────────────────────────────────────────────────────────────────┘
```

DailyClosing 대조가 핵심이므로 `원장금액`, `결산금액`, `차이`, `대조결과`를 우측에 묶어 배치한다.

---

## 2. 필터

| 필터 | 입력 방식 | 동작 |
|---|---|---|
| 거래처명 | 텍스트 | `partnerName` 부분 일치 |
| 전표번호 | 텍스트 | `slipNo` 부분 일치 |
| 기간 | 날짜 범위 | 매출일 기준 |
| 대조결과 | 선택 | 전체 / 일치 / 차이 / 결산 없음 |

---

## 3. 컬럼

| 컬럼 | 데이터 | 표시 규칙 |
|---|---|---|
| 전표번호 | `slipNo` | 링크, UUID 표시 금지 |
| 거래처 | `partnerName` | 18자 이후 말줄임 |
| 매출일 | `ledgerDate` | `YYYY-MM-DD` |
| 원장금액 | `rawTotal` | 우정렬 |
| 결산금액 | `closingTotal` | 없으면 `-` |
| 차이 | `diff` | 0이면 muted, 양수/음수는 강조 |
| 대조결과 | `reconcileStatus` | 상태 badge |

---

## 4. 상태

- 빈 결과: `조건에 맞는 매출 원장이 없습니다.` + `필터 초기화`
- 오류: `매출 원장을 불러오지 못했습니다.` + `다시 시도`
- 권한 없음: `매출 원장을 볼 권한이 없습니다.`
- 로딩: 표 skeleton 8행, 대조결과 chip 영역은 유지한다.
