# 매출 원장 목업

대상 화면: `SalesLedgerPage`  
경로: `/accounting/admin/ledger/sales`

---

## 1. 레이아웃

```
┌────────────────────────────────────────────────────────────────────────────────────┐
│ 회계 관리자 / 매출 원장                                           [새로고침]        │
├────────────────────────────────────────────────────────────────────────────────────┤
│ [거래처명 ________] [거래참조 ________] [기간 ____ ~ ____] [변환상태 ▼ 전체] [검색] │
│ 적용 필터: 변환상태: 제외                                          [초기화]        │
├────────────────────────────────────────────────────────────────────────────────────┤
│ 거래참조        거래처       매출일       원장금액      결산금액       차이     변환상태 │
│ SLP-202605-018  삼한공조     2026-05-18  1,250,000    1,250,000        0     변환완료 │
│ SLP-202605-014  한빛상사     2026-05-16    760,000      750,000   10,000     대기 │
│ SLP-202605-008  세진산업     2026-05-13    510,000            -        -     제외 │
├────────────────────────────────────────────────────────────────────────────────────┤
│ 총 156건 · 50건씩 보기                                      처음 이전 1 2 3 4 다음 │
└────────────────────────────────────────────────────────────────────────────────────┘
```

DailyClosing 대조가 핵심이므로 `원장금액`, `결산금액`, `차이`, `변환상태`를 우측에 묶어 배치한다.

---

## 2. 필터

| 필터 | 입력 방식 | 동작 |
|---|---|---|
| 거래처명 | 텍스트 | `partnerName` 부분 일치 |
| 거래참조 | 텍스트 | `transactionRef` 부분 일치 |
| 기간 | 날짜 범위 | 매출일 기준 |
| 변환상태 | 선택 | 전체 / 대기 / 변환완료 / 제외 |

---

## 3. 컬럼

| 컬럼 | 데이터 | 표시 규칙 |
|---|---|---|
| 거래참조 | `transactionRef` | 링크, UUID 표시 금지 |
| 거래처 | `partnerName` | 18자 이후 말줄임 |
| 매출일 | `ledgerDate` | `YYYY-MM-DD` |
| 원장금액 | `rawTotal` | 우정렬 |
| 결산금액 | `closingTotal` | 없으면 `-` |
| 차이 | `diff` | 0이면 muted, 양수/음수는 강조 |
| 변환상태 | `transformStatus` | `PENDING`=`대기`, `TRANSFORMED`=`변환완료`, `REJECTED`=`제외` badge |

---

## 4. 상태

- 빈 결과: `조건에 맞는 매출 원장이 없습니다.` + `필터 초기화`
- 오류: `매출 원장을 불러오지 못했습니다.` + `다시 시도`
- 권한 없음: `매출 원장을 볼 권한이 없습니다.`
- 로딩: 표 skeleton 8행, 변환상태 chip 영역은 유지한다.
