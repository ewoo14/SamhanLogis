# 주문서 목록 목업

대상 화면: `OrderListPage`  
경로: `/accounting/admin/orders`

---

## 1. 레이아웃

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 회계 관리자 / 주문서                                         [새로고침]     │
├──────────────────────────────────────────────────────────────────────────────┤
│ [주문번호 ________] [거래처명 ________] [매니저명 ________] [진행상태 ▼ 전체] [검색] │
│ 적용 필터: 진행상태: 진행 중  매니저: 김영수                      [초기화]  │
├──────────────────────────────────────────────────────────────────────────────┤
│ 주문번호        거래처       매니저   진행상태   연결 전표번호   주문일     │
│ ORD-202605-041  삼한공조     김영수   진행 중    SLP-202605-018  2026-05-18 │
│ ORD-202605-036  세진산업     박민지   확정       -               2026-05-17 │
│ ORD-202605-029  대한물류     김영수   완료       SLP-202605-013  2026-05-16 │
├──────────────────────────────────────────────────────────────────────────────┤
│ 총 203건 · 50건씩 보기                              처음 이전 1 2 3 4 5 다음 │
└──────────────────────────────────────────────────────────────────────────────┘
```

행 클릭 시 주문 상세로 이동한다. 이동 후 상세 헤더에는 주문번호를 크게 표시하고 내부 식별자는 표시하지 않는다.

---

## 2. 필터

| 필터 | 입력 방식 | 동작 |
|---|---|---|
| 주문번호 | 텍스트 | `orderNo` 부분 일치 |
| 거래처명 | 텍스트 | `partnerName` 부분 일치 |
| 매니저명 | 텍스트 | `managerName` 부분 일치 |
| 진행상태 | 선택 | 전체 / 초안 / 확정 / 진행 중 / 완료 / 취소 |

---

## 3. 컬럼

| 컬럼 | 데이터 | 표시 규칙 |
|---|---|---|
| 주문번호 | `orderNo` | 링크, UUID 표시 금지 |
| 거래처 | `partnerName` | 18자 이후 말줄임 |
| 매니저 | `managerName` | 이름 그대로 표시 |
| 진행상태 | `progressStatus` | OrderProgressStatus badge. `DRAFT`=`초안`, `CONFIRMED`=`확정`, `IN_PROGRESS`=`진행 중`, `COMPLETED`=`완료`, `CANCELLED`=`취소` |
| 연결 전표번호 | `linkedSlipNo` | 값 없으면 `-` |
| 주문일 | `orderDate` | `YYYY-MM-DD` |

---

## 4. 상태

- 빈 결과: `조건에 맞는 주문서가 없습니다.` + `필터 초기화`
- 오류: `주문서 목록을 불러오지 못했습니다.` + `다시 시도`
- 권한 없음: `주문서 관리 화면을 볼 권한이 없습니다.`
- 로딩: 표 skeleton 8행, 페이지네이션은 숨긴다.
