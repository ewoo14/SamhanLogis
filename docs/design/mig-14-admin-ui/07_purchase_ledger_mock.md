# 매입 원장 목업

대상 화면: `PurchaseLedgerPage`  
경로: `/accounting/admin/ledger/purchase`

---

## 1. 레이아웃

```
┌────────────────────────────────────────────────────────────────────────────────────┐
│ 회계 관리자 / 매입 원장                                           [새로고침]        │
├────────────────────────────────────────────────────────────────────────────────────┤
│ [거래처명 ________] [거래참조 ________] [기간 ____ ~ ____] [변환상태 ▼ 전체] [검색] │
│ 적용 필터: 거래처: 대한물류  기간: 2026-05-01 ~ 2026-05-31          [초기화]        │
├────────────────────────────────────────────────────────────────────────────────────┤
│ 거래참조        거래처       매입일       원장금액      결산금액       차이     변환상태 │
│ SLP-202605-013  대한물류     2026-05-16    320,000      320,000        0     변환완료 │
│ SLP-202605-010  동해운송     2026-05-14     88,000       90,000   -2,000     대기 │
│ SLP-202605-006  제일상사     2026-05-11    145,000            -        -     제외 │
├────────────────────────────────────────────────────────────────────────────────────┤
│ 총 112건 · 50건씩 보기                                      처음 이전 1 2 3 다음   │
└────────────────────────────────────────────────────────────────────────────────────┘
```

매출 원장과 동일한 구조를 사용한다. 사용자는 탭 또는 사이드바에서 매출/매입을 전환해도 컬럼 위치를 동일하게 인지할 수 있어야 한다.

---

## 2. 필터

| 필터 | 입력 방식 | 동작 |
|---|---|---|
| 거래처명 | 텍스트 | `partnerName` 부분 일치 |
| 거래참조 | 텍스트 | `transactionRef` 부분 일치 |
| 기간 | 날짜 범위 | 매입일 기준 |
| 변환상태 | 선택 | 전체 / 대기 / 변환완료 / 제외 |

---

## 3. 컬럼

| 컬럼 | 데이터 | 표시 규칙 |
|---|---|---|
| 거래참조 | `transactionRef` | 링크, UUID 표시 금지 |
| 거래처 | `partnerName` | 18자 이후 말줄임 |
| 매입일 | `ledgerDate` | `YYYY-MM-DD` |
| 원장금액 | `rawTotal` | 우정렬 |
| 결산금액 | `closingTotal` | 없으면 `-` |
| 차이 | `diff` | 0이면 muted, 양수/음수는 강조 |
| 변환상태 | `transformStatus` | `PENDING`=`대기`, `TRANSFORMED`=`변환완료`, `REJECTED`=`제외` badge |

---

## 4. 상태

- 빈 결과: `조건에 맞는 매입 원장이 없습니다.` + `필터 초기화`
- 오류: `매입 원장을 불러오지 못했습니다.` + `다시 시도`
- 권한 없음: `매입 원장을 볼 권한이 없습니다.`
- 로딩: 표 skeleton 8행, 페이지네이션은 조회 완료 후 표시한다.
