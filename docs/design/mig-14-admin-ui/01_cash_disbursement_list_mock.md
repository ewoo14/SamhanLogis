# 지출 트랜잭션 목록 목업

대상 화면: `CashDisbursementListPage`  
경로: `/accounting/admin/cash-disbursements`

---

## 1. 레이아웃

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 회계 관리자 / 현금 지출                                      [새로고침]     │
├──────────────────────────────────────────────────────────────────────────────┤
│ [거래처명 ________] [전표번호 ________] [구분 ▼ 전체] [기간 ____ ~ ____] [검색] │
│ 적용 필터: 거래처: 삼한공조  기간: 2026-05-01 ~ 2026-05-31      [초기화]     │
├──────────────────────────────────────────────────────────────────────────────┤
│ 전표번호        거래처        구분   거래일       금액        연결 분개번호 │
│ SLP-202605-018  삼한공조      지출   2026-05-18   1,250,000   JRN-202605-44 │
│ SLP-202605-013  대한물류      지출   2026-05-16     320,000   JRN-202605-39 │
│ SLP-202605-009  동해운송      지출   2026-05-14      88,000   JRN-202605-31 │
├──────────────────────────────────────────────────────────────────────────────┤
│ 총 128건 · 50건씩 보기                                  처음 이전 1 2 3 다음 │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 화면 상단은 제목, 보조 설명, 새로고침 버튼 순서로 배치한다.
- 필터 영역은 한 줄을 기본으로 하되 1300px 미만에서는 두 줄 wrap을 허용한다.
- 적용 필터 chip은 검색 후에만 표시한다.

---

## 2. 필터

| 필터 | 입력 방식 | 동작 |
|---|---|---|
| 거래처명 | 텍스트 | `partnerName` 부분 일치 |
| 전표번호 | 텍스트 | `slipNo` 정확 또는 부분 일치 |
| 구분 | 선택 | 전체 / 지출 |
| 기간 | 날짜 범위 | `transactionDate` 기준 |

검색 버튼으로 조회하고, Enter 키도 동일하게 동작한다. 초기화는 모든 필터와 페이지를 1페이지로 되돌린다.

---

## 3. 컬럼

| 컬럼 | 데이터 | 표시 규칙 |
|---|---|---|
| 전표번호 | `slipNo` | 링크, UUID 표시 금지 |
| 거래처 | `partnerName` | 18자 이후 말줄임 |
| 구분 | `kind` | `지출` badge |
| 거래일 | `transactionDate` | `YYYY-MM-DD` |
| 금액 | `amount` | 우정렬, 천 단위 쉼표 |
| 연결 분개번호 | `journalNo` | 값 없으면 `-` |

---

## 4. 상태

- 빈 결과: `조건에 맞는 지출 자료가 없습니다.` + `필터 초기화`
- 오류: `지출 자료를 불러오지 못했습니다.` + `다시 시도`
- 권한 없음: `현금 지출 화면을 볼 권한이 없습니다.`
- 로딩: 표 skeleton 8행, 필터 입력은 비활성화하지 않는다.
