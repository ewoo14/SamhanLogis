```
│          │ │ 분개번호   │ 일자 │ 적요               │ 출처    │ 상태   │ 합계  ││

│          │  총 5건                                       [< 1 2 3 ... >]        │
└──────────┴──────────────────────────────────────────────────────────────────────┘
```

**컬럼 정의**
- 분개번호: `journalNo` (yyyyMMdd-N) — UUID 미노출 (`feedback_uuid_no_user_visibility.md`)
- 일자: `journalDate` MM-DD (호버 시 yyyy-MM-DD tooltip)
- 적요: 좌정렬, ellipsis 32 char
- 출처: `sourceType` enum (수동 / 슬립연계 / 결산 …) — 본 슬라이스 "수동" 만
- 상태: `<JournalStatusBadge variant="draft|posted|reversed">` 신규 컴포넌트
- 합계: 차변 합계 (= 대변 합계, KRW only) — 우정렬 + tabular-nums

**행 클릭** → JournalDetailPage 이동 (PathParam 은 UUID 이지만 화면엔 journalNo 만 표시)

## 3. JournalFormPage (`/accounting/journals/new` 또는 `/edit`)

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│ [Header]  업무 화면 / 회계 / 분개장 / 신규                       [김미선 ▾]    │
├──────────┬──────────────────────────────────────────────────────────────────────┤
│ Sidebar  │ 신규 분개                                  (DRAFT 저장 후 POST 가능) │
│          │ ─────────────────────────────────────────────────────────────────── │
│          │  ┌─ 헤더 ─────────────────────────────────────────────────────────┐ │
│          │  │ 일자  [2026-05-04 📅]    출처 [수동 ▼]                         │ │
│          │  │ 적요  [5월 임차료 지급____________________________________]    │ │
│          │  └────────────────────────────────────────────────────────────────┘ │
│          │                                                                      │
│          │  ┌─ 라인 ──────────────────────────────────────────────────────────┐│
│          │  │ # │ 계정      │ 차변     │ 대변     │ 거래처   │ 메모    │      ││
│          │  ├───┼───────────┼──────────┼──────────┼──────────┼─────────┼──────┤│
│          │  │ 1 │ 805 임차료│   500,000│         │ 강남빌딩 │ 5월분   │ [✕] ││
│          │  │ 2 │ 102 보통예│         │   500,000│ 국민은행 │         │ [✕] ││
│          │  │ 3 │ 마지막 행 입력 시 아래 빈 행 자동 생성                    ││
│          │  ├───┴───────────┼──────────┼──────────┼──────────┼─────────┴──────┤│
│          │  │ 합계          │  500,000 │  500,000 │ ✓ 일치   │                ││
│          │  └───────────────┴──────────┴──────────┴──────────┴────────────────┘│
│          │                                                                      │
│          │                          [취소]  [저장 (DRAFT)]  [확정 (POST)]      │
└──────────┴──────────────────────────────────────────────────────────────────────┘
```

**라인 입력 패턴**
- 표 grid: `# (24px) / 계정 (180px) / 차변 (140px) / 대변 (140px) / 거래처 (160px) / 메모 (1fr) / [✕] (32px)`
- 계정: `<AccountCodeSelect>` (검색 + 트리 표시) — 신규 컴포넌트
- 차변/대변: `<MoneyInput>` (콤마 자동) — 한쪽 입력 시 반대쪽 disabled (배타 입력)
- 거래처: `<PartnerSelect>` (Q8 — 본 슬라이스는 free-text + partnerId nullable)
- 합계 행: 차변/대변 합계 + ✓ 일치 또는 ✕ 불일치 표시 (`--state-success` / `--state-danger`)

**버튼 disabled 규칙**
- `[저장 (DRAFT)]`: 항상 활성 (라인 0건 또는 합계 불일치 OK — DRAFT 단계)
- `[확정 (POST)]`: 라인 ≥ 2 + 차변 합계 = 대변 합계 + 모든 라인 계정 선택됨 + 합계 > 0

**상호작용**

- `[엑셀]` → CSV download (Slice A 범위, xlsx 변환은 deferred)

## 6. 모바일 (Slice A 범위 외)

본 슬라이스는 **데스크탑 전용**. 회계 업무는 사무실 환경 위주이므로 모바일 우선순위 낮음.
모바일 미지원 화면 진입 시 "데스크탑에서 이용해주세요" 안내 (Phase 5+ 모바일 대응).
