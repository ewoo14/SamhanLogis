# 01. 카카오톡 배차 자동 파싱

> **Stage 안내**: Stage 4 ✅ — P1-5 Frontend admin UI 구현 완료. `/arologis/admin/auto-dispatch` 정식 운영.

---

## 1. 구현 상태

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| Backend `KakaoDispatchParser` | ✅ 운영 | 13 차량 / 약 50 정차 / 약 80% 정확도 |
| Backend `/admin/arologis/dispatches/parse-kakao` | ✅ 운영 | API 만 |
| Backend `/dispatches` 저장 | ✅ 운영 | 자동 저장 |
| Frontend admin UI | ✅ 운영 | `/arologis/admin/auto-dispatch` (P1-5) |
| 인성데이타 vendor 연계 | ⏳ 부분 | DriverMatcher (Mock + Insung) |

(주)삼한공조시스템 arologis 카카오톡 배차는 인성데이타 퀵프로그램에서 carrier (운수사) 가 발송한 카카오톡 메시지를 자동 파싱하여 배차 정보로 등록하는 기능입니다.

---

## 2. 대상 독자

- 배차 상황을 모니터링하는 영업 부장 (MANAGER)

## 4. 본문

### 4-1. 카카오톡 배차 메시지 구조

인성데이타 퀵프로그램이 발송하는 표준 메시지 (예시).

```
[배차통보]
일시: 2026-05-10 09:30
차량: 12가3456
기사: 홍길동 (010-1234-5678)
정차: 본사창고 → A거래처 → B거래처
화물: SLIP-2026-0001, SLIP-2026-0002
```

### 4-2. Frontend admin UI — 자동 매칭 화면

좌측 사이드바 **[arologis]** > **[자동 매칭]** 클릭 → `/arologis/admin/auto-dispatch` 진입.

**운영 절차**:

1. 배차 일자 선택 (기본: 오늘)
2. 미배차 전표 건수 확인 (화면 상단 현황 banner)
3. **[자동 매칭 실행]** 버튼 클릭 → DriverMatcher (Mock + Insung) 호출
4. 매칭 결과 표 확인 — 전표별 기사 / 차량 / 신뢰도 표시
5. 매칭 실패 건 → [배차 관리] (`/arologis/admin/manual-dispatch`) 에서 수동 보정

진입 권한: DISPATCH / MANAGER / MASTER.

### 4-3. 우회 — backend API 직접 호출

#### 단계 1 — 메시지 복사

1. 카카오톡 배차방에서 배차 메시지 복사
2. 메시지 본문 전체 복사 (하단 footer 포함 가능)

#### 단계 2 — IT 관리자 API 호출

1. 메시지 본문을 IT 관리자에게 전달 (이메일 / 사내 메신저)
2. IT 관리자가 backend API 호출.

```
POST /admin/arologis/dispatches/parse-kakao
Content-Type: text/plain

[배차통보]
일시: 2026-05-10 09:30
...
```

3. 응답으로 파싱 결과 + 등록된 배차 ID 회신

#### 단계 3 — 결과 확인

1. 배차 담당이 [02. 수동 배차](02-수동-배차.md) list 진입
2. 자동 등록된 배차 확인 + 누락 사항 수정

### 4-4. 파싱 정확도 약 80%

- 정차 순서 / 화물번호 / 차량번호 정확
- 기사 전화번호 부분 (개인정보 가림 사례)
- 메시지 footer / 인사말 무시
- 80% 자동 + 20% 수동 보정 권장

### 4-5. 인성데이타 vendor 연계

DriverMatcher 가 다음 2개 모드 지원.

- **Mock** — 개발 / 테스트용
- **Insung** — 인성데이타 실 연계

자세한 흐름은 [03. 기사 배정](03-기사-배정.md) 참조.

### 4-6. 정식 UI 운영 (P1-5 완료)

본 docs 는 P1-5 PR 머지로 정식 본문으로 교체되었습니다. `/arologis/admin/auto-dispatch` 정식 운영 중.

## 6. FAQ

**Q1. 카카오톡 자동 수신 가능한가요?**
A. P1-5 Frontend UI 운영 중 (PR #145). `/arologis/admin/auto-dispatch` 에서 메시지를 붙여넣어 자동 파싱 후 배차 등록. Webhook 완전 자동 수신은 장기 backlog 입니다.

**Q2. 파싱 정확도 80% 가 낮지 않나요?**
A. 인성데이타 / 운수사별 메시지 형식 차이로 80% 수준 운영 중. 오파싱 건은 [02. 수동 배차](02-수동-배차.md) 로 보완하세요. 사례 학습 개선은 장기 backlog 입니다.

**Q3. 파싱 실패 시?**
A. [02. 수동 배차](02-수동-배차.md) 로 직접 등록.

**Q4. 동일 배차가 두 번 등록되면?**
A. backend idempotency-key 보호. 동일 차량 / 동일 일시 조합 시 중복 등록 거부.

**Q5. 정식 출시는 언제?**
A. P1-5 슬라이스로 출시 완료. `/arologis/admin/auto-dispatch` 에서 바로 사용 가능.
