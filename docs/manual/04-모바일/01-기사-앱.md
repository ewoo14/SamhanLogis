## 4. 본문

### 4-1. 앱 설치

#### 4-1-1. Android

1. Google Play Store 에서 "Samhan Public" 검색
2. 또는 IT 관리자가 안내한 URL (Expo URL) 직접 접속
3. 설치 후 아이콘 클릭

#### 4-1-2. iOS

1. App Store 에서 "Samhan Public" 검색
2. 또는 TestFlight 초대 링크 접속 (베타 시점)
3. 설치 후 아이콘 클릭

### 4-2. 로그인

1. 본인의 desktop 동일 ID/PW 로 로그인
2. 첫 로그인 시 비밀번호 변경 화면 자동 표시 ([00-시작하기 / 01. 로그인](../00-시작하기/01-로그인.md) 참조)
3. ROLE 이 DRIVER 인 경우 자동으로 driver mode 진입

### 4-3. DriverDashboard

로그인 직후 표시되는 메인 화면.

- **본인 배차 전표 list** — status: APPROVED / PICKED / SHIPPING
- **오늘의 배송 통계** — 완료 / 진행중 / 대기
- **알림** — 신규 배차 / 배차 변경 / 시스템 공지
- **하단 navigation** — 전표 / 위치 / 설정

### 4-4. 전표 상세 + 진행

list 의 전표 클릭 → 상세 화면.

- 거래처 / 받는 사람 / 주소 / 전화 / 합계
- **[배송 시작]** — status: PICKED → SHIPPING (재고 deduct)
- **[전자 서명]** — 도착 후 [02. 전자 서명](02-전자-서명.md) 진행
- **[전화]** — 받는 사람 전화 자동 다이얼

### 4-5. GPS 위치 추적

배송 중 위치를 자동 수집합니다.

1. 첫 실행 시 GPS 권한 허용 (앱 사용 시)
2. 백그라운드에서도 일정 간격 위치 전송
3. 배차 담당이 desktop 에서 실시간 위치 확인

> GPS 권한 거부 시 GpsBlocked 화면 표시 + 안내. 설정 > 앱 > 권한에서 재허용.

### 4-6. mode toggle

영업 직원이 mobile-staff 앱을 사용할 경우 estimate mode 로 전환 가능. ROLE 에 따라 자동 결정.

- DRIVER → driver mode (DriverDashboard)
- SALES → estimate mode (legacy webview, [03. 영업 앱](03-영업-앱.md) 참조)

### 4-7. Stage 4 실시간 협업

배차 변경 / 전표 수정 등 실시간 알림이 푸시로 도착합니다. 자세한 절차는 [08-실시간-협업 / 08. 모바일 실시간 알림](../08-실시간-협업/08-모바일-실시간-알림.md) 참조.

## 6. FAQ

**Q1. GPS 권한을 거부했는데?**
A. GpsBlocked 화면 표시. 설정 > 앱 > Samhan Public > 권한 > 위치 > 허용.

**Q2. 배터리가 빨리 닳습니다.**
A. GPS 백그라운드 전송이 원인. 배송 종료 후 앱 강제 종료 또는 로그아웃 권장.

**Q3. 전표이 안 보입니다.**
A. (1) 본인 배차 분만 표시. 배차 담당에게 확인. (2) status 가 PICKED 이전 (APPROVED) 인 경우 미표시 가능.

**Q4. 전화 다이얼이 안 됩니다.**
A. 받는 사람 전화번호 미등록 가능성. 영업 직원에게 거래처 정보 갱신 요청.

**Q5. 영업 직원도 이 앱을 쓸 수 있나요?**
A. 가능. ROLE 이 SALES 인 경우 estimate mode 로 자동 전환. [03. 영업 앱](03-영업-앱.md) 참조.

**Q6. 사진 첨부 기능은?**
A. P1 미구현. [04. 사진 첨부](04-사진-첨부.md) 참조.
