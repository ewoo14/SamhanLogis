# 03. 영업 직원 견적/주문 모바일

> **Stage 안내**: Stage 1 ✅ (정식 본문) — P1-4 영업 앱 정식 운영 (PR #144). mobile-staff estimate mode + legacy WebView 임베드 정식 출시.

---

## 1. 구현 상태

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| mobile-staff (estimate mode) | ✅ 운영 | react-native-webview 1 screen |
| Legacy estimate-app v2 임베드 | ✅ 운영 | port 5183 / estimate.samhan-air.com |
| Native 견적 앱 (P1-4) | ⛔ 미구현 | Phase 11+1개월 |
| Native 주문 앱 (P1-4) | ⛔ 미구현 | Phase 11+1개월 |
| 모바일 mode toggle | ✅ 운영 | ROLE 자동 |

(주)삼한공조시스템 영업 직원 모바일은 현재 native 앱이 미구현 상태이므로, mobile-staff 앱 안에 legacy estimate-app v2 (Node.js + Express + EJS) WebView 를 임베드한 임시 솔루션으로 운영합니다.

## 2. 대상 독자

- 외근 중 견적 / 주문을 모바일로 처리하는 영업 직원 (SALES)
- 영업 직원 native 앱 인수인계를 받는 신규 직원
- legacy v2 ↔ Samhan Public 마이그레이션을 검토하는 IT 관리자

## 3. 학습 내용

- mobile-staff (estimate mode) 진입
- Legacy v2 WebView 사용 흐름
- Legacy v2 ↔ Samhan Public 데이터 동기화 (현재 분리)
- Phase 11+1개월 후 정식 native 앱 출시 일정

---

## 4. 본문

### 4-1. mode 진입

1. mobile-staff 앱 로그인 (ROLE = SALES)
2. 자동으로 estimate mode 진입
3. react-native-webview 가 legacy estimate-app v2 표시

### 4-2. Legacy estimate-app v2 사용

legacy mobile UI 가 100% 보존되어 있습니다.

- 견적 작성 / 거래처 검색 / 단가 입력 / PDF 발송
- legacy 인증 (별도 로그인 가능 / SSO 미지원)

> Legacy v2 는 v4 + Phase 10 신규 시스템과 데이터 분리 상태. 등록한 견적은 별도 동기화 필요 (수동).

### 4-3. mode toggle (DRIVER ↔ SALES)

ROLE 이 DRIVER + SALES 양쪽 보유 시 mode toggle 가능.

1. 우측 상단 mode toggle 아이콘 클릭
2. driver mode ↔ estimate mode 전환

### 4-4. Phase 11+1개월 후 정식 native 앱

P1-4 슬라이스로 출시 예정 기능.

- React Native (Expo) native 견적 / 주문 화면
- Samhan Public backend 직접 연동 (legacy 분리 종료)
- 거래처 검색 / 품목 검색 / 단가 자동 / 결재 요청
- 사진 첨부 (P1 사진 첨부와 통합)
- 오프라인 작성 + 재연결 동기화

### 4-5. Stage 4 실시간 협업

Legacy WebView 는 실시간 협업 패턴 미적용. Phase 11+1개월 후 정식 native 앱 출시 시 [실시간 동기화](../08-실시간-협업/01-실시간-동기화.md), [수정 횟수 chip](../08-실시간-협업/03-수정-횟수-카운트.md) 등 표준 패턴 일괄 적용 예정.

## 6. FAQ

**Q1. legacy v2 견적 ↔ Samhan Public 슬립 자동 변환?**
A. 미구현. 영업 직원이 desktop 에 별도 슬립 등록.

**Q2. legacy v2 인증을 잊었습니다.**
A. legacy 별도 인증. IT 관리자에게 문의.

**Q3. Native 앱은 언제 나오나요?**
A. P1-4 슬라이스로 Phase 11+1개월 후 출시 예정.

**Q4. 외근 중 인터넷 안 되는 곳에서?**
A. 정식 native 앱 출시 시 오프라인 작성 + 재연결 동기화 지원 예정. 현재는 legacy v2 도 실시간 인터넷 필요.

**Q5. 모바일에서 슬립 결재 요청 가능한가요?**
A. legacy v2 자체 결재 흐름. Samhan Public 결재 ([01-영업 / 04. 슬립 결재 라인](../01-영업/04-슬립-결재-라인.md)) 와 분리.
