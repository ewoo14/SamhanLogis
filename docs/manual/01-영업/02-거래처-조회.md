## 4. 본문

### 4-1. 거래처 list 진입

좌측 사이드바 **[영업]** > **[거래처]** 클릭. list 화면이 표시됩니다.

### 4-2. 거래처 검색

list 상단의 검색 박스에 다음 중 하나를 입력하고 Enter 또는 [검색] 클릭.

- 거래처명 (부분 일치)
- 사업자등록번호 (10자리 또는 부분)
- 거래처 코드 (`P-2026-0123` 등)
- 담당자명 (부분 일치)

검색 결과는 list 영역에 즉시 표시됩니다.

### 4-3. 정렬

list 상단의 컬럼 헤더를 클릭하면 해당 컬럼 기준 오름차순/내림차순 정렬됩니다.

- 거래처명 / 사업자번호 / 거래 시작일 / 신용한도 / 신용 평가

### 4-4. 페이지네이션

list 하단에서 페이지당 행 개수(20/50/100)를 선택하고, 페이지 번호 클릭으로 이동합니다.

### 4-5. Excel 다운로드 (P1-6 ✅)

거래처 목록 화면 우측 상단 **[Excel 다운로드]** 버튼을 클릭합니다.

- 현재 설정된 **유형 필터** (고객 / 공급사 / 전체) 와 **상태 필터** (거래중 / 거래중지 / 거래종료 / 전체) 조건을 그대로 적용해 다운로드합니다.
- 버튼 클릭 시 로딩 spinner 표시 후 `거래처목록_YYYY-MM-DD.xlsx` 파일로 자동 저장됩니다.
- BE endpoint: `GET /api/v1/partners/export?type=...&status=...`

### 4-6. 거래처 상세 정보 (4탭 dialog)

list 의 거래처 행을 클릭하면 4탭 상세 다이얼로그가 열립니다.

- **탭 1 기본정보**: 거래처명, 사업자번호, 주소, 유형, 대표자 등
- **탭 2 단가/할인 정책**: 기본 할인율, 결제 기간, 신용한도
- **탭 3 배송지**: 등록된 배송지 목록 (기본 배송지 표시)
- **탭 4 담당자**: 담당자 목록 (주 담당자 표시)

dialog 하단 **[편집]** 버튼 클릭 시 인라인 수정 모드로 전환됩니다. 수정 후 **[저장]** 클릭.

### 4-7. 신용 평가 / 미수금 (P2-4 — 장기 backlog)

거래처 신용 평가, 미수금 잔액, 최근 거래 history 자동 집계 표시는 P2-4 매출 마감 슬라이스 구현 후 추가 예정입니다. 현재는 [03-회계 / 02. 보고서](../03-회계/02-보고서.md) 에서 거래처원장으로 확인하세요.

### 4-8. Stage 4 실시간 협업

거래처 list 의 각 행에는 수정 횟수 chip 이 표시됩니다 ([수정 횟수 카운트](../08-실시간-협업/03-수정-횟수-카운트.md)). 다른 영업 직원이 거래처 정보를 수정하면 1초 이내 본인 화면에 자동 반영됩니다.

## 6. FAQ

**Q1. 거래처가 검색되지 않습니다.**
A. (1) 거래처명은 부분 일치가 가능하지만, 띄어쓰기 / 괄호 표기 차이로 미검색 가능. 사업자등록번호로 재시도. (2) 사용 여부 "비활성" 거래처는 기본 list 에 표시되지 않습니다. 필터에서 "비활성 포함" 체크.

**Q2. 한 페이지에 100개 넘게 표시할 수 있나요?**
A. 현재 최대 100행. 더 많은 데이터가 필요하면 우측 상단 **[Excel 다운로드]** 버튼으로 전체 목록을 내려받으세요 (P1-6 정식 운영 중, PR #146).

**Q3. Excel 로 다운로드할 수 있나요?**
A. 네. 거래처 목록 화면 우측 상단 **[Excel 다운로드]** 버튼으로 즉시 다운로드할 수 있습니다 (P1-6 ✅). 현재 필터 조건(유형/상태)이 그대로 적용됩니다.

**Q4. 거래처별 매출 합계가 보이지 않습니다.**
A. P2-4 미구현 (장기 backlog). 현재는 [03-회계 / 02. 보고서](../03-회계/02-보고서.md) 거래처원장을 활용하세요.

**Q5. 거래처 상세에서 수정할 수 있나요?**
A. 네. 행 클릭 → 4탭 상세 dialog → [편집] 버튼으로 수정 가능합니다. SALES / MANAGER / MASTER 역할만 편집 가능.
