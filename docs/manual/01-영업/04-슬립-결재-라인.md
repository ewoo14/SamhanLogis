## 4. 본문

### 4-1. 결재 라인 구조

(주)삼한공조시스템 슬립 결재는 1단계 결재 라인을 기본으로 합니다.

```
[SALES 작성/임시저장] → [SALES 결재요청 SUBMITTED] → [MANAGER 승인 APPROVED 또는 반려 REJECTED]
```

> 다단계 결재 (예: SALES → 부장 → 임원 → 대표) 는 미구현 상태입니다. 필요시 IT 관리자에게 backend ROLE 추가 요청.

### 4-2. 결재요청 (SALES)

1. 슬립 작성 완료 후 **[결재요청]** 버튼 클릭
2. 슬립 status: DRAFT → SUBMITTED
3. 영업 부장(들)에게 알림 발송 (헤더 종 아이콘 배지)
4. 본인 슬립 list 에서 status 가 "결재요청" 으로 표시

### 4-3. 승인 (MANAGER)

1. 헤더 알림 클릭 또는 사이드바 **[영업]** > **[결재대기]** 진입
2. 슬립 상세 확인 (라인 / 단가 / 합계 / 거래처)
3. **[승인]** 버튼 클릭
4. 슬립 status: SUBMITTED → APPROVED
5. 창고팀 자동 알림 (피킹 시작)

### 4-4. 반려 (MANAGER)

승인하지 않을 경우 반려.

1. 슬립 상세에서 **[반려]** 버튼 클릭
2. **사유 입력** 다이얼로그 표시 (필수)
3. 사유 입력 후 [확인]
4. 슬립 status: SUBMITTED → REJECTED
5. 영업 직원 알림 (헤더 배지 + 슬립 list 빨간 표시)

### 4-5. 취소 (SALES → MANAGER 승인)

이미 결재된 슬립을 취소하려면.

1. 영업 직원이 슬립 상세에서 **[취소요청]** 클릭 + 사유 입력
2. 영업 부장 알림 수신 → **[취소승인]** 클릭
3. 슬립 status: APPROVED → CANCELED
4. 자동 분개가 이미 발행되었다면 역분개 자동

### 4-6. ROLE 별 액션 매트릭스

전체 11 status × ROLE 매트릭스는 [00-시작하기 / 03. 역할별 화면 차이 §4-3](../00-시작하기/03-역할별-권한.md#4-3-슬립-11-status--role-액션-매트릭스) 참조.

### 4-7. 자동 분개

DELIVERED 시 slip-service 가 accounting-service 로 분개 트랜잭션 자동 발행. CANCELED 시 역분개 자동.

자세한 흐름은 [03-회계 / 01. 분개 입력](../03-회계/01-분개-입력.md) 참조.

### 4-8. Stage 4 실시간 협업

영업 부장이 슬립 결재 진행 시, 영업 직원 화면에 status 변경이 1초 이내 자동 반영됩니다 ([실시간 동기화](../08-실시간-협업/01-실시간-동기화.md)).

영업 부장이 잠시 자리 비운 사이 영업 직원이 슬립을 수정하려면 [수정 요청 워크플로우](../08-실시간-협업/05-수정-요청-워크플로우.md) 를 사용하세요. 영업 부장 복귀 후 수락하면 수정 가능합니다.

## 6. FAQ

**Q1. 결재 위임이 가능한가요?**
A. 미구현. 영업 부장 부재 시 MASTER 가 임시 결재하거나, 다른 영업 부장에게 슬립 작성자 변경 요청.

**Q2. 일괄 결재 (10건 한 번에 승인) 가능한가요?**
A. 미구현. 1건씩 처리. 장기 backlog.

**Q3. 반려된 슬립을 다시 결재요청할 수 있나요?**
A. 네. 영업 직원이 사유 확인 후 슬립 수정하고 다시 [결재요청] 클릭. status: REJECTED → DRAFT → SUBMITTED.

**Q4. 결재 알림을 이메일로 받을 수 있나요?**
A. 미구현. 헤더 종 아이콘 배지로만 알림. Phase 11 후 이메일/카카오톡 알림 출시 예정.

**Q5. MANAGER 도 본인 슬립을 본인이 결재할 수 있나요?**
A. 정책상 금지. 다른 MANAGER 또는 MASTER 가 결재해야 합니다.

**Q6. 자동 분개가 잘못 발행되었습니다.**
A. 영업 부장이 슬립 CANCELED 처리 시 역분개 자동. 또는 회계 직원이 [03-회계 / 01. 분개 입력](../03-회계/01-분개-입력.md) 에서 수동 역분개 등록.
