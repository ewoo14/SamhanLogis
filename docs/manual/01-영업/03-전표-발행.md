# 03. 전표 발행

> **Stage 안내**: Stage 2 ✅ (정식 본문) — Phase 12 step-6 본 PR 에서 7-section 패턴으로 재작성 + 신규 PNG inline.

---

## 1. 구현 상태

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| 전표 등록/조회/수정 | ✅ 운영 | slip-service `/slips/**` |
| 11 status workflow | ✅ 운영 | DRAFT → CLOSED |
| 자동 분개 (회계 연동) | ✅ 운영 | DELIVERED 시 분개 자동 |
| 모바일 서명 | ✅ 운영 | mobile-staff `/sign-mock` + 실 서명 |
| 인쇄 양식 (거래명세표) | ✅ 운영 | 브라우저 인쇄 |
| 인쇄 양식 (세금계산서) | ✅ 운영 (P0-4) | NTS 종이 양식 인쇄 (PR #139). NTS API 전자 연계는 장기 backlog |
| 전표 목록 Excel export | ✅ 운영 (P1-6) | 출고/입고 구분별 당월 기준 다운로드 |
| 반품 (Return) / 부분 출고 / 묶음 발행 | ⛔ 미구현 | 장기 backlog |

전표는 (주)삼한공조시스템의 핵심 거래 단위입니다. 등록 → 결재 → 출고 → 배송 → 완료 → 마감의 11 status 를 거칩니다.

---

## 2. 대상 독자

- 전표을 등록하는 영업 직원 (SALES)
- 결재하는 영업 부장 (MANAGER)
- 출고/배송 진행하는 창고/기사
- 자동 분개 결과를 확인하는 회계 (ACCOUNTANT)

## 3. 학습 내용

- 전표 신규 등록 절차 (거래처 / 품목 / 수량 / 단가)

- 인쇄 (거래명세표)
- 모바일 서명 수신 흐름
- 자동 분개 결과 확인

## 4. 본문

### 4-1. 전표 list 진입

좌측 사이드바 **[영업]** > **[전표]** 클릭. 전표 list 화면이 표시됩니다.

### 4-2. 신규 전표 등록

list 상단 우측 **[신규 등록]** 버튼 클릭.

#### 4-2-1. 헤더 정보 입력

| 필드 | 필수 | 설명 |
| --- | :-: | --- |
| 거래처 | ✅ | 검색 후 선택 |
| 거래일 | ✅ | YYYY-MM-DD (기본 오늘) |
| 거래 유형 | ✅ | 매출 / 매입 / 반품(미구현) |
| 출고 창고 | ✅ | 본사창고 / 지점창고 등 |
| 배송태그 | — | 아래 배송태그 표 참조 |
| 비고 | — | 자유 입력 |

#### 4-2-1-1. 배송태그 (DeliveryTag)

전표 유형별로 선택 가능한 배송태그입니다. 판매조회(출고전표)와 구매조회(입고전표)에서 배송태그 필터로 목록 조회도 가능합니다.

**판매조회 (출고전표) — 8종**

| 태그 코드 | 한국어 라벨 | 설명 |
| --- | --- | --- |
| DAY | 당일 | 당일 출고/배송 (긴급) |
| STACK | 야적 | 출고일 야적, 익일 상차/하차 (자동 메모) |
| REGION | 지방 | 지방 배송 (자동 메모) |
| LOGEN | 로젠택배 | 외부 택배사 위탁 |
| GYEONGDONG_PARCEL | 경동택배 | 외부 택배사 위탁 (소형) |
| GYEONGDONG_FREIGHT | 경동화물 | 외부 화물사 위탁 (대형) |
| RENTAL | 대여 | 대여 출고 |
| RETURN_RENTAL | 반납 | 대여품 반납 출고 |

**구매조회 (입고전표) — 3종**

| 태그 코드 | 한국어 라벨 | 설명 |
| --- | --- | --- |
| RETURN_TRIP | 회차 | 차량 회차 입고 |
| RETURN | 반품 | 거래처 반품 입고 |
| BORROW | 차용 | 외부 차용품 입고 |

#### 4-2-2. 라인(품목) 입력

품목 행 추가. 1 전표당 다수 라인 입력 가능.

| 필드 | 필수 | 설명 |
| --- | :-: | --- |
| 품목 | ✅ | 검색 후 선택 |
| 수량 | ✅ | 양의 정수 |
| 단가 | ✅ | 거래처별 단가 자동 표시 (수정 가능) |
| 할인율 | — | % |
| 부가세 별도 / 포함 | ✅ | 라디오 |
| 메모 | — | |

#### 4-2-3. 임시저장 / 결재요청

- **[임시저장]** — DRAFT 상태로 저장 (이후 수정 가능)
- **[결재요청]** — SUBMITTED 상태로 전환 (영업 부장에게 알림)

### 4-3. 11 status 흐름

| Status | 한국어 | 액션 책임자 | 다음 액션 |
| --- | --- | --- | --- |
| DRAFT | 작성중 | SALES | 결재요청 / 삭제 |
| SUBMITTED | 결재요청 | MANAGER | 승인 / 반려 |
| APPROVED | 결재완료 | WAREHOUSE | 피킹 시작 |
| PICKING | 피킹중 | WAREHOUSE | 피킹 완료 |
| PICKED | 피킹완료 | DISPATCH | 배차 / 직접 배송 |
| SHIPPING | 배송중 | DRIVER | 도착 / 서명 |
| DELIVERED | 배송완료 | DRIVER | 서명 수신 (자동 분개 트리거) |
| INVOICED | 세금계산서 발행 | ACCOUNTANT | NTS 발행 |
| CLOSED | 마감 | ACCOUNTANT | 월말 마감 |
| CANCELED | 취소 | SALES → MANAGER 승인 | (종료) |
| REJECTED | 반려 | MANAGER | SALES 재작성 |

### 4-4. 인쇄 (거래명세표)

전표 상세 화면 우측 상단 **[인쇄]** 버튼 클릭. 브라우저 인쇄 미리보기가 열립니다.

- Edge / Chrome 권장 (Internet Explorer 비호환)
- 용지: A4 세로
- 회사명: (주)삼한공조시스템 자동 표시
- 인쇄 안 됨 트러블슈팅: [06-트러블슈팅 / 03. 인쇄 안 됨](../06-트러블슈팅/03-인쇄-안됨.md)

### 4-5. 모바일 서명

DELIVERED 직전 단계인 SHIPPING 시, 기사가 mobile-staff 앱에서 받는 사람의 전자 서명을 수신합니다. 자세한 절차는 [04-모바일 / 02. 전자 서명](../04-모바일/02-전자-서명.md) 참조.

### 4-6. 자동 분개

DELIVERED 전환 시 slip-service 가 accounting-service 로 분개 트랜잭션을 자동 발행합니다. 회계 직원은 [03-회계 / 01. 분개 입력](../03-회계/01-분개-입력.md) 에서 결과를 확인할 수 있습니다.

### 4-7. Stage 4 실시간 협업

전표 list / 상세 / 폼 화면 모두 [수정 횟수 chip](../08-실시간-협업/03-수정-횟수-카운트.md), [audit overlay](../08-실시간-협업/02-수정-이력-보기.md) 가 표시됩니다. 영업 부장이 결재 도중 전표을 수정하면 영업 직원 화면에 1초 이내 자동 반영됩니다 ([실시간 동기화](../08-실시간-협업/01-실시간-동기화.md)).

수정이 필요한 경우 [수정 요청 워크플로우](../08-실시간-협업/05-수정-요청-워크플로우.md) 를 사용하세요.

## 6. FAQ

**Q1. 전표을 등록한 후 수정하려면?**
A. DRAFT 상태에서는 자유롭게 수정 가능. SUBMITTED 이후는 영업 부장에게 [수정 요청](../08-실시간-협업/05-수정-요청-워크플로우.md) 을 통해 진행하세요.

**Q2. 결재 후에도 취소할 수 있나요?**
A. APPROVED 이전에는 SALES 가 직접 [취소] 가능. APPROVED 이후는 영업 부장에게 CANCELED 신청해야 합니다.

**Q3. 자동 분개 결과는 어디서 확인하나요?**
A. [03-회계 / 01. 분개 입력](../03-회계/01-분개-입력.md) 의 분개 list 에서 전표번호로 검색하면 자동 발행 분개를 확인할 수 있습니다.

**Q4. 세금계산서 인쇄는 가능한가요?**
A. P0-4 운영 중 (PR #139 ✅). NTS 종이 양식 인쇄 기능이 정식 운영 중입니다. [03-회계 / 03. 세금계산서](../03-회계/03-세금계산서.md) 참조. NTS API 전자 발행 연계는 장기 backlog 입니다.

**Q5. 반품(Return) 전표은 어떻게 등록하나요?**
A. 미구현. 임시 우회로 음수 수량 전표을 등록하거나, IT 관리자에게 문의하세요.

**Q6. 전표번호 형식은?**
A. `S-2026-0001` 형태. 거래일 기준 자동 채번. UUID 는 사용자에게 노출되지 않습니다.
