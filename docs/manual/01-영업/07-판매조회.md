# 07. 영업조회

> **2026-05 메뉴 통합 (2a)**: 기존 `판매조회` (legacy 출고전표 list) + `판매조회(상세)` (rich query) 가 단일 메뉴로 통합되었습니다. 사이드바 최상단 **"판매조회"** 가 이제 본 화면(SalesQueryPage)으로 직행합니다. 데이터 필드명(예: `판매번호` = `slipNo`)은 회계/세무 관행 호환을 위해 보존합니다.

## 1. 개요

영업조회 화면(`/sales`)은 출고전표의 풍성한 컬럼을 제공하는 조회 전용 페이지입니다.
대량 조회 · 다중 선택 · Excel 다운로드에 특화되어 있습니다.

접근 경로: 사이드바 최상단 → **판매조회**

> 기존 deep-link `/sales/query` 는 호환 alias 로 유지되며, 동일 화면으로 진입합니다.
> legacy SlipListPage (출고전표 작성/lifecycle 흐름) 는 `/sales/slips` 로 이전되었으며 사이드바에서는 미노출입니다 — 2c 전표 작성 plumbing 합류 시 정식 진입점이 부활합니다.

---

## 2. 날짜 범위 설정

- 기본값: 오늘 기준 ±15일 (Asia/Seoul)
- 직접 날짜 입력 또는 아래 preset 버튼 사용

| 버튼 | 범위 |
|---|---|
| 이번달 | 이번달 1일 ~ 말일 |
| 지난달 | 지난달 1일 ~ 말일 |
| 이번주 | 이번주 일요일 ~ 토요일 |

---

## 3. 컬럼 명세 (17개)

| # | 컬럼명 | 설명 |
|---|---|---|
| 1 | ☑ | 체크박스 (다중 선택 / 전체 선택) |
| 2 | 순번 | slipDate 내림차순 기준 행 번호 |
| 3 | 판매번호 | slipNo (사용자 노출 식별자) |
| 4 | 거래처 | partnerName |
| 5 | 거래처코드 | businessNumber (사업자등록번호) |
| 6 | 배송주소 | deliveryAddress (인수 현장) |
| 7 | 품목 | lineSummary 파생 (BE 미제공 시 "—") |
| 8 | 특이사항 | memo (적요/비고/특이사항 공용) |
| 9 | 금액 | totalAmount (우측 정렬, 천 단위 콤마) |
| 10 | 출고창고 | sourceWarehouseId → 창고명 변환 |
| 11 | 인수자 번호 | recipientPhone |
| 12 | 전표수정내역 | editHistoryCount ("0" 또는 "N건") |
| 13 | 감리주소 | supervisionAddress (설치 현장) |
| 14 | 프로젝트명 | projectName |
| 15 | 담당자명 | salesPersonName |
| 16 | 인쇄 | printed → "인쇄" Badge 또는 "—" |
| 17 | 입금예정일 | paymentDueDate (YYYY-MM-DD) |

> UUID(id, sourceWarehouseId 등)는 화면에 노출되지 않습니다.

---

## 4. 다중 선택

- 행 클릭 또는 체크박스 클릭으로 행 선택
- 선택된 행 배경: 파란 계열 (`#EFF6FF`)
- 헤더 체크박스: 현재 페이지 전체 선택/해제
- 선택 건수는 툴바에 "N행 선택됨"으로 표시

---

## 5. 검색 모달

툴바 우측 "검색" 버튼 클릭 시 검색 다이얼로그가 열립니다.

| 입력 필드 | 설명 |
|---|---|
| 판매번호 | slipNo 부분 검색 |
| 거래처명 | partnerName 부분 검색 |
| 거래처코드 (사업자번호) | businessNumber 검색 |
| 배송주소 | deliveryAddress 부분 검색 |
| 프로젝트명 | projectName 부분 검색 |

- "조회" 버튼: 검색 파라미터 적용, 1페이지로 이동, 모달 닫기
- "초기화" 버튼: 모든 검색 조건 초기화 후 재조회

---

## 6. 페이지네이션

- 50건/페이지 고정
- 이전/다음/처음/마지막/숫자 버튼으로 페이지 이동
- 페이지 이동 시 선택 상태 자동 초기화

---

## 7. 일괄 액션 + 신규 전표

| 액션 | 조건 | 설명 |
|---|---|---|
| 인쇄 | 1건 이상 선택 시 노출 | 브라우저 인쇄 실행 |
| Excel 다운로드 | 항상 노출 | 현재 날짜 범위의 전체 OUTBOUND 전표 Excel 저장 |
| **신규 출고전표** | `SALES / MANAGER / MASTER` 권한 보유 시 노출 | `/sales/new` (SlipFormPage) 로 이동 — 2c 백로그 완료 |

> 2a 메뉴 통합 이후 본 화면이 `/sales` 정식 진입점이 되었습니다. 사이드바 "판매조회" 클릭 → 본 화면 → 우상단 **"신규 출고전표"** 버튼으로 신규 작성. (`data-testid=sales-query-new-slip-btn`)
