# 01. 입고 처리

> **Stage 안내**: Stage 1 ✅ (정식 본문) — P0-9 입고 검수 UI 구현 완료 (PR #142). InboundInspectionListPage + InboundInspectionDialog 정식 운영. 우회 절차 폐기.

---

## 1. 구현 상태

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| Backend (inventory-service) | ✅ 운영 | `/inventory/lots/inbound` |
| Backend (slip-service INBOUND) | ✅ 운영 | 12 신규 컬럼 (PR-G1) |
| 자체 발행 일원화 | ✅ 운영 | PR-G1 |
| 입고 list 화면 | ✅ 운영 | 단순 list |
| 정식 입고 dialog (검수 UI) | ✅ 운영 (P0-9) | `/warehouse/inbound-inspections` + InboundInspectionDialog |
| Lot/유효기간 관리 | ✅ 운영 | backend 만 |

(주)삼한공조시스템 입고 처리는 거래처(공급사)로부터 물품을 받아 창고에 등록하는 단계입니다.

---

## 2. 대상 독자

- 입고 물품을 검수하고 등록하는 창고 직원 (WAREHOUSE)
- 재고 lot 을 관리하는 재고 관리자 (INVENTORY)
- 입고 결재를 검토하는 영업 부장 (MANAGER)

---

## 3. 학습 내용

- INBOUND 전표 유형 의미
- 입고 등록 절차 (수량 / lot / 유효기간 / 단가)
- 정식 검수 UI (InboundInspectionDialog) 사용 절차
- 입고 후 재고 자동 갱신 확인

---

## 4. 본문

### 4-1. 입고 메뉴 진입

좌측 사이드바 **[창고]** > **[입고]** 클릭.

### 4-2. INBOUND 전표 등록

list 상단 **[신규 입고]** 클릭. 기본 전표 등록 폼과 유사하지만 거래 유형이 "매입(INBOUND)" 으로 고정.

| 필드 | 필수 | 설명 |
| --- | :-: | --- |
| 공급사 | ✅ | 거래처 검색 |
| 입고일 | ✅ | YYYY-MM-DD |
| 입고 창고 | ✅ | 본사창고 / 지점창고 |
| 라인 (품목/수량/단가/lot/유효기간) | ✅ | 다중 입력 |

### 4-3. 검수 (P0-9 정식 UI)

P0-9 입고 검수 UI 가 구현되었습니다.

#### 방법 1 — 입고 검수 전용 메뉴

좌측 사이드바 **[창고 운영]** > **[입고 검수]** 클릭.

- 상태 필터 (대기 / 임시저장 / 완료) 로 검수 대상 전표 필터
- 행 클릭 또는 **[검수]** 버튼 → InboundInspectionDialog 오픈
- 라인별 검수 수량 / 불량 수량 / 불량 사유 입력
- **[검수 저장]**: DRAFT 임시 저장 (재고 미반영)
- **[검수 완료]**: 재고 lot 생성 + 분개 자동 발행

#### 방법 2 — 구매관리(입고전표) 목록에서 검수

좌측 사이드바 **[구매관리]** 클릭 → SAVED 또는 CONFIRMED 상태 전표 행의 **[검수]** 버튼 클릭 → InboundInspectionDialog 오픈.

> **권한**: WAREHOUSE / MANAGER / MASTER 만 검수 메뉴 및 버튼에 접근할 수 있습니다.
> **번호 원칙**: 구매번호/판매번호/배차번호는 모두 `YYYY/MM/DD-{순번}` 형식의 업무번호이지만, 서비스/메뉴/업무 타입별로 독립 채번됩니다. 따라서 출고전표 `2026/05/16-1`과 입고전표 `2026/05/16-1`은 동시에 존재할 수 있으며, 내부 복구/이력은 UUID PK가 담당합니다.

### 4-4. 입고 확정

입고 확정 시 inventory-service 가 재고 lot 자동 생성. [03. 재고 조회](03-재고-조회.md) 에서 신규 lot 확인 가능.

### 4-5. Lot / 유효기간 관리

각 입고 라인은 lot 번호 + 유효기간을 가질 수 있습니다.

- Lot 번호: 공급사 라벨 또는 자체 채번 (`LOT-2026-0001`)
- 유효기간: YYYY-MM-DD 또는 무기한
- 출고 시 FIFO (선입선출) 자동 적용

### 4-6. 자동 분개

INBOUND 확정 시 accounting-service 로 매입 분개 자동 발행. [03-회계 / 01. 분개 입력](../03-회계/01-분개-입력.md) 에서 확인.

### 4-7. Stage 4 실시간 협업

입고 list / 상세 화면에 [수정 횟수 chip](../08-실시간-협업/03-수정-횟수-카운트.md) + [audit overlay](../08-실시간-협업/02-수정-이력-보기.md) 표시. 다른 창고 직원이 입고를 등록하면 1초 이내 본인 화면 갱신.

## 6. FAQ

**Q1. 입고 수량이 전표과 다릅니다.**
A. InboundInspectionDialog 에서 라인별 검수 수량 / 불량 수량 / 불량 사유를 입력하세요. [검수 완료] 시 정확한 수량으로 재고 lot 이 생성됩니다. 부족분이 있으면 차후 추가 입고 전표으로 보정하세요.

**Q2. Lot 번호를 입력하지 않으면?**
A. 시스템 자동 채번 (`LOT-2026-XXXX`). 단, 공급사 라벨 번호를 사용하면 추적이 쉽습니다.

**Q3. 유효기간이 지난 lot 은 어떻게 되나요?**
A. 재고 list 에서 노란/빨간색 표시. 출고 시 자동 제외. 폐기 처리는 [05. 재고 실사](05-재고-실사.md) (PR #148 ✅ 운영 중) 화면에서 처리하세요.

**Q4. 입고 분개는 자동인가요?**
A. 네. INBOUND 확정 시 매입 분개 자동 발행. (차변) 재고자산 / (대변) 매입채무.

**Q5. 정식 검수 UI 는 어디에 있나요?**
A. P0-9 슬라이스에서 구현 완료. 좌측 사이드바 **[창고 운영]** > **[입고 검수]** 또는 **[구매관리]** 목록의 **[검수]** 버튼에서 접근합니다.
