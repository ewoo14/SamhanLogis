# 03. 재고 조회 및 이동

> **Stage 안내**: Stage 2 ✅ — Phase 12 step-6 본 PR 에서 7-section 패턴으로 재작성.

---

## 1. 구현 상태

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| Backend (inventory-service) | ✅ 운영 | balances / lots / movements / transfers |
| 재고 list 화면 | ✅ 운영 | desktop |
| 시드 데이터 | ✅ | 200 row + 창고 2개 |
| 차트 / 안전재고 알림 | ✅ 운영 (P1-3) | desktop 창고 운영 메뉴 |
| 재고 실사 UI | ⛔ 미구현 (P2-6) | [05. 재고 실사](05-재고-실사.md) 안내 |

(주)삼한공조시스템 재고 조회는 현재 보유 재고, lot 별 잔량, 이동 이력을 확인하는 핵심 기능입니다.

---

## 2. 대상 독자

- 재고 잔량을 확인하는 창고 직원 (WAREHOUSE)
- Lot / 유효기간을 추적하는 재고 관리자 (INVENTORY)
- 출고 가능 여부를 확인하는 영업 직원 (SALES)

---

## 3. 학습 내용

- 4 개 조회 화면: balances / lots / movements / transfers
- 창고별 / 품목별 / lot 별 필터
- 안전재고 / 유효기간 임박 항목 식별
- 창고간 이동 (transfer) 등록

---

## 4. 본문

### 4-1. 재고 메뉴 진입

좌측 사이드바 **[창고]** > **[재고]** 클릭.

### 4-2. 재고 잔량 (balances)

품목별 + 창고별 현재 잔량 표시.

| 컬럼 | 설명 |
| --- | --- |
| 품목 | 품목명 + 코드 |
| 창고 | 본사창고 / 지점창고 |
| 가용 수량 | reserve 후 가용 |
| 예약 수량 | 진행 중 슬립이 reserve |
| 합계 | 가용 + 예약 |

### 4-3. Lot 별 잔량 (lots)

각 lot 번호별 잔량 + 유효기간.

- Lot 번호 / 입고일 / 유효기간 / 잔량 / 단가
- 유효기간 임박 (30일 이내): 노란색 표시
- 유효기간 만료: 빨간색 표시 + 출고 자동 제외

### 4-4. 이동 이력 (movements)

각 품목의 입고/출고/이동/실사 이력.

| 컬럼 | 설명 |
| --- | --- |
| 일시 | YYYY-MM-DD HH:mm |
| 유형 | 입고 / 출고 / 이동 / 실사조정 |
| 슬립번호 / 참조번호 | 클릭 시 원 슬립 상세 |
| 수량 | + (입고) / - (출고) |
| 잔량 | 이력 후 잔량 |
| 담당자 | 풀네임 |

### 4-5. 창고간 이동 (transfers)

창고 간 재고 이동을 등록합니다.

1. **[신규 이동]** 클릭
2. 출발 창고 / 도착 창고 / 품목 / 수량 / lot 입력
3. **[이동 시작]** → status: REQUESTED → IN_TRANSIT → COMPLETED
4. 자동으로 출발 창고 차감 + 도착 창고 증가

### 4-6. 안전재고 알림 (P1-3 ✅)

품목별 안전재고 임계 미만 시 알림. 좌측 사이드바 **[창고 운영]** > **[안전재고 알림]** 에서 진입.

- 진입 권한: MASTER / MANAGER / WAREHOUSE
- 임계 미만 (가용 수량 < 임계값) 인 (제품, 창고) 조합 전체를 표시
- 창고 필터로 특정 창고 품목만 조회 가능
- 1분 주기 자동 갱신 + 새로고침 버튼 제공
- 헤더 우상단 **"재고 부족 N"** 배지로 현재 건수 상시 확인
- 부족분 (임계값 - 가용 수량) 을 빨간 배지로 강조 표시
- 임계값 설정은 MASTER / MANAGER 가 제품 상세에서 수행 (Phase 11+ 예정)

### 4-7. Stage 4 실시간 협업

재고 list 에 [수정 횟수 chip](../08-실시간-협업/03-수정-횟수-카운트.md) + [audit overlay](../08-실시간-협업/02-수정-이력-보기.md) 표시. 출고 진행 중인 lot 은 [잠금 banner](../08-실시간-협업/06-잠금-정책.md) 노출.

## 6. FAQ

**Q1. 가용 수량과 합계 차이는?**
A. 가용 = 합계 - 예약. 출고 슬립이 PICKING 진입 시 예약 증가, 가용 감소.

**Q2. 유효기간 만료 lot 은 자동 폐기되나요?**
A. 자동 폐기 미구현. 출고 자동 제외만. 실 폐기는 [05. 재고 실사](05-재고-실사.md) (P2-6 안내) 또는 IT 관리자 우회.

**Q3. 안전재고 알림은 어디서?**
A. 좌측 사이드바 **[창고 운영] > [안전재고 알림]** 에서 확인. 헤더 우상단 빨간 배지로 건수 상시 표시. P1-3 운영 중.

**Q4. Lot 별 출고 순서는?**
A. FIFO (선입선출) 자동. 입고일이 빠른 lot 우선 출고.

**Q5. 재고 차이 발생 시?**
A. 정식 재고 실사 UI (P2-6) 미구현. 임시로 IT 관리자에게 수기 보정 요청. [05. 재고 실사](05-재고-실사.md) 참조.
