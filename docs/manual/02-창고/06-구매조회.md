# 06. 구매조회 (상세)

## 1. 개요

구매조회(상세) 화면(`/purchases/query`)은 입고전표의 풍성한 컬럼을 제공하는 조회 전용 페이지입니다.
기존 구매조회(`/purchases`)는 전표 작성/상세 워크플로우 중심이며, 본 화면은 대량 조회·다중 선택·Excel 다운로드에 특화되어 있습니다.

접근 경로: 사이드바 "판매" 그룹 → "구매 조회 (상세)"

---

## 2. 날짜 범위 설정

- 기본값: 오늘 기준 ±15일 (Asia/Seoul)
- 직접 날짜 입력 또는 아래 preset 버튼 사용

| 버튼 | 범위 |
|---|---|
| 이번달 | 이번달 1일 ~ 말일 |
| 지난달 | 지난달 1일 ~ 말일 |
| 이번주 | 이번주 일요일 ~ 토요일 |

---

## 3. 컬럼 명세 (11개)

| # | 컬럼명 | 설명 |
|---|---|---|
| 1 | ☑ | 체크박스 (다중 선택 / 전체 선택) |
| 2 | 순번 | slipDate 내림차순 기준 행 번호 |
| 3 | 구매번호 | slipNo (사용자 노출 식별자) |
| 4 | 거래처 | partnerName |
| 5 | 거래처코드 | businessNumber (사업자등록번호) |
| 6 | 품목 | lineSummary 파생 (BE 미제공 시 "—") |
| 7 | 금액 | totalAmount (우측 정렬, 천 단위 콤마) |
| 8 | 수량합계 | totalQuantity (우측 정렬, 천 단위 콤마) |
| 9 | 입고창고 | destinationWarehouseId → 창고명 변환 |
| 10 | 적요 | memo |
| 11 | 비고 | memo (BE 분리 컬럼 추가 시 후속 갱신) |

> UUID(id, destinationWarehouseId 등)는 화면에 노출되지 않습니다.

---

## 4. 다중 선택

- 행 클릭 또는 체크박스 클릭으로 행 선택
- 선택된 행 배경: 파란 계열 (`#EFF6FF`)
- 헤더 체크박스: 현재 페이지 전체 선택/해제
- 선택 건수는 툴바에 "N행 선택됨"으로 표시

---

## 5. 검색 모달

툴바 우측 "검색" 버튼 클릭 시 검색 다이얼로그가 열립니다.

| 입력 필드 | 설명 |
|---|---|
| 구매번호 | slipNo 부분 검색 |
| 거래처명 | partnerName 부분 검색 |
| 거래처코드 (사업자번호) | businessNumber 검색 |

- "조회" 버튼: 검색 파라미터 적용, 1페이지로 이동, 모달 닫기
- "초기화" 버튼: 모든 검색 조건 초기화 후 재조회

---

## 6. 페이지네이션

- 50건/페이지 고정
- 이전/다음/처음/마지막/숫자 버튼으로 페이지 이동
- 페이지 이동 시 선택 상태 자동 초기화

---

## 7. 일괄 액션

| 액션 | 조건 | 설명 |
|---|---|---|
| 인쇄 | 1건 이상 선택 시 노출 | 브라우저 인쇄 실행 |
| Excel 다운로드 | 항상 노출 | 현재 날짜 범위의 전체 INBOUND 전표 Excel 저장 |
