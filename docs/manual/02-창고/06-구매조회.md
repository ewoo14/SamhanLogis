# 06. 구매조회

> **2026-05 메뉴 통합 (2a)**: 기존 `구매조회` (legacy 입고전표 list) + `구매조회(상세)` (rich query) 가 단일 메뉴로 통합되었습니다. 사이드바 최상단 **"구매조회"** 가 이제 본 화면(PurchaseQueryPage)으로 직행합니다.

## 1. 개요

구매조회 화면(`/purchases`)은 입고전표의 풍성한 컬럼을 제공하는 조회 전용 페이지입니다.
대량 조회 · 다중 선택 · Excel 다운로드에 특화되어 있습니다.

접근 경로: 사이드바 최상단 → **구매조회**

> 기존 deep-link `/purchases/query` 는 호환 alias 로 유지되며, 동일 화면으로 진입합니다.
> legacy SlipListPage (입고전표 작성/lifecycle 흐름) 는 `/purchases/slips` 로 이전되었으며 사이드바에서는 미노출입니다 — 2c 전표 작성 plumbing 합류 시 정식 진입점이 부활합니다.

---

## 2. 날짜 범위 설정

- 기본값: 오늘 기준 ±15일 (Asia/Seoul)
- 직접 날짜 입력 또는 아래 preset 버튼 사용

| 버튼 | 범위 |
|---|---|
| 이번달 | 이번달 1일 ~ 말일 |
| 지난달 | 지난달 1일 ~ 말일 |
| 이번주 | 이번주 일요일 ~ 토요일 |

---

## 3. 컬럼 명세 (11개)

| # | 컬럼명 | 설명 |
|---|---|---|
| 1 | ☑ | 체크박스 (다중 선택 / 전체 선택) |
| 2 | 순번 | slipDate 내림차순 기준 행 번호 |
| 3 | 구매번호 | slipNo (사용자 노출 식별자) |
| 4 | 거래처 | partnerName |
| 5 | 거래처코드 | businessNumber (사업자등록번호) |
| 6 | 품목 | lineSummary 파생 (BE 미제공 시 "—") |
| 7 | 금액 | totalAmount (우측 정렬, 천 단위 콤마) |
| 8 | 수량합계 | totalQuantity (우측 정렬, 천 단위 콤마) |
| 9 | 입고창고 | destinationWarehouseId → 창고명 변환 |
| 10 | 적요 | memo |
| 11 | 비고 | memo (BE 분리 컬럼 추가 시 후속 갱신) |

> UUID(id, destinationWarehouseId 등)는 화면에 노출되지 않습니다.

---

## 4. 다중 선택

- 행 클릭 또는 체크박스 클릭으로 행 선택
- 선택된 행 배경: 파란 계열 (`#EFF6FF`)
- 헤더 체크박스: 현재 페이지 전체 선택/해제
- 선택 건수는 툴바에 "N행 선택됨"으로 표시

---

## 5. 검색 모달

툴바 우측 "검색" 버튼 클릭 시 검색 다이얼로그가 열립니다.

| 입력 필드 | 설명 |
|---|---|
| 구매번호 | slipNo 부분 검색 |
| 거래처명 | partnerName 부분 검색 |
| 거래처코드 (사업자번호) | businessNumber 검색 |

- "조회" 버튼: 검색 파라미터 적용, 1페이지로 이동, 모달 닫기
- "초기화" 버튼: 모든 검색 조건 초기화 후 재조회

---

## 6. 페이지네이션

- 50건/페이지 고정
- 이전/다음/처음/마지막/숫자 버튼으로 페이지 이동
- 페이지 이동 시 선택 상태 자동 초기화

---

## 7. 일괄 액션 + 신규 전표

| 액션 | 조건 | 설명 |
|---|---|---|
| 인쇄 | 1건 이상 선택 시 노출 | 브라우저 인쇄 실행 |
| Excel 다운로드 | 항상 노출 | 현재 날짜 범위의 전체 INBOUND 전표 Excel 저장 |
| **신규 입고전표** | `SALES / MANAGER / MASTER` 권한 보유 시 노출 | `/purchases/new` (SlipFormPage) 로 이동 — 2c 백로그 완료 |

> 2a 메뉴 통합 이후 본 화면이 `/purchases` 정식 진입점이 되었습니다. 사이드바 "구매조회" 클릭 → 본 화면 → 우상단 **"신규 입고전표"** 버튼으로 신규 작성. (`data-testid=purchase-query-new-slip-btn`)
