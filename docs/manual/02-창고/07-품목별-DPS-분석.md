# 07. 품목별 DPS 분석

> **Stage**: Stage 1 ✅ — P0-B GAS 보강. 품목별 DPS 입고 pivot 화면 `/warehouse/dps-compare/by-product` 운영 중.

## 2. 대상 독자

- 입고 현황을 DPS 기록과 대조하는 창고 관리자 (WAREHOUSE)
- 전체 창고 현황을 모니터링하는 영업 부장 (MANAGER)
- 전사 재고 감사를 담당하는 시스템 관리자 (MASTER)

---

## 3. 학습 내용

- 사이드바 "창고 운영 > DPS 비교 > 품목별 DPS 분석" 진입 방법
- 날짜 범위 및 창고 조건 설정 후 조회
- DataGrid 8 컬럼 (입고 단계별 pivot) 의미 이해
- 음수 표시 (반품 수량·DPS 차이) 의미 파악
- 열헤더 필터 및 Ctrl+C 복사 활용

---

## 4. 사이드바 진입

| 단계 | 설명 |
| --- | --- |
| 1 | 좌측 사이드바 "창고 운영" 그룹 확인 |
| 2 | "DPS 입고 비교" 아래 들여쓰기 항목 "**품목별 DPS 분석**" 클릭 |
| 3 | `/warehouse/dps-compare/by-product` 페이지 로드 |

> **권한**: WAREHOUSE / MANAGER / MASTER 만 진입 가능. 권한 없는 ROLE 은 사이드바 항목이 회색(disabled) 처리됨.

---

## 5. 조회

### 5.1 날짜 범위 설정

- **조회 시작일**: 기본값 = Asia/Seoul 이번달 첫날 (YYYY-MM-01)
- **조회 종료일**: 기본값 = 오늘 (YYYY-MM-DD)
- 두 날짜를 조정 후 "조회" 버튼 클릭

### 5.2 창고 선택 (선택)

- 기본값 = **전체** (모든 창고 합산)
- 드롭다운에서 특정 창고 선택 시 해당 창고만 조회

### 5.3 조회 버튼

- 날짜 범위가 유효하면 BE `GET /warehouse/audit/dps-compare/by-product` 호출
- 시작일이 종료일보다 늦으면 오류 배너 표시

## 6. DataGrid 컬럼 의미

| 컬럼명 | 설명 | 비고 |
| --- | --- | --- |
| 상품코드 | 비즈니스 식별자 (사용자 노출 허용) | UUID 미노출 |
| 상품명 | 품목명 | 열헤더 text 필터 지원 |
| 입고대기 | PENDING 단계 수량 | 천 단위 콤마 |
| 완료 | COMPLETED 단계 수량 | 천 단위 콤마 |
| 품질검사 | QC 단계 수량 | 천 단위 콤마 |
| 반품 | RETURN 단계 수량 | **음수 시 빨강** |
| 합계 | 전 단계 합산 | 천 단위 콤마 |
| DPS차이 | DPS 기록 - 자사 입고합계 | **음수 시 빨강 + 굵게** |

> **음수 의미**: DPS차이 음수 = 자사 입고가 DPS 기록보다 많음 (초과 입고). 반품 음수 = 반품 차감 처리.

## 7. pivot 활용 방법

### 7.1 차이 컬럼 확인

1. "DPS차이" 컬럼에서 `0` 이외의 값 확인
2. 음수(빨강)는 초과 입고 → 입고 전표 재확인 필요
3. 양수는 DPS 미달 입고 → 미입고 품목 추적

### 7.2 Excel 복사 (Ctrl+C)

1. DataGrid 셀을 클릭하여 선택 (단일 / Shift+범위 / Ctrl+A 전체)
2. **Ctrl+C** → TSV 형식으로 클립보드 복사
3. Excel 에 **Ctrl+V** 붙여넣기 → 그대로 붙여넣기 (열 정렬 유지)

### 7.3 열헤더 필터

1. "상품코드" 또는 "상품명" 열 헤더의 깔때기(▼) 아이콘 클릭
2. 팝오버에서 포함 검색어 입력 후 "적용"
3. 일치 행만 표시 → 필요 품목 집중 분석

## 8. FAQ

**Q. 품목별 DPS 분석과 DPS 입고 비교(엑셀 업로드)의 차이는?**
A. DPS 입고 비교(엑셀 업로드)는 DPS 엑셀 파일을 직접 업로드하여 전표 단위/품목 단위로 mismatch 를 검출합니다. 품목별 DPS 분석은 BE 가 DPS 데이터를 자동 조회하여 품목별 단계별 수량을 pivot 표로 보여줍니다. 두 화면을 함께 사용하면 불일치 원인을 정확히 파악할 수 있습니다.

**Q. "DPS차이" 가 0 이 아닌 품목은 어떻게 처리하나요?**
A. 해당 품목의 입고 전표를 "DPS 입고 비교" 화면에서 상세 mismatch 분석 후 원인 파악 → 담당자에게 전달하거나 입고 전표를 수정 요청합니다.

**Q. 창고를 선택하지 않으면 어떤 데이터가 조회되나요?**
A. 모든 창고(본사창고, 차량재고, 위탁창고, 가상창고 포함)를 합산한 전체 품목별 현황이 표시됩니다.

**Q. 음수 반품 수량이 보이는 이유는?**
A. 반품 단계(RETURN)에서 차감 처리된 수량이 음수로 표현됩니다. 이는 정상 동작이며, 순 입고 합계에 반영됩니다.
