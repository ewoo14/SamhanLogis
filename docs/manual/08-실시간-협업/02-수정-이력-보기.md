- 모바일 long-press 사용법
- 적용 항목 / 미적용 항목 구분

## 4. 본문

### 4-1. 호버 진입

데이터 옆 / 위에 마우스 호버.

- 자동으로 popover 표시 (300ms 지연)
- popover 내용: 변경자 풀네임 / 시각 / 이전 값 → 새 값 / 사유

### 4-2. 시각 패턴

| 시각 요소 | 의미 |
| --- | --- |
| **취소선** | 이전 값 (변경됨) |
| **굵은 글씨** | 새 값 (현재) |
| **색상 dot** | 변경자별 색상 (개인 식별) |
| **풀네임** | 변경자 (UUID 비공개) |
| **시각** | YYYY-MM-DD HH:mm |
| **사유** | (있는 경우) |

### 4-3. 색상 dot 의미

각 변경자에게 자동 할당된 색상 dot.

- 본인: 파랑
- 다른 직원: 자동 색상 풀에서 할당 (빨강 / 초록 / 보라 등)
- 시스템 자동 분개: 회색

### 4-4. 모바일 long-press

mobile-staff 에서는 호버가 없으므로 long-press (1초 누름) 로 popover.

- 항목 1초 누름 → popover 표시
- 화면 다른 곳 탭 → popover 닫기

### 4-5. 변경 history 전체 조회

popover 하단 [전체 이력 보기] 클릭 시 history 전체 list dialog.

- 시간순 / 역시간순 정렬
- 필터 (변경자 / 항목 / 기간)
- 외부 감사 PDF 출력 (Phase 11+ 출시 예정)

### 4-6. 적용 항목

- 전표 모든 필드
- 거래처 master
- 재고 lot
- 분개 라인 (POSTED 후 변경 추적)
- 세금계산서 발행 history
- 배차 / 기사 배정
- 사용자 / 권한 (P0-5 출시 후)

### 4-7. 미적용 항목

- 회계 보고서 (read-only)
- legacy v2 WebView
- 시스템 메타데이터 (created_at 등)

## 6. FAQ

**Q1. 호버해도 안 떠요.**
A. (1) 마우스를 정확히 데이터 위에 두기. (2) 적용 항목인지 확인 ([09. 적용 범위](09-적용-범위.md)). (3) 안 되면 새로고침.

**Q2. 색상 dot 이 변경자별로 다른 이유?**
A. 시각 식별 보조. 본인 = 파랑 고정. 다른 직원은 자동 할당.

**Q3. 변경 이력을 영구 보관하나요?**
A. 한국 회계 표준상 5년 이상. 시스템상 무기한 보관.

**Q4. UUID 가 보이나요?**
A. 절대 안 보임. 풀네임 + 전표번호 등 비즈니스 식별자만 노출.

**Q5. 외부 감사용 PDF 는?**
A. Phase 11+ 출시 예정. 현재는 화면 캡처.

**Q6. 모바일에서 long-press 해도 안 떠요.**
A. 1초 이상 꾹 누름. 짧으면 일반 탭.
