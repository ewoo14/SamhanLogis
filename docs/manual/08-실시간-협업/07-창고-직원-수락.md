- 흐름을 모니터링하는 영업 부장 (MANAGER)

## 4. 본문

### 4-1. picking 중 잠금

WAREHOUSE 가 전표을 PICKING 진입 시 자동으로 2단계 잠금 (하드).

- 영업 직원은 전표 라인 직접 수정 불가
- 잠금 banner 노출

### 4-2. 영업 직원 수정 요청

영업 직원이 변경 필요 시.

1. 전표 상세 진입
2. 잠금 banner [수정 요청] 클릭 ([05. 수정 요청 워크플로우](05-수정-요청-워크플로우.md))
3. 사유 입력 (예: "거래처 추가 주문 5개")
4. [요청] 발송

### 4-3. 창고 직원 수락

WAREHOUSE 화면 (desktop 또는 mobile-staff).

#### desktop

1. 헤더 종 아이콘 배지 + 토스트
2. 전표 상세 진입
3. 화면 상단 [수정 요청] banner
4. [수락] 또는 [거절] 클릭

#### mobile-staff

1. 푸시 알림 + 토스트
2. 알림 클릭 → 전표 상세
3. [수락] / [거절]

### 4-4. 수락 시 동작

[수락] 클릭.

- picking 일시 중지
- 잠금 해제 → 영업 직원 편집 가능
- 영업 직원에게 SSE 알림
- 영업 직원이 수정 완료 후 [완료] → 창고 직원 picking 재개

### 4-5. 거절 시 동작

[거절] + 사유 입력.

- picking 계속 진행
- 영업 직원에게 SSE 알림 + 거절 사유

### 4-6. 재고 영향

- 수락 → 재고 reserve 일시 release
- 거절 → reserve 유지
- 수정 후 재 picking → 재 reserve

### 4-7. 모바일 long-press

mobile-staff 에서 항목 long-press → audit overlay 진입 후 수락/거절 dialog.

## 6. FAQ

**Q1. picking 중에 자주 수정 요청이 오면?**
A. 영업 부장 코칭. 영업 직원이 전표 사전 검토 강화.

**Q2. 창고 직원이 수락 / 거절 안 하면?**
A. 30분 자동 만료. 영업 직원 재요청.

**Q3. 거절 사유가 필수인가요?**
A. 권장. 영업 직원이 사유 확인 후 다른 전표으로 재발행 가능.

**Q4. 모바일에서 수락 빠르게?**
A. 푸시 알림 → 알림 탭 → [수락] 1탭.

**Q5. 수락 후 picking 재개 시 재고는?**
A. 자동 재 reserve. 변경 후 수량 / 라인 기준.

**Q6. 다른 service (예: 회계) 도 같은 흐름?**
A. 전표이 대표. 다른 service 도 PR-H4b 부터 동일 패턴 적용.
