## 3. 학습 내용

- 복원 진입 (audit overlay 호버 → 드롭다운)

- 복원 사유 입력 + 확인
- 복원 history 별도 추적

---

## 4. 본문

### 4-1. 복원 진입

#### 단계 1 — Audit overlay 호버

데이터 위에 호버하여 [02. 수정 이력 보기](02-수정-이력-보기.md) popover 표시.

#### 단계 2 — 변경 행에서 [복원] 드롭다운

각 변경 행 우측에 ⋮ 또는 [복원] 드롭다운.

- MASTER + MANAGER 만 표시
- 다른 ROLE 은 미노출 (드롭다운 자체 없음)

#### 단계 3 — 복원 사유 입력 + 확인

[복원] 클릭 시 사유 입력 dialog.

- 사유: 필수 (자유 입력)
- 영향 항목 미리보기 (어떤 필드가 어떤 값으로 되돌아가는지)
- [확인] 클릭 시 즉시 복원

### 4-2. 복원 후 동작

- 데이터 즉시 이전 값으로 변경
- audit history 에 "[복원] 김미선 님이 SLIP-2026-0001 라인 1 수량을 8 → 5 (이전 값) 로 복원" 기록
- SSE 로 다른 직원 화면 1초 이내 갱신
- 복원 자체도 변경 횟수 +1 카운트

### 4-3. 복원 가능 항목

audit 적용 모든 항목.

- 전표 라인 / 헤더
- 거래처 필드
- 재고 lot 정보
- 분개 (POSTED 전)
- 세금계산서
- 배차 / 기사 배정

### 4-4. 복원 불가 항목

- POSTED 분개 (역분개 권장)
- DELIVERED 전표 (CANCELED 권장)
- 시스템 메타데이터 (created_at)

### 4-5. 권한 검증

| ROLE | 복원 가능 |
| --- | --- |
| MASTER | ✅ 모든 항목 |
| MANAGER | ✅ 본 부서 항목만 (영업/창고/회계 분리) |
| 다른 ROLE | ❌ 드롭다운 미노출 |

### 4-6. 복원 history 별도 audit

복원도 audit 이벤트로 기록 + 변경 횟수 카운트 +1. 외부 감사 시 추적 가능.

## 6. FAQ

**Q1. SALES 가 본인 전표을 복원할 수 있나요?**
A. 불가. SALES 는 [복원] 드롭다운 미노출. 영업 부장에게 요청.

**Q2. POSTED 분개 복원은?**
A. 불가. [VOID] 처리 + 역분개 자동 발행 + 신규 분개 등록.

**Q3. 여러 변경을 한 번에 복원?**
A. 1건씩 처리. 일괄 복원 미구현.

**Q4. 복원 후 다시 원래 값으로?**
A. 가능. 신규 변경으로 카운트 +1.

**Q5. 복원이 다른 직원에게 어떻게 보이나요?**
A. SSE 토스트로 1초 이내 알림 ([01. 실시간 동기화](01-실시간-동기화.md)).

**Q6. 권한 부족 메시지?**
A. 드롭다운 자체가 안 보이므로 시도 자체 불가. 영업 부장 / IT 관리자 요청.
