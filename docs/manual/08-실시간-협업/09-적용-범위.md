## 6. FAQ

**Q1. 어느 page 에 적용되었는지 빠르게 확인?**
A. 화면 우측 상단에 SSE 연결 indicator 또는 audit chip 노출 시 적용. 4-3 카테고리 표 참조.

**Q2. 미적용 page 에서 동시 편집 충돌 시?**
A. 일반 충돌 처리 (마지막 저장이 덮어씀). 가능하면 적용 page 에서 작업 권장.

**Q3. legacy v2 WebView 도 적용 예정?**
A. 미예정. legacy 마이그레이션 (Phase 11+) 후 신규 native UI 에 적용.

**Q4. 신규 service 개발 시 어떻게?**
A. shared-realtime module import + 표준 hook 사용. IT 관리자 / 개발팀 가이드.

**Q5. 적용 / 미적용 service 추가 변경 가능?**
A. 본 매트릭스는 Phase 12 시리즈 종결 시점. 향후 변경 시 본 docs 갱신.
