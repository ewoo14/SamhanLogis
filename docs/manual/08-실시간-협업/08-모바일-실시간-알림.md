## 4. 본문

### 4-1. 8 이벤트 종류

| # | 이벤트 | 발생 조건 | 알림 형태 |
| --- | --- | --- | --- |
| 1 | 전표 신규 배차 | DISPATCH 가 본인 배정 | 푸시 + 토스트 |
| 2 | 전표 변경 | 영업 직원이 라인 수정 | 푸시 + 토스트 |
| 3 | 검수 결과 | WAREHOUSE 가 검수 (P0-9 후) | 토스트 |
| 4 | 수정 요청 | 영업 → 창고 (picking 중) | 푸시 + 토스트 |
| 5 | 수정 수락 | 창고 → 영업 | 푸시 + 토스트 |
| 6 | 수정 거절 | 창고 → 영업 | 푸시 + 토스트 |
| 7 | 요청 만료 | 30분 무응답 | 토스트 |
| 8 | 전표 취소 | CANCELED 처리 | 푸시 + 토스트 |

### 4-2. 푸시 알림 권한 허용

#### Android

1. 설정 > 앱 > Samhan Public > 알림
2. "알림 표시" 켜기
3. 모든 채널 허용

#### iOS

1. 설정 > 알림 > Samhan Public
2. "알림 허용" 켜기
3. 배너 / 사운드 / 배지 모두 켜기

### 4-3. 토스트 표시

화면 상단 4 ~ 6초간 토스트.

```
[배차] 본사창고 → A거래처 배송 (SLIP-2026-0001) — 13:30 출발
```

탭 시 해당 전표 상세로 이동.

### 4-4. 사일런트 모드 / 방해 금지 모드

- 사일런트: 진동만
- 방해 금지: 알림 차단 가능
- 업무 시간 중 방해 금지 해제 권장

### 4-5. 알림 history

헤더 종 아이콘 → 알림 list dialog.

- 미확인 알림 배지
- 시간순 list
- 항목 탭 시 해당 화면 이동

### 4-6. 알림 끄기 (긴급)

너무 많은 알림 시.

- OS 설정 > 알림 채널별 분리 (지원 OS)
- 운전 중 사일런트 모드 자동 (자동차 모드)

### 4-7. 모바일 long-press = audit overlay

알림 list 항목 long-press → audit overlay popover ([02. 수정 이력 보기](02-수정-이력-보기.md)).

## 6. FAQ

**Q1. 푸시가 안 와요.**
A. (1) OS 알림 권한. (2) 사일런트 / 방해 금지 모드. (3) 앱 강제 종료 시 일부 OS 푸시 차단. 백그라운드 유지 권장.

**Q2. 푸시는 오는데 토스트가 안 떠요.**
A. 앱이 백그라운드 상태 = 푸시만, 포어그라운드 상태 = 토스트.

**Q3. 알림이 너무 많아요.**
A. 본인 배정 전표 만 알림. 다른 직원의 전표은 알림 안 옴. 그래도 많으면 IT 관리자에게 정책 조정 요청.

**Q4. 카톡처럼 알림 history 가 사라져요.**
A. OS 알림 영역만 사라짐. 앱 내 종 아이콘 list 는 영구 보관.

**Q5. 모바일에서 수정 요청 처리?**
A. 가능. [07. 창고 직원 수락](07-창고-직원-수락.md) 참조.

**Q6. 이메일 / 카톡 알림은?**
A. 현재 앱 푸시 알림 운영 중. 이메일/카카오톡 외부 채널 알림은 장기 backlog 입니다.
