## 4. 본문

### 4-1. 화면의 3대 영역

로그인 직후 표시되는 메인 화면은 다음 3개 영역으로 구성됩니다.

| 영역 | 위치 | 역할 |
| --- | --- | --- |
| **상단 헤더** | 화면 최상단 | 시스템 로고 / 알림 / 사용자 메뉴 |
| **좌측 사이드바** | 화면 좌측 | 카테고리별 메뉴 트리 (ROLE 별 차이) |
| **본문 영역** | 화면 가운데 ~ 우측 | 메뉴 클릭 시 페이지 전환 |

### 4-2. 상단 헤더

상단 헤더는 항상 화면 최상단에 고정 표시됩니다.

- **좌측**: Samhan Public 로고 (클릭 시 메인 대시보드로 이동)
- **우측**: 알림(종 모양 아이콘) / 본인 이름 / 드롭다운 메뉴
- **알림 배지**: 미확인 알림이 있을 경우 숫자 배지가 표시됩니다.
- **사용자 드롭다운**: 본인 이름 클릭 시 [내 정보] / [로그아웃] 메뉴 표시

### 4-3. 좌측 사이드바

좌측 사이드바는 본인의 ROLE 에 맞는 메뉴 트리만 표시합니다. ROLE 별 메뉴 차이는 [03. 역할별 화면 차이](03-역할별-권한.md) 를 참조하세요.

대표 메뉴 카테고리:

- **영업** — 거래처 / 전표 / 견적
- **창고** — 입고 / 출고 / 재고 / 매출 마감 / 재고 실사
- **회계** — 분개 / 보고서 / 세금계산서 / 월말 마감
- **배차(arologis)** — 카카오 / 수동 배차 / 기사 배정
- **모바일** — 기사 앱 / 영업 앱
- **관리(MASTER 만)** — 사용자 / 권한 / 시스템 설정

### 4-4. 본문 영역

좌측 사이드바에서 메뉴를 클릭하면 본문 영역에 해당 페이지가 표시됩니다.

- 페이지 상단에 현재 위치(빵부스러기 navigation)가 표시됩니다.
- 페이지 우측 상단에는 [신규 등록] / [엑셀 다운로드] 등의 액션 버튼이 표시됩니다.
- 페이지 하단에는 페이지네이션 / 정렬 / 필터 옵션이 표시됩니다.

### 4-5. 실시간 협업 (Stage 4)

Phase 12 시리즈 적용 후, 본문 영역의 모든 list / 상세 / 폼 화면에는 다음 패턴이 공통 노출됩니다.

- **수정 횟수 chip** — 항목 옆 색상 chip (0=회색 / 1~4=파랑 / 5~9=주황 / 10+=빨강)
- **audit overlay** — 호버 시 변경 이력 popover (취소선 + 풀네임 + 색상 dot)
- **잠금 banner** — 다른 직원이 잠금 중인 항목은 상단 banner 표시
- **SSE 토스트** — 다른 직원의 변경 사항이 1초 이내 화면에 자동 갱신

자세한 안내는 [08-실시간-협업 / 00. 개요](../08-실시간-협업/00-실시간-협업-개요.md) 를 참조하세요.

## 6. FAQ

**Q1. 메뉴가 보이지 않습니다.**
A. 본인의 ROLE 에 따라 표시되는 메뉴가 다릅니다. 예를 들어 SALES 권한자는 회계 메뉴를 볼 수 없습니다. 필요한 메뉴가 보이지 않으면 IT 관리자에게 권한 추가를 요청하세요.

**Q2. 알림 배지의 숫자는 무엇인가요?**
A. 본인이 아직 확인하지 않은 알림(전표 결재 요청 / 수정 요청 / 시스템 공지 등)의 개수입니다. 종 아이콘 클릭 시 알림 list 가 표시됩니다.

**Q3. 화면 색상이 갑자기 바뀌었어요.**
A. 시스템 공지나 긴급 안내가 있을 때 헤더 색상이 바뀔 수 있습니다. 종 아이콘으로 알림을 확인하세요.

**Q4. 사이드바를 접고 싶어요.**
A. 사이드바 상단의 햄버거(≡) 아이콘 클릭 시 사이드바가 축소됩니다. 본문 영역이 더 넓게 표시됩니다.

**Q5. 빠른 검색은 어디에 있나요?**
A. 각 list 페이지(거래처/전표/재고/분개 등) 상단에 검색 박스가 있어 기본 검색이 운영 중입니다. 전체 화면 통합 검색(헤더 단일 박스)은 P3 backlog 입니다.
