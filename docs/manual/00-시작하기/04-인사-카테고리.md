## 4. 본문

### 4-1. 인사 카테고리 진입 조건

인사 카테고리는 다음 두 조건을 **동시에 만족**해야 접근할 수 있습니다.

| 조건 | 설명 |
| --- | --- |
| **MASTER ROLE** | 시스템 최고 권한자 ROLE |
| **대표실 부서 소속** | user-service 의 부서 정보가 '대표실' 인 경우 |

진입 시 BE `GET /api/v1/users/me/is-executive-office` 를 자동 호출하여 두 조건을 검증합니다. 조건 불만족 시 403 접근 거부 화면으로 이동합니다.

### 4-2. 인사 메뉴와 quick link

| 번호 | 메뉴명 | 경로 | 설명 |
| --- | --- | --- | --- |
| 1 | 신규 인사 | `/admin/users/new` | 신규 직원 계정 생성 (임시 비밀번호 발급) |
| 2 | 권한 조정 | `/admin/roles` | 직원 ROLE 변경 + 변경 이력 조회 |
| 3 | 부서 | `/admin/departments` | 부서 목록 조회 / 부서 코드 관리 |
| 4 | 단톡방 매핑 | `/admin/chat-rooms` | 카카오 단톡방 ↔ 부서/배차 그룹 매핑 |
| 5 | 거래처 DC 설정 | `/sales/partner-dc-config` | 거래처별 DC율 CSV 일괄 설정 |
| 6 | 거래처 관리 | `/admin/partners` | 공용 거래처 관리 화면으로 이동 (`SALES / MANAGER / MASTER`) |
| 7 | 창고 | `/admin/warehouses` | 창고 등록 / 코드 / 유형 관리 |

### 4-3. 사이드바 disabled UX

권한이 없는 메뉴는 **숨기지 않고 회색으로 표시**합니다.

- 텍스트 색상: 회색 (`#94A3B8`)
- 클릭 차단: `pointer-events: none` + `onClick preventDefault`
- 마우스 오버 tooltip: "대표실 부서 권한자만 접근 가능" 또는 "권한이 없습니다 (필요 ROLE: XXX)"
- 스크린리더: `aria-disabled="true"` 적용

이 정책은 전체 사이드바(영업/창고/회계/배차/메신저/설정/인사 카테고리)에 동일하게 적용됩니다.

### 4-4. 403 접근 거부 화면

MASTER 이지만 대표실 부서 미소속인 경우, 인사 카테고리 진입 시 다음 화면이 표시됩니다.

> **"인사 카테고리는 대표실 부서 소속 + MASTER 권한자만 접근할 수 있습니다."**

[대시보드로 돌아가기] 버튼을 클릭하면 메인 대시보드로 이동합니다.

### 4-5. 신규 인사 등록 흐름

1. 사이드바 [신규 인사] 클릭 → `/admin/users/new` 진입
2. 로그인 ID / 이름 / 이메일 / ROLE / 부서 입력
3. 등록 완료 시 임시 비밀번호가 한 번만 표시됩니다.
4. 신규 직원은 첫 로그인 후 비밀번호 변경이 강제됩니다.

> UUID 비공개 가드: 직원 ID(UUID)는 화면에 표시되지 않습니다. 식별자는 loginId / fullName 을 사용하세요. (memory `feedback_uuid_no_user_visibility`)

## 6. FAQ

**Q1. MASTER 인데 인사 카테고리가 비활성(회색)입니다.**
A. 대표실 부서 소속 조건이 누락된 경우입니다. IT 관리자에게 부서 배정을 요청하세요.

**Q2. 사이드바에서 메뉴가 회색인데 이전에는 안 보였습니다.**
A. PR-HR 슬라이스부터 권한 없는 메뉴는 숨기지 않고 회색으로 표시합니다. 마우스 오버 시 필요 권한 안내가 표시됩니다.

**Q3. 단톡방 매핑은 MANAGER 도 접근 가능하지 않았나요?**
A. AppLayout 의 "알림 매핑" 카테고리를 통해 MANAGER 도 `/admin/chat-rooms` 에 접근할 수 있습니다. 인사 카테고리는 MASTER + 대표실 전용입니다.

**Q4. 거래처 DC 설정이 인사 카테고리에 있는 이유는?**
A. 거래처 DC 설정의 CSV 일괄 업로드는 MASTER 전용 기능입니다. 영업 카테고리에서는 조회/단건 설정, 인사 카테고리에서는 CSV 일괄 처리를 담당합니다.
