## 4. 본문

### 4-1. 자주 발생하는 원인

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| "아이디 또는 비밀번호가 일치하지 않습니다" | ID 대소문자 / 한영 키 / Caps Lock | 재입력 (3회 이내) |
| 입력 후 무반응 | 네트워크 / 서버 다운 | 새로고침 → IT 관리자 |
| 5회 실패 후 잠김 | 잠금 정책 작동 | IT 관리자 잠금 해제 요청 |
| 첫 로그인 후 비밀번호 변경 화면 무반응 | 비밀번호 정책 미충족 | 영문+숫자+특수문자 8자 이상 |
| 모바일 로그인만 안 됨 | 앱 캐시 / 권한 | [04. 모바일 접속 오류](04-모바일-접속-오류.md) |

### 4-2. 5회 실패 잠금 해제

#### 단계 1 — 잠금 확인

5회 실패 후 다음 메시지 표시.

> "5회 연속 실패로 계정이 일시 잠겼습니다. IT 관리자에게 문의하세요."

#### 단계 2 — MASTER(IT 관리자) 잠금 해제 (UI)

1. MASTER 계정으로 로그인
2. 좌측 메뉴 **관리자 → 사용자 관리** 이동
3. 잠긴 사용자 행의 상태 열에 "잠금" Badge 확인
4. 해당 행에서 **[잠금 해제]** 버튼 클릭 → 확인 대화상자 확인
5. 상태가 "활성"으로 즉시 변경됨

> MASTER 계정이 없는 경우 운영팀 대표자에게 연락.

#### 단계 3 — 재로그인

1. 잠금 해제 후 ID + 비밀번호 재입력
2. 비밀번호 분실 시 §4-3 절차

### 4-3. 비밀번호 분실

로그인 화면 **[비밀번호를 잊으셨나요?]** 링크를 통한 셀프 재설정 사용 가능 (P0-2 출시 완료).

#### 단계 1 — 셀프 재설정 요청

1. 로그인 화면에서 **[비밀번호를 잊으셨나요?]** 링크 클릭
2. 로그인 ID 와 가입 이메일 입력
3. **[인증번호 받기]** 클릭 → 이메일로 6자리 인증번호 발송

#### 단계 2 — 인증번호 입력 + 새 비밀번호 설정

1. 이메일로 받은 6자리 인증번호 입력 (10분 이내)
2. 새 비밀번호 입력 (8자 이상, 영문+숫자+특수문자)
3. **[비밀번호 재설정]** 클릭 → 로그인 화면으로 자동 이동

#### 셀프 재설정 불가 시 — MASTER(IT 관리자) 우회

1. 본인 ID + 부서 + 휴대전화로 IT 관리자에게 사내 메신저 / 전화
2. MASTER 가 **관리자 → 사용자 관리** → 해당 사용자 행 **[수정]** 버튼으로 이메일 확인
3. 필요 시 초기화 후 임시 비밀번호 직접 전달

### 4-4. 비밀번호 정책

- 영문 대/소문자 + 숫자 + 특수문자 조합 8자 이상 권장
- 너무 단순 (`12345678`, `password`) 거부 가능
- 본인 ID, 휴대전화, 생년월일 포함 거부 권장
- 모니터에 메모 부착 절대 금지

### 4-5. 셀프 재설정 및 사용자 관리 UI (운영 완료)

P0-2 셀프 비밀번호 재설정 및 P0-5 사용자/권한 관리 UI 가 출시되었습니다.

- 이메일 인증 6자리 코드 → 비밀번호 셀프 변경 (P0-2)
- MASTER 전용 사용자 관리: 신규 등록 / 정보 수정 / 권한 변경 / 잠금 해제 / 탈퇴 처리 (P0-5)

## 6. FAQ

**Q1. 본인이 직접 비밀번호를 변경할 수 있나요?**
A. 네. 로그인 화면 하단 **[비밀번호를 잊으셨나요?]** 링크로 셀프 재설정 가능합니다. 첫 로그인 시에도 자동 변경 화면이 표시됩니다.

**Q2. 잠금 해제까지 시간이?**
A. MASTER 권한 관리자가 "사용자 관리" 화면에서 즉시 처리 가능합니다. 평일 업무 시간 내 30분 이내 권고.

**Q3. 비밀번호가 만료되나요?**
A. 만료 정책 미구현. 회사 보안 정책상 6개월 ~ 1년 자율 변경 권장.

**Q4. 모바일 로그인은 ID 만 다른가요?**
A. 동일 ID/PW. mobile-staff 앱 / desktop 동일 인증.

**Q5. 다른 사람 ID 로 로그인 가능?**
A. 절대 금지. 보안 정책 위반.

**Q6. 5회 실패 후 즉시 다시 시도?**
A. 잠금 정책 작동. IT 관리자 우회 필수.
