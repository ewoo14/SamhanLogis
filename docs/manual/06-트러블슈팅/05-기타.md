## 4. 본문

### 4-1. 권한 부족 메시지

> "권한이 없습니다. 관리자에게 문의하세요."

본인 ROLE 로 접근 / 액션 불가. 처리 절차.

1. 본인 ROLE 확인 (우측 상단 본인 이름 > [내 정보])
2. 필요 ROLE 확인 ([00-시작하기 / 03. 역할별 권한](../00-시작하기/03-역할별-권한.md))
3. ROLE 추가 필요 시 IT 관리자 / 인사 담당자에게 신청서 제출

### 4-2. 세션 자동 만료

30분 무활동 시 자동 로그아웃.

- 작성 중 데이터 손실 위험 → 임시저장 자주 활용
- 다음 로그인 시 임시저장 데이터 복구 가능 (DRAFT 상태)

### 4-3. 알림 (종 아이콘) 동작

| 알림 유형 | 발생 조건 |
| --- | --- |
| 결재 요청 | 영업 부장 / MANAGER |
| 결재 결과 (승인/반려) | 영업 직원 / SALES |
| 수정 요청 | 잠금 해제 권한자 |
| 시스템 공지 | MASTER 발송 |
| 푸시 알림 (모바일) | 배차 / 전표 변경 |

종 아이콘 클릭 시 알림 list 표시. 클릭 시 해당 페이지 자동 이동.

### 4-4. 검색 결과 0건

| 가능 원인 | 조치 |
| --- | --- |
| 키워드 오타 | 키워드 단순화 |
| 비활성 (사용 여부=N) 항목 미포함 | 필터에서 비활성 포함 |
| 본인 ROLE 권한 외 | IT 관리자 |
| 다른 부서 / 다른 거래처 | 검색 범위 확장 |
| 최근 등록 직후 | 새로고침 (F5) |

### 4-5. 데이터 변경이 안 보일 때 (Stage 4)

Phase 12 시리즈 적용 후 데이터 변경 시 SSE 로 1초 이내 자동 반영. 안 보이면.

1. 새로고침 (F5)
2. SSE 연결 status 확인 (헤더 또는 [실시간 동기화](../08-실시간-협업/01-실시간-동기화.md))
3. 안 되면 로그아웃 → 재로그인
4. 안 되면 IT 관리자

### 4-6. 한국어 깨짐 / 글꼴

OS 한국어 언어팩 미설치 가능.

#### Windows

1. 설정 > 시간 및 언어 > 언어 > 언어 추가 > 한국어
2. 한국어 글꼴 (맑은 고딕) 자동 설치
3. 브라우저 재시작

#### macOS

1. 시스템 환경설정 > 언어 및 지역 > 한국어 추가
2. 브라우저 재시작

### 4-7. 시스템 공지 / 점검 알림

MASTER 가 시스템 점검 / 긴급 공지 발송 시 헤더 색상 변경 + 종 배지 + 팝업 표시. 즉시 확인 권장.

### 4-8. 본인 정보 변경

이름 / 부서 / 휴대전화 등 변경.

- 정식 사용자/권한 관리 화면 운영 중 (PR #140 ✅).
- 좌측 사이드바 **[관리]** > **[사용자 관리]** 진입 후 본인 행 클릭 → [편집] 으로 직접 수정 가능 (MASTER 역할) 또는 MASTER 에게 수정 요청.

## 6. FAQ

**Q1. 30분 자동 만료가 너무 짧아요.**
A. 보안 정책. 변경 불가. 임시저장 자주 활용.

**Q2. 검색이 부분 일치 안 됩니다.**
A. 페이지마다 검색 정책 다름. 일부는 정확 일치 / 일부는 부분 일치. 단순화 시도.

**Q3. 알림을 모두 읽었는데 배지가 남아요.**
A. 새로고침. 안 되면 알림 list 진입 후 [모두 읽음] 클릭.

**Q4. 시스템 공지를 못 봤어요.**
A. 알림 list 에 누적. 종 아이콘 클릭 후 history 확인.

**Q5. 본인 정보 변경은 어떻게?**
A. 정식 사용자/권한 관리 화면이 운영 중입니다 (PR #140 ✅). MASTER 는 [관리] > [사용자 관리] 에서 직접 수정. 일반 직원은 MASTER 에게 수정 요청.

**Q6. 동시 같은 데이터 수정 시 충돌?**
A. Stage 4 [잠금 정책](../08-실시간-협업/06-잠금-정책.md) 으로 보호. 잠금 banner 표시 시 [수정 요청 워크플로우](../08-실시간-협업/05-수정-요청-워크플로우.md) 사용.
