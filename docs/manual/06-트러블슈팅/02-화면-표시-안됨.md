# 02. 화면이 표시되지 않음 / 빈 화면

> **Stage 안내**: Stage 3 ✅ — Phase 12 step-6 본 PR 에서 7-section 패턴으로 재작성.

---

## 1. 구현 상태

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| Gateway / service health check | ✅ 운영 | `/actuator/health` |
| Service 자동 재시작 | ⏳ 부분 | Phase 11 EC2 Auto Recovery |
| 새로고침 / 로그아웃 우회 | ✅ 권장 | 클라이언트 측 |

(주)삼한공조시스템 화면이 표시되지 않거나 빈 화면 발생 시 대처 절차.

---

## 2. 대상 독자

- desktop electron-vite 사용자 (모든 ROLE)
- 클라이언트 측 1차 진단을 진행하는 본인
- 서버 측 진단을 보조하는 IT 관리자 (MASTER)

---

## 3. 학습 내용

- 빈 화면 발생 자주 패턴
- 새로고침 / 로그아웃 / 캐시 삭제 1차 우회
- IT 관리자 호출 시점 (서버 다운 의심)
- gateway / service 별 health check 확인

---

## 4. 본문

### 4-1. 자주 발생 패턴

| 증상 | 1차 진단 | 조치 |
| --- | --- | --- |
| 메뉴 클릭 후 빈 화면 | 새로고침 (F5) | 해결 안 되면 §4-2 |
| 로그인 직후 메인 화면이 비어 있음 | 권한 / ROLE | IT 관리자 |
| list 표시되다 갑자기 사라짐 | 세션 만료 | 재로그인 |
| 로딩 spinner 만 무한 표시 | 서버 응답 없음 | §4-3 |
| 한글이 □ 로 표시 | 글꼴 / 인코딩 | 브라우저 / OS 글꼴 |

### 4-2. 1차 우회 — 새로고침 / 로그아웃

1. **새로고침** (F5 또는 Ctrl+R)
2. 안 되면 **로그아웃** → **재로그인**
3. 안 되면 **브라우저 캐시 삭제** (Ctrl+Shift+Del → 캐시 삭제)
4. 안 되면 **다른 브라우저** 시도 (Edge ↔ Chrome)
5. 안 되면 §4-3 IT 관리자

### 4-3. IT 관리자 호출

1차 우회 모두 실패 시.

#### 본인 측 정보 수집 (IT 관리자 전달용)

- 본인 ID
- 사용 화면 (예: "영업 > 전표 > 신규 등록")
- 발생 시각 (YYYY-MM-DD HH:mm)
- 에러 메시지 (있는 경우 캡처)
- 사용 브라우저 + 버전 (Edge / Chrome / Firefox)
- OS (Windows / macOS)

#### IT 관리자 측 진단

1. gateway 헬스 체크: `GET /actuator/health`
2. 해당 service 헬스 체크 (예: slip-service `/actuator/health`)
3. service 로그 확인
4. 필요시 service 재시작

### 4-4. Service 별 health check URL

| Service | URL |
| --- | --- |
| gateway | `/actuator/health` |
| auth | `/api/auth/actuator/health` |
| slip | `/api/slip/actuator/health` |
| inventory | `/api/inventory/actuator/health` |
| accounting | `/api/accounting/actuator/health` |
| arologis | `/api/arologis/actuator/health` |
| (각 service) | `/api/{service}/actuator/health` |

### 4-5. EC2 Auto Recovery (Phase 11 ✅)

AWS 마이그레이션 (Phase 11, PR #152) 완료 후 EC2 Auto Recovery + Health Check Lambda 가 적용되어 service 다운 시 자동 복구됩니다. 자동 복구가 되지 않는 경우 IT 관리자에게 연락하세요.

## 6. FAQ

**Q1. 새로고침해도 안 되면?**
A. 로그아웃 → 재로그인 → 캐시 삭제 순서로 시도. 안 되면 IT 관리자.

**Q2. 권한 ROLE 변경 직후 빈 화면?**
A. 다음 로그인부터 적용. 현재 세션은 이전 ROLE 유지.

**Q3. 한글이 □ 로 표시?**
A. 브라우저 글꼴 설정 → 한국어 글꼴 (맑은 고딕 등) 선택. OS 가 한국어 미설치 시 한국어 언어팩 설치.

**Q4. service 다운 시 다른 service 도 영향?**
A. gateway 가 fallback 처리. 일부 페이지만 영향. 전체 다운은 gateway 자체.

**Q5. 자동 복구는 언제?**
A. Phase 11 진입 후 EC2 Auto Recovery + Health Check Lambda 적용 예정.
