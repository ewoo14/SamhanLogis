## 4. 본문

### 4-1. 자주 발생 패턴

| 증상 | 1차 진단 | 조치 |
| --- | --- | --- |
| 앱 시작 직후 흰 화면 | 앱 캐시 / 업데이트 | §4-2 |
| 로그인 후 401 | 토큰 만료 / 권한 | 로그아웃 → 재로그인 |
| GPS 화면 (GpsBlocked) | GPS 권한 거부 | 설정 > 권한 |
| WebView 안 뜸 | legacy 서버 / 네트워크 | IT 관리자 |
| 푸시 알림 안 옴 | 푸시 권한 / 토큰 | §4-4 |
| 카메라 / 사진 첨부 안 됨 | 카메라 권한 + P1 미구현 | [04-모바일 / 04. 사진 첨부](../04-모바일/04-사진-첨부.md) |

### 4-2. 1차 우회 — 앱 재시작 / 캐시 삭제

1. 앱 강제 종료 (백그라운드 제거)
2. 다시 실행
3. 안 되면 앱 캐시 삭제 (Android: 설정 > 앱 > Samhan Public > 저장소 > 캐시 삭제)
4. 안 되면 앱 재설치
5. 안 되면 §4-5 IT 관리자

### 4-3. 401 (인증 만료) 대처

자동 로그아웃 또는 토큰 만료.

1. 좌측 상단 메뉴 > 로그아웃
2. 재로그인
3. 동일 증상 시 비밀번호 변경 가능성 — IT 관리자 확인

### 4-4. GPS / 카메라 권한 재허용

#### Android

1. 설정 > 앱 > Samhan Public
2. 권한 > 위치 > 항상 허용 또는 앱 사용 시 허용
3. 권한 > 카메라 > 허용
4. 앱 재시작

#### iOS

1. 설정 > Samhan Public
2. 위치 / 카메라 > 허용
3. 앱 재시작

### 4-5. IT 관리자 호출

#### 본인 측 정보 수집

- 본인 ID
- 사용 OS (Android / iOS) + 버전
- 앱 버전 (설정 화면에서 확인)
- 발생 시각 + 에러 메시지 (있는 경우 캡처)
- 네트워크 (Wi-Fi / LTE / 5G)

#### IT 관리자 측 진단

- mobile-staff 빌드 버전
- gateway / service health check
- 사용자 토큰 status
- 필요시 비밀번호 초기화 / 토큰 재발급

### 4-6. 도메인 안내

## 6. FAQ

**Q1. 앱 업데이트는 자동인가요?**
A. Google Play / App Store 자동 업데이트. Expo OTA 업데이트는 앱 시작 시 자동 적용.

**Q2. 인터넷 끊긴 곳에서 사용 가능?**
A. 일시 보관 + 재연결 시 동기화 일부 지원. 단, 신규 전표 / 서명 등은 실시간 인터넷 필요.

**Q3. 앱이 자주 멈춰요.**
A. OS 백업 + 앱 재설치 권장. 안 되면 IT 관리자에게 OS 버전 / 기기 모델 정보 전달.

**Q4. legacy WebView 가 안 뜨면?**
A. legacy v2 서버 (port 5183) 다운 가능. IT 관리자에게 즉시 문의.

**Q5. 푸시 알림이 안 옵니다.**
A. (1) 앱 권한 > 알림 허용. (2) OS 설정 > 알림 > Samhan Public 허용. (3) 사일런트 모드 / 방해 금지 모드 해제. [08-실시간-협업 / 08. 모바일 실시간 알림](../08-실시간-협업/08-모바일-실시간-알림.md) 참조.
