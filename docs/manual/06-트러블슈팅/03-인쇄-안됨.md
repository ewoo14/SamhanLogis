## 4. 본문

### 4-1. 자주 발생 패턴

| 증상 | 1차 진단 | 조치 |
| --- | --- | --- |
| [인쇄] 클릭 후 무반응 | 브라우저 종류 / 팝업 차단 | Edge / Chrome 권장, 팝업 허용 |
| 인쇄 미리보기에 한글 깨짐 | 글꼴 / 인코딩 | OS 한국어 글꼴 확인 |
| 인쇄 미리보기는 정상이나 출력 누락 | 프린터 드라이버 / 용지 | 드라이버 재설치 / 용지 |
| 표 / 컬럼이 잘림 | 용지 가로/세로 / 여백 | A4 세로 + 여백 5mm |
| 인쇄 후 부분 백지 | 페이지 break | 필요시 줄바꿈 조정 |

### 4-2. 브라우저 권장 설정

#### Edge (권장)

1. 우측 상단 ... > 인쇄 (Ctrl+P)
2. 용지: A4
3. 방향: 세로
4. 여백: 사용자 지정 (좌/우/위/아래 5mm)
5. 머리글/바닥글: 끄기
6. 배경 그래픽: 켜기

#### Chrome

1. 우측 상단 ⋮ > 인쇄 (Ctrl+P)
2. Edge 와 동일 설정
3. "기타 설정" > "배경 그래픽" 켜기

#### Internet Explorer

비호환. Edge / Chrome 으로 변경.

### 4-3. 양식별 인쇄

#### 거래명세표

1. 전표 상세 우측 상단 [인쇄] 클릭
2. 브라우저 인쇄 미리보기 자동 열림
3. 위 권장 설정으로 인쇄

#### 세금계산서 (P0-4 정식 운영 중, PR #139)

1. 세금계산서 상세 화면 (`/accounting/tax-invoices/:id`) 진입
2. ISSUED 또는 CANCELLED 상태에서 **[인쇄]** 버튼 클릭 → 새 창 NTS 표준 A4 양식
3. Edge 권장 설정으로 인쇄

자세한 절차는 [03-회계 / 03. 세금계산서](../03-회계/03-세금계산서.md) §4-4 참조.

#### 견적서 (P2-1 정식 운영 중, PR #148)

1. 견적서 상세 화면 (`/sales/estimates/:id`) 진입
2. **[인쇄]** 버튼 클릭 → 새 창 인쇄 양식
3. Edge 권장 설정으로 인쇄

자세한 절차는 [01-영업 / 06. 견적서](../01-영업/06-견적서.md) 참조.

#### 회계 보고서

[03-회계 / 02. 보고서](../03-회계/02-보고서.md) 의 시산표 / 거래처원장 화면에서 [인쇄] 클릭.

### 4-4. 프린터 / 네트워크 문제

| 증상 | 진단 | 조치 |
| --- | --- | --- |
| 인쇄 작업이 큐에서 멈춤 | 프린터 오프라인 | 프린터 전원 / 네트워크 |
| 큐 넘침 | 인쇄 작업 대량 | 큐 비우기 |
| 한 페이지만 출력 | 페이지 범위 설정 | 전체 페이지 선택 |
| 출력 색상 다름 | 흑백/컬러 설정 | 프린터 설정 |

### 4-5. PDF 우회 (긴급)

프린터 환경 문제 시.

1. 인쇄 미리보기에서 "PDF 로 저장" 선택
2. PDF 다운로드
3. 다른 PC / 다른 프린터에서 PDF 인쇄

## 6. FAQ

**Q1. 흑백 프린터에서 색상 표시?**
A. 자동 흑백 변환. 표 색상이 회색 음영으로 출력. 시인성 떨어짐 시 IT 관리자 양식 조정 요청.

**Q2. 인쇄 시 페이지 break 가 이상해요.**
A. 브라우저 측 자동 break. 양식 측 CSS @page 정책으로 조정 (IT 관리자).

**Q3. 모바일에서 인쇄 가능?**
A. 모바일 OS 인쇄 기능 또는 PDF 저장 후 PC 인쇄.

**Q4. 양식 변경을 요청하려면?**
A. IT 관리자에게 요청. 사용자 이미지 → mock → 미세 조정 3~5회 iteration 후 PR 발행 ([feedback_print_design_iteration.md] 정책).

**Q5. 견적서 / 세금계산서 인쇄는?**
A. 두 양식 모두 정식 인쇄 기능이 운영 중입니다. 세금계산서는 PR #139 (P0-4), 견적서는 PR #148 (P2-1) 로 출시되었습니다. 각 상세 화면의 **[인쇄]** 버튼을 클릭하세요.
