## 4. 본문

### 4-1. 로그인 / 권한

**Q. 비밀번호를 잊었습니다.**
A. 로그인 화면 **[비밀번호를 잊으셨나요?]** 링크로 셀프 재설정 가능합니다 (P0-2, PR #138 정식 출시). [06-트러블슈팅 / 01. 로그인 실패](../06-트러블슈팅/01-로그인-실패.md).

**Q. 5회 실패해 잠겼습니다.**
A. IT 관리자 잠금 해제 요청.

**Q. 본인 ROLE 확인은?**
A. 우측 상단 본인 이름 > [내 정보].

**Q. ROLE 변경은?**
A. IT 관리자 / 인사 담당자 신청. [00-시작하기 / 03. 역할별 권한](../00-시작하기/03-역할별-권한.md).

### 4-2. 영업

**Q. 거래처 신규 등록은?**
A. P0-6 4탭 등록 UI 정식 운영 중 (PR #141, SP-01 메뉴 정합화). 좌측 사이드바 **[판매] > [거래처 관리] > [신규 등록]** 으로 즉시 등록. [01-영업 / 01. 거래처 등록](../01-영업/01-거래처-등록.md).

**Q. 전표 결재 후 수정?**
A. [수정 요청 워크플로우](../08-실시간-협업/05-수정-요청-워크플로우.md) 활용.

**Q. 견적서 발송은?**
A. P2-1 미구현. Legacy v4 또는 Excel 우회. [01-영업 / 06. 견적서](../01-영업/06-견적서.md).

**Q. 거래처 주문 자동 변환은?**
A. ✅ 운영. [01-영업 / 05. 거래처 주문](../01-영업/05-거래처-주문.md).

**Q. 전표번호 형식?**
A. `YYYY/MM/DD-{순번}` 형식입니다. 순번은 출고전표/입고전표/배차 등 메뉴·업무 속성별로 독립 증가하므로, 같은 날짜의 출고전표 `1`번과 입고전표 `1`번은 공존할 수 있습니다. UUID는 내부 PK라 화면에는 표시하지 않습니다.

### 4-3. 창고

**Q. 입고 검수 UI 는?**
A. P0-9 미구현. 종이 양식 + IT 관리자 우회. [02-창고 / 01. 입고 처리](../02-창고/01-입고-처리.md).

**Q. 출고 부분 처리?**
A. 미구현. 전표 라인 수정 + 재결재.

**Q. 재고 실사는?**
A. P2-6 정식 운영 중 (PR #148 ✅). [02-창고 / 05. 재고 실사](../02-창고/05-재고-실사.md) 참조.

**Q. 창고간 이동은?**
A. ✅ 운영. transfer 화면. [02-창고 / 03. 재고 조회](../02-창고/03-재고-조회.md).

**Q. 안전재고 알림은?**
A. P1-3 운영 중 (PR #143 ✅). [관리] > [안전재고 임계 설정] 에서 품목별 임계값 설정 후 헤더 배지 + 알림 list 에서 확인하세요.

### 4-4. 회계

**Q. 손익계산서 / 재무상태표 보고서는?**
A. P0-1 Slice A+B+C 로 11개 보고서 화면 운영 중 (PR #134~#137). 잔여 5건은 장기 backlog. [03-회계 / 02. 보고서](../03-회계/02-보고서.md) 참조.

**Q. 세금계산서 발행은?**
A. P0-4 운영 중 (PR #139 ✅). NTS 종이 양식 인쇄 정식 운영. NTS API 전자 연계는 장기 backlog. [03-회계 / 03. 세금계산서](../03-회계/03-세금계산서.md) 참조.

**Q. 월말 마감은?**
A. P2-3 운영 중 (PR #148 ✅). [03-회계 / 04. 월말 마감](../03-회계/04-월말-마감.md) 참조.

**Q. 자동 분개 결과는?**
A. 분개 list 에서 전표번호로 검색.

**Q. 분개 차변/대변 안 맞으면?**
A. 저장 비활성. 합계 검토.

### 4-5. 모바일

**Q. 모바일 앱 설치는?**
A. Google Play / App Store / Expo URL. [04-모바일 / 01. 기사 앱](../04-모바일/01-기사-앱.md).

**Q. 영업 직원 native 앱은?**
A. P1-4 운영 중 (PR #144 ✅). Expo EAS Build 정식 배포. [04-모바일 / 03. 영업 앱](../04-모바일/03-영업-앱.md) 참조.

**Q. GPS 권한 거부했어요.**
A. 설정 > 앱 > 권한 재허용. [06-트러블슈팅 / 04. 모바일 접속 오류](../06-트러블슈팅/04-모바일-접속-오류.md).

**Q. 사진 첨부는?**
A. P1-8 운영 중 (PR #147 ✅). 검수/배송/영업 방문 3종 — MinIO 저장 + RN 카메라/갤러리. [04-모바일 / 04. 사진 첨부](../04-모바일/04-사진-첨부.md) 참조.

**Q. 푸시 알림 안 옵니다.**
A. 권한 + 사일런트 모드 확인. [08-실시간-협업 / 08. 모바일 실시간 알림](../08-실시간-협업/08-모바일-실시간-알림.md).

### 4-6. 배차 (arologis)

**Q. 카카오톡 배차 자동 등록은?**
A. P1-5 Frontend UI 운영 중 (PR #145 ✅). `/arologis/admin/auto-dispatch` 에서 바로 사용 가능. [05-arologis / 01. 카카오톡 배차](../05-arologis/01-카카오톡-배차.md) 참조.

**Q. 인성데이타 vendor 연계는?**
A. DriverMatcher Insung 모드. [05-arologis / 03. 기사 배정](../05-arologis/03-기사-배정.md).

**Q. 기사 배정 드래그 자동 매칭은?**
A. P1-5 배차 UI 운영 중 (PR #145 ✅). 상세 자동 매칭 알고리즘 고도화는 장기 backlog 입니다.

### 4-7. 실시간 협업 (Stage 4)

**Q. 다른 직원 변경이 안 보여요.**
A. 새로고침 → SSE 연결 확인. [08-실시간-협업 / 01. 실시간 동기화](../08-실시간-협업/01-실시간-동기화.md).

**Q. 수정 횟수 chip 색상 의미?**
A. 0=회색 / 1~4=파랑 / 5~9=주황 / 10+=빨강. [08-실시간-협업 / 03. 수정 횟수 카운트](../08-실시간-협업/03-수정-횟수-카운트.md).

**Q. 잠금 banner 가 떴어요.**
A. 다른 직원이 편집 중. [수정 요청](../08-실시간-협업/05-수정-요청-워크플로우.md) 활용.

**Q. 수정 복원 권한은?**
A. MASTER, MANAGER 만. [08-실시간-협업 / 04. 수정 복원](../08-실시간-협업/04-수정-복원.md).

### 4-8. 기타

**Q. 시스템 점검 일정은?**
A. MASTER 가 헤더 / 종 알림으로 사전 공지.

**Q. 데이터 백업은?**
A. AWS 마이그레이션 (Phase 11, PR #152) 완료로 RDS auto backup 이 운영 중입니다. [07-부록 / 01. FAQ](01-FAQ.md) 또는 IT 관리자에게 확인하세요.

**Q. 한국어 깨짐?**
A. OS 한국어 언어팩 / 브라우저 글꼴. [06-트러블슈팅 / 05. 기타](../06-트러블슈팅/05-기타.md).

**Q. 30분 자동 만료가 짧아요.**
A. 보안 정책. 변경 불가. 임시저장 활용.

**Q. 인쇄가 안 됩니다.**
A. Edge / Chrome 권장. [06-트러블슈팅 / 03. 인쇄 안 됨](../06-트러블슈팅/03-인쇄-안됨.md).
