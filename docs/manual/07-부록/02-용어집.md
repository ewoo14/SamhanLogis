## 4. 본문

### 4-1. 한국 회계 표준 용어

| 용어 | 영문 / 약자 | 설명 |
| --- | --- | --- |
| 분개 | Journal Entry | 거래를 차변/대변으로 기록 |
| 차변 | Debit | 회계의 왼쪽 (자산 증가 / 비용 / 부채 감소) |
| 대변 | Credit | 회계의 오른쪽 (자산 감소 / 수익 / 부채 증가) |
| 시산표 | Trial Balance | 월말 잔액 검증표 |
| 거래처원장 | Partner Ledger | 거래처별 거래 내역 |
| 손익계산서 | Income Statement | 일정 기간 수익/비용/순이익 (P0-1 미구현) |
| 재무상태표 | Balance Sheet | 특정 시점 자산/부채/자본 (P0-1 미구현) |
| 세금계산서 | Tax Invoice | 부가가치세 신고용 거래 증빙 |
| 부가세예수금 | Output VAT | 매출 시 거래처로부터 받은 부가세 |
| 매출원가 | COGS (Cost of Goods Sold) | 판매된 재고의 원가 |
| 미수금 | Accounts Receivable | 받을 돈 |
| 미지급금 | Accounts Payable | 줘야 할 돈 |
| 결산 | Closing | 회계연도 마감 (12/31) |
| 표준 계정과목 코드 | Standard Account Code | 100/200/300/400/500/800/900 |
| 일반기업회계기준 | K-GAAP | 한국 일반 법인 회계 표준 |
| 외상매출금 | Trade Receivables | 외상으로 판 미수금 |
| 외상매입금 | Trade Payables | 외상으로 산 미지급금 |
| 재고자산 | Inventory | 보유 재고의 자산 가치 |
| 재고자산평가손익 | Inventory Valuation Gain/Loss | 실사 차이 보정 분개 |

### 4-2. ERP 일반 용어

| 용어 | 영문 / 약자 | 설명 |
| --- | --- | --- |
| 전표 | Slip | 거래 단위 (영업/창고/회계 공통) |
| 거래처 | Partner | 고객 / 공급사 |
| 품목 | Item / Product | 판매 / 매입 단위 |
| Lot | Lot | 입고 단위 (유효기간 / 단가 묶음) |
| FIFO | First In First Out | 선입선출 (출고 우선 순위) |
| 매출 마감 | Sales Closing | 일정 기간 매출 정산 |
| 월말 마감 | Month-End Closing | 한 달 회계 거래 확정 |
| 재고 실사 | Inventory Audit | 시스템 재고 vs 실 재고 비교 (한국 회계 표준 의무) |
| DPS | Digital Picking System | 디지털 피킹 보조 |
| 결재 라인 | Approval Line | 결재 진행 단계 |
| 자동 분개 | Auto-Journal | 전표 → 회계 자동 발행 |
| 역분개 | Reversing Entry | 분개 취소용 반대 분개 |
| Idempotency | 멱등성 | 중복 호출 시 결과 동일 |

## 6. FAQ

**Q1. 용어가 누락되었어요.**
A. IT 관리자 / 매뉴얼 작성팀에게 추가 요청.

**Q2. 영문 용어집은?**
A. 미제공. 한국어 100%.

**Q3. K-GAAP 과 K-IFRS 차이는?**
A. K-GAAP = 한국 일반 법인 (일반기업회계기준). K-IFRS = 상장사 / 대형 법인. (주)삼한공조시스템은 K-GAAP 적용.

**Q4. 도메인 status 가 자주 바뀌나요?**
A. 핵심 11 status 는 안정. 신규 status 추가 시 매뉴얼 갱신.
