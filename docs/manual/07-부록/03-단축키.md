# 03. 단축키 일람

> **Stage 안내**: Stage 3 ✅ — Phase 12 step-6 본 PR 에서 7-section 패턴으로 재작성. desktop electron-vite 단축키.

---

## 1. 구현 상태

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| 브라우저 표준 단축키 | ✅ 운영 | Edge / Chrome 표준 |
| Electron 단축키 | ✅ 운영 | desktop |
| 페이지별 커스텀 단축키 | ⏳ 부분 | 일부 페이지 |
| 사용자 커스텀 단축키 | ⛔ 미구현 | 장기 backlog |

(주)삼한공조시스템 desktop electron-vite 앱에서 자주 사용하는 단축키 일람.

---

## 2. 대상 독자

- desktop 사용자 (모든 ROLE)
- 빠른 입력을 위해 단축키 학습하는 신입
- 키보드 위주 작업 직원 (회계 / 분개 입력)

---

## 3. 학습 내용

- 표준 브라우저 단축키
- 페이지 navigation 단축키
- 폼 입력 단축키
- Electron 표준 단축키
- 페이지별 커스텀 단축키 (있는 경우)

---

## 4. 본문

### 4-1. 표준 브라우저 단축키

| 단축키 | 동작 |
| --- | --- |
| F5 | 새로고침 |
| Ctrl + R | 새로고침 |
| Ctrl + Shift + R | 강력 새로고침 (캐시 무시) |
| Ctrl + F | 페이지 내 검색 |
| Ctrl + P | 인쇄 |
| Ctrl + S | 페이지 저장 (HTML) |
| Ctrl + + | 화면 확대 |
| Ctrl + - | 화면 축소 |
| Ctrl + 0 | 확대 초기화 |
| F11 | 전체화면 토글 |
| F12 | 개발자 도구 (IT 관리자용) |

### 4-2. 페이지 navigation

| 단축키 | 동작 |
| --- | --- |
| Alt + ← | 이전 페이지 |
| Alt + → | 다음 페이지 |
| Alt + Home | 메인 화면 |
| Tab | 다음 입력 박스 |
| Shift + Tab | 이전 입력 박스 |
| Enter | 폼 제출 / [확인] 버튼 |
| Esc | dialog 닫기 / [취소] |

### 4-3. 폼 입력

| 단축키 | 동작 |
| --- | --- |
| Ctrl + S | 임시저장 (지원 페이지) |
| Ctrl + Enter | 결재요청 / 제출 (지원 페이지) |
| Ctrl + Z | 입력 취소 |
| Ctrl + Y | 다시 실행 |
| Ctrl + C | 복사 |
| Ctrl + V | 붙여넣기 |
| Ctrl + X | 잘라내기 |
| Ctrl + A | 전체 선택 |

### 4-4. Electron 표준

| 단축키 | 동작 |
| --- | --- |
| Ctrl + Q | 앱 종료 |
| Ctrl + W | 창 닫기 |
| Ctrl + N | 새 창 (지원 시) |
| F11 | 전체화면 |

### 4-5. 페이지별 커스텀 (참고)

#### 전표 list

| 단축키 | 동작 |
| --- | --- |
| N | 신규 등록 (focus 가 list 일 때) |
| Enter | 선택 전표 상세 |
| Del | 선택 전표 삭제 (DRAFT 만) |

#### 분개 list

| 단축키 | 동작 |
| --- | --- |
| N | 신규 분개 등록 |
| + | 라인 추가 |
| Ctrl + B | 차변/대변 균형 검증 |

#### 재고 조회

| 단축키 | 동작 |
| --- | --- |
| Ctrl + F | 품목 검색 focus |

> 페이지별 단축키는 일부 페이지만 지원. 미지원 시 마우스 사용.

mobile-staff 앱은 터치 위주. 단축키 미지원.

### 4-7. 사용자 커스텀 단축키

미구현. 장기 backlog. 현재는 시스템 표준만 제공.

## 6. FAQ

**Q1. F12 (개발자 도구) 사용 가능?**
A. IT 관리자 / 개발자 용도. 일반 직원 사용 비권장.

**Q2. Ctrl + S 가 페이지 저장으로 동작?**
A. 일부 페이지는 임시저장으로 override. 미override 페이지는 브라우저 기본 동작.

**Q3. 단축키 충돌 시?**
A. OS / 브라우저 우선. 페이지 커스텀이 무시될 수 있음.

**Q4. 모바일 단축키는?**
A. 미지원. 터치 사용.

**Q5. 사용자 커스텀 단축키 가능?**
A. 미구현. 표준 단축키만.
