# 01. 분개(전표) 입력

> **Stage 안내**: Stage 3 ✅ — Phase 12 step-6 본 PR 에서 7-section 패턴으로 재작성.

---

## 1. 구현 상태

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| Backend (accounting-service) | ✅ 운영 | `JournalController` 5 endpoint |
| 시드 데이터 | ✅ | `JournalSeeder` 50건 |
| 3 status 라이프사이클 | ✅ 운영 | DRAFT / POSTED / VOID |
| 한국 일반기업회계기준 표준 계정과목 코드 | ✅ 운영 | 100/200/300/400/500/800/900 |
| 분개장 desktop UI | ✅ 운영 | 본 PR 시점 활성화 |
| 자동 분개 (slip-service 연동) | ✅ 운영 | DELIVERED 시 |
| 분개장 Excel export | ✅ 운영 (P1-6) | 당월 기준 / 상태 필터 연동 다운로드 |

(주)삼한공조시스템 회계 분개는 한국 일반기업회계기준에 따라 차변/대변 균형을 맞춰 입력하는 기본 단위입니다.

---

## 2. 대상 독자

- 회계 분개를 직접 입력하는 회계 직원 (ACCOUNTANT)
- 자동 분개 결과를 검토하는 ACCOUNTANT
- 외부 감사 / 외주 회계 (VIEWER 또는 ACCOUNTANT)

---

## 3. 학습 내용

- 분개 list 진입 + 신규 등록
- 차변 / 대변 라인 입력
- 한국 표준 계정과목 코드 검색
- POSTED / VOID status 흐름
- 자동 분개 (slip → 회계) 결과 확인

---

## 4. 본문

### 4-1. 분개 메뉴 진입

좌측 사이드바 **[회계]** > **[분개]** 클릭. 분개 list 화면이 표시됩니다.

### 4-2. 신규 분개 등록

list 상단 **[신규 등록]** 버튼 클릭.

#### 4-2-1. 헤더 정보

| 필드 | 필수 | 설명 |
| --- | :-: | --- |
| 분개일 | ✅ | YYYY-MM-DD |
| 적요 | ✅ | 거래 내용 요약 |
| 거래처 | — | 거래처 검색 (선택) |
| 참조번호 | — | 전표번호 등 |

#### 4-2-2. 차변 / 대변 라인

각 라인은 차변 또는 대변 1건. 차변 합계 = 대변 합계 강제 검증.

| 필드 | 필수 | 설명 |
| --- | :-: | --- |
| 차/대 | ✅ | 차변 또는 대변 라디오 |
| 계정 | ✅ | 표준 계정과목 코드 검색 |
| 금액 | ✅ | 원화 |
| 메모 | — | 라인별 |

> 차변 합계 ≠ 대변 합계 시 [저장] 버튼이 비활성화됩니다.

### 4-3. 한국 표준 계정과목 코드

한국 일반기업회계기준 표준 계정과목 코드 체계.

| 코드 시작 | 분류 | 예시 |
| --- | --- | --- |
| 100~ | 자산 | 100 현금, 110 보통예금, 130 외상매출금 |
| 200~ | 부채 | 200 외상매입금, 210 미지급금 |
| 300~ | 자본 | 300 자본금 |
| 400~ | 매출 | 400 상품매출 |
| 500~ | 원가 | 500 매출원가 |
| 800~ | 판관비 | 800 급여, 820 임차료 |
| 900~ | 기타손익 | 910 이자수익 |

### 4-4. 저장 + POSTED 처리

- **[임시저장]** — DRAFT 상태 (이후 수정 가능)
- **[전기]** — POSTED 상태 (재무제표 반영 시작)

POSTED 후에도 사유 입력 시 [VOID] 처리 가능. VOID 시 역분개 자동 발행.

### 4-5. 자동 분개 확인

slip-service 가 자동 발행한 분개는 분개 list 에서 다음으로 검색.

- 거래처 / 기간 / 참조번호 (전표번호) 필터
- 자동 분개 표시: 적요에 "자동: SLIP-2026-0001" 형식

### 4-6. Stage 4 실시간 협업

분개 list / 상세 / 폼 모두 [수정 횟수 chip](../08-실시간-협업/03-수정-횟수-카운트.md) + [audit overlay](../08-실시간-협업/02-수정-이력-보기.md) 표시. 다른 회계 직원이 같은 분개를 동시에 수정 시 [잠금 banner](../08-실시간-협업/06-잠금-정책.md) 노출. POSTED 분개 수정 시 [수정 요청](../08-실시간-협업/05-수정-요청-워크플로우.md) 흐름 권장.

## 6. FAQ

**Q1. 차변/대변이 안 맞으면 어떻게 되나요?**
A. 저장 버튼이 비활성화됩니다. 합계 표시를 확인하고 차이만큼 라인 보정.

**Q2. POSTED 후 수정 가능한가요?**
A. 직접 수정 불가. [VOID] 처리 후 역분개 자동 발행 + 신규 분개 등록.

**Q3. 자동 분개 결과를 수동 보정해도 되나요?**
A. 권장하지 않음. 가능하면 원 전표을 CANCELED 처리하여 자동 역분개 발생 후 재발행.

**Q4. 표준 계정과목을 모릅니다.**
A. 분개 폼의 계정 검색 박스에서 한글 (예: "현금") 또는 코드 (예: "100") 로 검색. 외주 회계와 협의.

**Q5. 시산표는 어디서 보나요?**
A. [02. 보고서](02-보고서.md) 의 시산표 메뉴.
