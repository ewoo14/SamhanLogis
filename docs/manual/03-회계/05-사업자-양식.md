## 2. 대상 독자

- 사업자 정보를 등록/관리하는 시스템 관리자 (MASTER)
- 세금계산서 발행 시 공급자 정보 확인이 필요한 회계 담당자 (ACCOUNTANT)

---

## 3. 사업자 양식 화면 (`/accounting/supplier-profiles`)

좌측 사이드바 **[회계]** > **[사업자 양식]** 을 클릭하면 현재 등록된 사업자 목록이 표시됩니다.

### 3-1. 표시 필드 (7개)

| 필드 | 설명 | seed 값 |
| --- | --- | --- |
| 사업자등록번호 | 10자리 숫자 (하이픈 없이 표시) | 2148720659 |
| 상호 | 법인명 또는 개인사업자명 | （주）삼한공조시스템 |
| 대표자 | 법인 대표자명 | — |
| 사업장주소 | 사업장 소재지 전체 주소 | — |
| 업태 | 사업 업태 (예: 도소매) | — |
| 종목 | 사업 종목 (예: 가전제품) | — |
| 이메일 | 세금계산서 발송용 이메일 | — |

### 3-2. 기본 사업자 (Primary)

목록에서 **[기본]** 배지가 표시된 사업자가 세금계산서 일괄발행 시 공급자 정보로 사용됩니다.
기본 사업자는 항상 1개이어야 하며, 삭제 시 오류가 발생합니다.

---

## 4. 사업자 정보 수정 (MASTER 전용)

> ACCOUNTANT 권한은 "수정" 버튼이 비활성화(disabled)됩니다. (PR #160 disabled UX 패턴)

**수정 절차**:
1. 사업자 카드 또는 목록 행 우측 **[수정]** 버튼 클릭
2. 편집 폼에서 필드 수정
3. **[저장]** 버튼 클릭 → 낙관적 락(version) 충돌 없으면 즉시 반영

**수정 가능 필드**: 상호, 대표자, 사업장주소, 업태, 종목, 이메일
(사업자등록번호는 수정 불가 — 변경 필요 시 삭제 후 재등록)

---

## 5. 신규 사업자 추가

1. 화면 우측 상단 **[신규 추가]** 버튼 클릭
2. 7개 필드 입력
3. **[저장]** 클릭 → 목록에 추가

> 사업자등록번호 10자리 유효성 검증이 즉시 수행됩니다.

---

## 6. 기본 사업자 전환

비기본 사업자 행의 **[기본 사업자 전환]** 버튼 클릭 → 해당 사업자가 primary 로 변경됩니다.
이전 primary 사업자는 자동으로 비기본 처리됩니다.

> 세금계산서 일괄발행 배치 생성 이후 primary 를 변경하면,
> 이후 생성 배치부터 새 공급자 정보가 반영됩니다. (기존 배치 snapshot 은 변경 없음)

---

## 7. 사업자 삭제 제약

- **기본 사업자(primary)는 삭제 불가**: `기본 사업자는 삭제할 수 없습니다` 오류 toast 표시
- 삭제 시 soft delete 처리 (물리 삭제 X) — 복원 가능

---

## 8. DataGrid 키보드 단축키 안내

세금계산서 일괄발행 결과 (Tab 2) 및 판매조회 페이지의 데이터 그리드에서
아래 단축키로 Excel-like 인터랙션이 가능합니다.

### 8-1. 셀 선택

| 단축키 | 동작 |
| --- | --- |
| **단일 클릭** | 셀 1개 선택 (이전 선택 모두 해제) |
| **Shift+클릭** | 기준점~클릭 위치 사각형 범위 선택 |
| **Ctrl+클릭** | 개별 셀 선택 추가 또는 해제 (토글) |
| **Ctrl+A** | 현재 페이지 전체 셀 선택 |

### 8-2. 복사

| 단축키 | 동작 |
| --- | --- |
| **Ctrl+C** | 선택 셀 내용을 TSV 형식으로 클립보드 복사 |

**TSV(Tab-Separated Values) 형식**: 열은 탭(`Tab`)으로, 행은 줄바꿈(`Enter`)으로 구분됩니다.
복사 후 Excel 또는 스프레드시트에 붙여넣기(Ctrl+V)하면 셀 배치가 그대로 유지됩니다.

**복사 예시**:
```
슬립번호    거래처명         공급가액
SLP-001   （주）삼한공조시스템   1,000,000
SLP-002   QA테스트거래처       500,000
```

### 8-3. 열헤더 필터

특정 컬럼 헤더를 클릭하면 필터 입력 popover 가 표시됩니다.

**사용 방법**:
1. 필터링하려는 컬럼 헤더 클릭 (예: "거래처명")
2. 검색어 입력 (예: "삼한")
3. Enter 또는 **[적용]** 클릭 → 해당 컬럼 값으로 행 필터링

> 필터 초기화: 입력 내용 지우고 Enter 또는 **[초기화]** 클릭
