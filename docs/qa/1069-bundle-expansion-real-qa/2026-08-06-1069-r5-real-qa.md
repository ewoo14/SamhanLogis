## 2. REMOTE 교체 컨트롤

**가시성 PASS.** 같은 실제 화면에서 다음 컨트롤을 확인했다.

```text
실외기 제외                    → checkbox visible=true
실외기 교체                    → input visible=true
input placeholder               → 교체 모델코드 (미입력=기본)
판넬 컨트롤 aria-label          → 판넬 옵션 (미입력=기본)
```

R2의 “별도 입력 컨트롤이 보이지 않았다”는 관측은 현재 화면 조합에서는 재현되지 않았다. 판넬은 `select`로 `미입력=기본 | 판넬제외 | 블랙판넬 | 승강판넬 | 공청판넬` 중 도메인 라벨을 선택하고, 실외기는 `교체 모델코드 (미입력=기본)` 텍스트를 입력한다. 라벨이 `판넬 옵션` 대 `교체 모델코드`로 구분되어 있어 규칙 차이는 사용자가 식별할 수 있다. 이번 R5에서는 REMOTE 값을 변경하는 별도 동작은 수행하지 않았다.

## 3. 저장·재조회

**미실시: 저장 단계에서 차단됨.** `블랙판넬` 변경 후 실제 저장 버튼을 눌렀으나 disabled 상태라 브라우저가 클릭을 수행하지 못했다. 저장 API POST는 0건이며 상세 화면으로 이동하지 않았으므로 저장 결과의 상세 재조회도 미실시다. 저장을 지어내거나 mock으로 대체하지 않았다.

DB read-only 확인:

```text
slips | 141 | 2026-08-06 09:39:37.454985
```

위 값은 저장 차단 후의 read-only 스냅샷이다. 이번 세션에서는 저장 POST가 없으므로 이 수치만으로 새 전표 생성 여부를 추정하지 않는다.
