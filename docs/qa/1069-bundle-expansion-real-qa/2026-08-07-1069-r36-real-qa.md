- 실행 수단: 인앱 브라우저를 사용하지 않고, 셸에서 Playwright `chromium.launch({ headless: false })`로 설치된 Chromium 1161을 직접 실행했다.

- 계정: `dev_manager` (비밀번호 원문은 보고서에 기록하지 않음).
- 로그인 실측: `POST http://localhost:8080/auth/login` → `200`.

- slip-service: `2026-08-06T15:31:39Z` (무변경).
- 데스크톱 번들: `out/` `2026-08-07 04:14`, `expansionPending` 7건.
- `hasMock=false`: 번들 `isMockMode()`가 `VITE_MOCK_MODE === "1" || false`이며, 이번 실행에서 실제 `localhost:8080` API의 `200/201/204` 응답을 확인했다.
