## 2. A 실측 — 정액 차감과 VAT 축

화면에 `전표 라인단가는 부가세 포함 단가`라고 표시되어 있어, 화면 단가는 VAT 포함 축으로 판정했다.

거래처 ① `랜드유통(최경호)` + 품목 ① `AC072CS6PBH1SY`의 실 화면:

```text
정가(product API sellingPrice)                         2,752,200
화면 전개 1행 AC072CN6PBH1                       1,011,775
화면 전개 2행 AC072CXAPBH1                     1,562,450
화면 전개 3행 PC6NUNK1NW                         104,060
화면 전개 4행 AR-EH05                             13,915
화면 총액                                       2,692,200
정가 대비 화면 차감                               -60,000
```

응답 원문인 `POST /slips/expand-line`의 `data`는 다음이었다.

```text
AC072CN6PBH1   unitPrice 1,041,775  INDOOR  setHead=true
AC072CXAPBH1   unitPrice 1,562,450  OUTDOOR
PC6NUNK1NW     unitPrice   104,060  PANEL
AR-EH05        unitPrice    13,915  REMOTE
API 합계                                  2,722,200
```

즉 API 확장 결과 자체가 정가보다 `30,000` 낮고, 화면은 첫 구성품을 `1,041,775 → 1,011,775`로 다시 `30,000` 낮춘다. 관측상 정액 차감은 실제로 작동하지만 `30,000` 단회가 아니라 `60,000`이다.

## 3. B 판정 — 차감 구성 분해

```text
기준: 거래처 ② + 같은 품목 ① 화면 총액                       2,752,200
거래처 ① API expand-line 합계(정액 1회 반영 후)              2,722,200  (-30,000)
거래처 ① 화면 전개 총액(정액이 다시 반영된 후)               2,692,200  (-60,000)
home 45%만 적용된 경우의 45% 가격                             관측 안 됨
```

45%가 추가로 곱해진 흔적은 없다. 그러나 정액이 API와 화면에서 각각 적용되어, **율·정액의 전형적 이중 적용은 아니지만 정액·정액 이중 적용이라는 셋째 결함**이 관측됐다. 따라서 B는 FAIL이다.

## 5. E 관측 — 전개 구성품에 반영된 방식

부모 `AC072CS6PBH1SY` 행은 화면에 남지 않고 4행으로 전개된다.

```text
                 거래처 ② API/화면      거래처 ① API       거래처 ① 화면
AC072CN6PBH1     1,053,775             1,041,775         1,011,775
AC072CXAPBH1     1,580,450             1,562,450         1,562,450
PC6NUNK1NW         104,060               104,060           104,060
AR-EH05             13,915                13,915            13,915
합계              2,752,200             2,722,200         2,692,200
```

관측만 정리하면:

1. API의 첫 정액 `30,000`은 실내기 `12,000`과 실외기 `18,000`의 합계 차이로 나타난다.
2. 화면은 API 실내기 단가에서 다시 `30,000`을 빼고, 실외기·판넬·리모컨에는 추가 차감을 보이지 않는다.
3. 따라서 부모 base 한 곳에서만 빠진 뒤 구성품에 배분된 상태가 아니다. 전개 API와 화면 계산 두 층에서 차감된다.
