### 1) select 값과 실제 요청·응답·화면

화면 select aria-label="판넬 옵션 (미입력=기본)"의 실제 option은 다음과 같았다.

~~~text
미입력=기본 value=""
판넬제외   value="판넬제외"
블랙판넬   value="블랙판넬"
~~~

## 2. 응답과 화면 일치 결과

- expand-line의 unitPrice는 VAT 포함 단가로 화면 단가와 직접 대조했다.
- 블랙판넬·판넬제외·승강판넬·공청판넬·기본 모두 응답의 modelCode, unitPrice, 행 구성이 직후 화면과 일치했다.
- 빠른 변경 후 최종 블랙판넬 화면도 PC6NBNK1NW / 150,040, 실내기 1,034,755, 실외기 1,553,490으로 최종 200 응답과 일치했다.
- 저장 API 응답과 DB의 unit_price는 공급가액이고, unit_price_with_vat가 화면의 VAT 포함 단가다. 따라서 DB의 940686, 1412264, 136400, 12650과 화면의 1,034,755, 1,553,490, 150,040, 13,915 차이는 불일치가 아니라 컬럼 의미 차이다.

## 4. 결함·실 사용자 도달 여부

R7에서 R5-01의 재현 절차는 재현되지 않았다. 실 사용자 동선인 판매 → 새 판매전표 → 거래처 1012555999 → AC072CS6PBH1SY → 판넬 옵션 변경으로 다음이 모두 닫혔다.

1. 응답이 화면에 반영된다.
2. 판넬 교체 시 형제 구성품을 포함해 전체 구성품 집합이 교체된다.
3. 판넬제외 시 PANEL 형제가 남지 않는다.
4. 성공 후 저장 차단 상태가 해제된다.
5. 저장·목록·상세·DB 계보가 이어진다.

따라서 **R7 대상 제품 결함 없음 / 일곱 항목 PASS / 라이브QA 게이트 ③ PASS**로 판정한다. 이번 QA가 생성한 2026/08/06-3 DRAFT 전표는 실제 DB에 남아 있으며, QA 범위 밖의 삭제·취소 조작은 하지 않았다.
