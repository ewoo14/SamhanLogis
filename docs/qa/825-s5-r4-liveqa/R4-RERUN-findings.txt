   · SELECTED+계좌1건인데 type=ALL 요청 → 조회 5 (확대 없음)
   *** 증명: 저장 범위가 실행 시 다른 카테고리로 조용히 확대되지 않는다.

   · null 명시 → 400 동일
   · 오타      → 400 "scopeMode 는 ALL 또는 SELECTED 이어야 합니다"

3) V65 DB 제약                   ✅ 해소 확인 → V65-constraint-probe.txt
   신규 INSERT  SELECTED+빈refs        → REJECT
   신규 INSERT  ALL+계좌refs           → REJECT
   신규 INSERT  ALL+대출refs만         → REJECT
   신규 INSERT  ALL+빈refs             → ACCEPT
   신규 INSERT  SELECTED+카드1건       → ACCEPT
   UPDATE legacy 위반 유지             → REJECT   ← NOT VALID 가 UPDATE 는 계속 검사
   UPDATE legacy → 유효 상태           → ACCEPT   ← V64 주석의 "재저장 시 갱신" 성립
   (전부 ROLLBACK · 최종 18행 · ZZ-probe 행 0)
   *** 증명: NOT VALID 는 legacy 행 검증만 보류할 뿐 신규 INSERT/UPDATE 에는
       계속 적용된다. legacy 보존과 신규 불변식이 동시에 성립. ***

4) scopeMode 전환 시 refs 정리    ✅ 해소 확인
