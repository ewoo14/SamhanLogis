유효성 오류 상세 필드 dateFrom: 시작일(2026-05-20)이 종료일(2026-05-15)보다 늦습니다.
서버 응답: 422 Unprocessable Entity — 날짜 범위를 수정 후 다시 조회하세요.
조치 방법
  • 날짜 오류 (422): 시작일이 종료일 이전이어야 합니다. 최대 31일 범위만 허용됩니다.
  • 서버 오류 (502): KFTC DRY_RUN 모드 placeholder 응답입니다. Phase 11 실 연동 후 KFTC 서비스 상태를 확인하세요.
  • 핀번호 오류: 계좌 핀번호가 일치하지 않으면 403 응답이 반환됩니다.
  • 권한 오류: ACCOUNTANT / MANAGER / MASTER 권한이 필요합니다.
