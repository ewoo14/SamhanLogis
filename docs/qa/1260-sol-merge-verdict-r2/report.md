## ② 홈멀티 `기본` 3갈래 확인

화면에서 서로 다른 실내기를 직접 수량 입력했다.

- 360 카세트 2
- 인피니트 1way 3
- 일반 1way 4

`기본` 선택의 레거시 계산 함수만 단독 실행하면 `AR-EC05=6`, `AR-CH01=3`으로 3갈래 집계가 맞다. 그러나 사용자가 실제 화면에서 거치는 전체 재계산 결과는 다음처럼 달랐다.

| 화면 선택 | 실제 화면 최종 수량 |
|---|---|
| 기본 | `AWR-WE13N=2`, `AR-EC05=0`, `AR-CH01=0` |
| 유선 | `AWR-WE13N=2`, 유선 키트 9 |
| 컬러 | `AWR-WG00N=9`, 컬러 유선 키트 9 |

즉 `기본`에서 일반 1way 4개와 인피니트 3개의 표준 리모컨이 사라지고, `유선`도 본체 9개가 아니라 활성 360 규칙 수량 2개만 남는다. 화면 전체 재계산에서 활성 수량동기화 규칙의 360 target이 적용된 뒤 비소유 레거시 리모컨이 보존되지 않는 경계로 재현됐다.

**도달 결함 1 — BLOCKER.** 사용자가 `기본` 또는 `유선`을 선택하면 실제 발행 수량이 실내기 수량과 달라진다.
