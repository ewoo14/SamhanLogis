## 확인된 것

### ✅ 복사 UI 가 계승됐습니다

`03-preview-with-copy-button.png` — 미리보기 영역에 복사 도구가 나옵니다.

```text
선택한 배차 대상만 복사 · 거래처명 / 전표번호 / 발송멘트 / 단톡방
                                              [ 선택 복사 (0건) ]
```

- 라벨에 **선택 건수**가 표시됩니다
- 선택이 0건이면 **비활성** — 빈 클립보드를 만들지 않습니다
- 레거시와 같은 항목 구성(거래처명 / 전표번호 / 발송멘트 / 단톡방)

### ⚠️ 복사 **내용**은 검증하지 못했습니다

미리보기가 **어느 날짜에도 출고전표 0건**을 반환했습니다.

| 배차일 | `slips` 의 OUTBOUND 건수 | 미리보기 결과 |
|---|---:|---|
| 2026-07-16 | 125 | **출고전표 0건 · 매핑 0건 · 미매핑 0건** |
| 2026-06-08 | 1,908 | **출고전표 0건 · 매핑 0건 · 미매핑 0건** |

화면 문구도 *"해당 일자에 발송할 출고전표가 없습니다."* 입니다.

⟹ 대상이 없어 **복사 텍스트를 실제로 만들어 볼 수 없었습니다.** 단위 테스트(`dispatchSmsClipboard.test.ts`)에서 직렬화 형식은 확인됐으나, **실 데이터로는 미검증**입니다.

## 🚨 이 QA 가 드러낸 별도 의문

`slips` 에 해당 일자 OUTBOUND 전표가 **1,908건** 있는데 미리보기가 **0건**입니다.

`DispatchBatchPreviewService.preview()` 는 출고전표를 조회해 `partnerCode`(없으면 `partnerName` 스냅샷)로 단톡방 매핑을 붙입니다(`:83-86`). 조회 자체가 0건인지, 매핑 단계에서 전부 탈락하는지는 **이번 라운드에서 가리지 못했습니다.**

앞선 정찰에서 나온 *"단톡방 매핑 112건 전부인데 실제 전달 0건"* 과 같은 계열일 수 있습니다.

⟹ **다음 라운드 각도로 이월합니다.**
