## ① 회귀 원인

PR 변경에서 `explodeSetParts()`가 `resolveSingleRemoteRows_()`의 결과만 사용하도록 바뀌었다. 이 함수는 UI 옵션 `컬러유선리모컨`을 DB 정본 변형 `컬러유선`으로 고정 비교했지만, 실제 구성품 정본은 `컬러`였다. 따라서 후보가 없을 때 기본 무선 행으로 복귀하던 main 동작이 사라져 리모컨 행 전체가 수량 0이 됐다.

수정은 후보가 있으면 구성품 설정을 그대로 사용하고, 후보가 없을 때만 기본 구성품 행을 반환하도록 제한했다. 가격 계산, 컬러 가격 미반영, 360 할인, 받침대 토글은 수정하지 않았다.

## ④ 수량 표현 축 계열 확인

수량 표현 경로를 `resolveSingleRemoteRows_()`와 `explodeSetParts()` 기준으로 훑었다. 무선 기본, 유선 선택, 컬러 선택, 리모컨 제외의 활성행 계산을 확인했다. 라이브 전수에서 컬러 선택 시 기본 무선 1을 유지했고, 유선은 `AWR-WE13N=1`, 무선 복귀는 `AR-EH05=1`이었다. 다른 가격 축(컬러 가격, 할인, 받침대 수량)은 범위 밖으로 변경하지 않았다.
