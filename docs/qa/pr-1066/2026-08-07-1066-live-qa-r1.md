## 계정 및 사전 확인

| 계정 | 역할 | 비밀번호 | 확인 경로 |
|---|---|---|---|
| `kimgicheol` | SALES | `samhan!2026` | 저장소의 기존 QA 시나리오 문서에 명시된 값 사용 |
| `kimeunji` | ACCOUNTANT | 확인 불가 | auth_db에는 password hash만 있어 추측/복구하지 않음 |
| `dev_manager` | MANAGER | `dev_p05_pass!` | 요청으로 제공된 값 |

읽기 전용 DB 확인 결과 `SLIP_OUTBOUND` 결재선은 작성자 → 검수자(`OUTBOUND_INSPECT`, USER: `kimgicheol`, `kimeunji`) → 출고담당 순서였다. DB 직접 INSERT/UPDATE는 수행하지 않았다.
