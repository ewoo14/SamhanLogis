## 종합 판정

**R3 종합: 판정불가(결재선 SALES 자격증명 미확보) + S3 PASS.**

현재 계정 환경에서 `kimgicheol`은 저장소에 남은 기존 QA 비밀번호 `${QA_MASTER_PASSWORD}`과 최신 핸드오프의 dev 시드 비밀번호 `${QA_DEV_DEFAULT_PASSWORD}` 모두 `POST /auth/login` `401`이었다. 비밀번호를 더 추측하지 않았다. 따라서 S1의 SALES GUI 활성/실행 및 S4의 핵심 lifecycle은 발화하지 못했다. S2도 `kimeunji` 비밀번호가 auth DB hash만으로 확인 불가하여 로그인하지 않았다.

반면 결재선 밖 `dev_sales`로는 상세 조회 `200`, `canInspect=false`, GUI 버튼 disabled, 강제 `POST .../inspect` `403`을 확인하여 S3 회귀 방어는 PASS다.
