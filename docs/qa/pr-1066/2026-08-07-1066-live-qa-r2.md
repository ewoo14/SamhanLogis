## 중단 사유

실제 Chromium으로 `http://localhost:5200/login`을 열었으나 로그인 화면이 생성되지 않았다. Vite가 다음 모듈을 HTTP 500으로 반환했다.

```text
GET /styles/global.css                         500
GET /components/common/AppVersionGate.tsx     500
GET /components/common/BiometricLockGate.tsx  500
GET /components/common/AppNoticeGate.tsx      500
Failed to resolve entry for package "@samhan/design-system".
```

`clients/desktop/node_modules/@samhan/design-system/package.json`의 `main`/`exports`는 `./dist/index.js`를 가리키지만, 해당 워크트리 패키지에는 `dist/`가 없다. 따라서 로그인·전표 목록·전표 상세 GUI가 로드되지 않았고, `/auth/login` 또는 `/slips/{id}` 네트워크 호출까지 도달하지 못했다.

사용자 지시의 “전제가 틀리면 고치지 말고 중단·보고”에 따라 컨테이너, renderer, 패키지를 재기동·재빌드·수정하지 않았다.
