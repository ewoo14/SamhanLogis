읽기 전용 집계:

```sql
WITH exposed AS (
  SELECT s.idempotency_key, s.delivery_address, a.request_fingerprint,
         (s.idempotency_key LIKE 'PO-MRG-%') AS is_merge, a.created_at
  FROM slips s
  JOIN slip_publish_audit a ON a.slip_id = s.id
  WHERE s.is_deleted = false
    AND a.is_deleted = false
    AND a.source_type = 'PARTNER_ORDER'
)
SELECT count(*),
       count(*) FILTER (WHERE idempotency_key IS NOT NULL AND request_fingerprint IS NOT NULL AND delivery_address IS NULL),
       count(*) FILTER (WHERE NOT (idempotency_key IS NOT NULL AND request_fingerprint IS NOT NULL AND delivery_address IS NULL)),
       count(*) FILTER (WHERE NOT is_merge AND idempotency_key IS NOT NULL AND request_fingerprint IS NOT NULL AND delivery_address IS NULL),
       count(*) FILTER (WHERE is_merge AND idempotency_key IS NOT NULL AND request_fingerprint IS NOT NULL AND delivery_address IS NULL),
       count(*) FILTER (WHERE created_at > TIMESTAMP '2026-07-31 15:39:42'),
       min(created_at), max(created_at)
FROM exposed;
```

원문: `16|16|0|13|3|0|2026-05-30 13:37:02.525309|2026-07-05 12:04:52.238171`
