사이드바 Hidden 디자인 결정 스펙 (SP-D1 2026-05-18)

항목 결정 이유
숨김 방식 display: none (조건부 렌더링) visibility: hidden 이나 opacity: 0 은 레이아웃 공간을 차지하여 사이드바 높이 낭비. 접근성 관점에서도 display:none 이 스크린리더 완전 제외.
회색 비활성화 금지 비활성 스타일 적용 불가 메뉴가 존재한다는 것을 SALES 가 인지하면 URL 직접 접근 시도 유발. 완전 미노출이 보안 UX 원칙.
카테고리 헤더 하위 항목 전체 hidden 시 카테고리도 hidden 빈 카테고리 레이블만 남는 경우 방지. 예) SALES 사이드바에 "회계" 레이블 노출되면 혼란.
권한 소스 세션 role → 매트릭스 API 조회 프론트엔드 사이드바는 GET /api/v1/rbac/me/pages 응답 기반. 매트릭스 저장 → 세션 갱신 → 사이드바 실시간 반영 (페이지 리로드 없음, SWR).
URL 직접 접근 사이드바 hidden + 라우트 가드 이중 방어 사이드바 미노출은 UX 레이어. 라우트 가드 (BE: @PreAuthorize, FE: RoleGuard) 가 실제 차단. 04 mock 참조.
