NTS 국세청
전자세금계산서 API 에러
⚠
NTS-E1 · PLACEHOLDER_DETECTED
국세청 API 키에 placeholder 값이 입력되었습니다
NTS_API_KEY=placeholder 값은 실제 국세청 전자세금계산서 API 키가 아닙니다. Phase 11 (AWS 이전) 이후 실 API 키로 교체하기 전까지 세금계산서 발행은 DRY_RUN mock 응답만 반환됩니다. 실 운영 환경에서는 반드시 국세청 발급 API 키를 .env 에 등록하십시오.
ℹ
NTS-E2 · KEY_NOT_SET
국세청 API 키가 설정되지 않았습니다
NTS_API_KEY 환경변수가 비어 있습니다. 세금계산서 발행을 위해 국세청 홈택스에서 발급된 API 키를 서버 환경변수에 등록해 주십시오. Phase 11 이전에는 DRY_RUN 모드로 동작합니다.
Aligo SMS
SMS 발송 API 에러
⚠
ALIGO-E1 · PLACEHOLDER_DETECTED
Aligo API 키에 placeholder 값이 입력되었습니다
ALIGO_API_KEY=placeholder 또는 ALIGO_USER_ID=placeholder 로 설정되어 있어 실제 SMS 발송이 불가능합니다. 현재 모든 SMS 발송은 DRY_RUN으로 처리되며 수신자에게 문자가 발송되지 않습니다. Aligo 관리자 콘솔에서 발급된 API 키와 발신번호를 등록해 주십시오.
⚠
ALIGO-E2 · SENDER_NOT_REGISTERED
등록되지 않은 발신번호입니다
ALIGO_SENDER=010-XXXX-XXXX 번호가 Aligo 플랫폼에 등록된 발신번호가 아닙니다. SMS 발신번호는 Aligo 관리 콘솔에서 사전 등록(본인인증) 이 완료되어야 합니다. 통신사 스팸 필터 차단 방지를 위해 반드시 등록된 번호를 사용하십시오.
Naver Clova OCR
OCR API 에러
⚠
CLOVA-E1 · PLACEHOLDER_DETECTED
Clova OCR Secret에 placeholder 값이 입력되었습니다
NAVER_CLOVA_OCR_SECRET=placeholder 값은 실제 Naver Cloud 발급 OCR Secret이 아닙니다. 현재 영수증 업로드 시 DRY_RUN mock 분석 결과가 반환됩니다. 실 OCR 결과를 위해 Naver Cloud Platform 콘솔에서 APIGW URL 및 Secret Key를 발급받아 등록해 주십시오.
⚠
CLOVA-E2 · INVALID_APIGW_URL
OCR APIGW URL 형식이 올바르지 않습니다
NAVER_CLOVA_OCR_APIGW_URL 값이 유효한 HTTPS URL이 아닙니다. Naver Cloud Platform 에서 발급된 OCR APIGW 주소는 https://​*.apigw.ntruss.com/custom/v1/... 형식이어야 합니다.
KFTC 오픈뱅킹
오픈뱅킹 API 에러
⚠
KFTC-E1 · PLACEHOLDER_DETECTED
KFTC Client ID에 placeholder 값이 입력되었습니다
KFTC_CLIENT_ID=placeholder 또는 KFTC_CLIENT_SECRET=placeholder 가 설정되어 있어 오픈뱅킹 실 API 호출이 불가능합니다. 현재 입금 내역 조회는 Sandbox mock 응답으로 처리됩니다. 금융결제원 오픈뱅킹 포털에서 기관 등록 후 발급된 Client ID / Secret을 등록해 주십시오.
⚠
KFTC-E2 · TOKEN_EXPIRED
오픈뱅킹 액세스 토큰이 만료되었습니다
KFTC 오픈뱅킹 액세스 토큰 유효기간이 초과되었습니다. (유효기간: 90일) 자동 갱신에 실패했거나 최초 발급이 필요합니다. 금융결제원 오픈뱅킹 포털에서 토큰을 재발급하거나 자동 갱신 스케줄러 설정을 확인해 주십시오.
