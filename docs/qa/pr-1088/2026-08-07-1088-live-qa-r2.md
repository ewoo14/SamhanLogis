## 중단 사유

브라우저(:5291) 우회는 금지되어 있어 `clients/arologis-desktop`에서 `npm run dev`로 Electron을 실행했다. 렌더러 개발 서버는 `http://localhost:5173`에서 기동했으나 Electron 메인 프로세스가 다음 오류로 종료됐다.

```text
Error: Electron uninstall
    at getElectronPath (.../node_modules/electron-vite/...)
```

`clients/arologis-desktop/node_modules/electron`에 실행 가능한 Electron 바이너리가 없었고, 이미 존재하는 패키지 실행 파일도 확인되지 않았다. 재설치·재빌드·컨테이너 조작·브라우저 대체는 하지 않았다.

따라서 preload IPC의 `getToken` 브리지가 포함된 Electron GUI를 열 수 없었고, 실제 GUI 클릭·네트워크 관측·스크린샷을 수행할 수 없었다. 표본 중 `driver_locations`와 `dispatch_notifications`도 0이므로 GPS·회신 영역은 앱이 실행되더라도 별도 판정 조건이 필요하다.
