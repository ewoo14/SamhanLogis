| 항목 | count |
|---|---:|

수신 그룹 표본은 `S19-20260805-01`이다. DB 직접 쓰기, 컨테이너 재시작/재빌드는 하지 않았다.

참고로 최초 Electron의 기존 저장 세션에서는 `GET /admin/arologis/permissions/my`가 403이어서 메뉴가 숨겨졌다. GUI에서 로그아웃 후 `admin / ${QA_AROLOGIS_ADMIN_PASSWORD}`로 재로그인하자 로그인 200 및 permissions 200이 되었고 `수신 배차 그룹` 메뉴가 표시됐다. 아래 시나리오는 이 새 로그인 세션에서 수행했다.

## S1. 사이드바에서 수신 배차 그룹 진입

1. 발화 조건: `admin / ${QA_AROLOGIS_ADMIN_PASSWORD}`, 수신 배차 그룹 1건, 운영 배차 26건.
2. 클릭 경로: Electron 로그인 → 로그인 버튼 → 배차 사이드바의 `수신 배차 그룹` 링크 클릭 → 배차 지정일을 `2026-08-05`로 입력.
3. 네트워크: `POST /auth/admin/login` 200, `GET /auth/me` 200, `GET /admin/arologis/permissions/my` 200, `GET /admin/arologis/dispatch-groups?dispatchDate=2026-08-05` 200.
4. GUI 실제 표시: `S19-20260805-01`, 차량 `S19 QA 차량 01`, 운송사 `AROLOGIS · 아로로지스`, 운영 `수신 전용`이 표시됐다. 화면 설명대로 수정/재분류 UI는 없었다.
5. 스크린샷: [사이드바 링크](screenshots/r4-S1-sidebar-link-real-qa.png), [진입 화면](screenshots/r4-S1-received-groups-real-qa.png)
6. 판정: **PASS**

## S3. 배차 상세 진입 affordance 재확인

1. 발화 조건: 운영 배차 26건. `driver_locations=0`, `dispatch_notifications=0`이라 GPS/회신 표본은 없다.
2. 클릭 경로: Electron 사이드바 `미배차` 클릭으로 배차 목록 진입 후 목록 `tbody`의 상세 진입 요소를 재확인. `a=0`, `button=8`; 8개 버튼의 라벨은 모두 `수동 배차로 이동`이며 배차 상세로 이동하는 링크/버튼은 없다. 상세 진입을 시도하거나 코드를 수정하지 않았다.
3. 네트워크: `GET /admin/arologis/dispatches/unassigned?date=2026-08-07` 200, 관련 저장 결과 `GET /admin/arologis/dispatches/history/latest?programType=UNASSIGNED` 200, `GET /admin/arologis/dispatches/history?...programType=UNASSIGNED...` 200.
4. GUI 실제 표시: 미배차 목록과 `수동 배차로 이동` 버튼은 표시되지만 배차 상세 클릭 진입로는 표시되지 않았다. GPS/회신은 표본 0이라 내용 판정도 불가하다.
5. 스크린샷: [상세 진입 재확인](screenshots/r4-S3-detail-entry-recheck-real-qa.png)
6. 판정: **판정불가** — 상세 진입 affordance 부재는 확인됐으나, 전표번호·문서번호 하이퍼링크 및 뒤로 가기 정본은 이슈 #1094 범위다. GPS/회신도 표본 0이다.

## S5. 권한 없는 계정의 메뉴 비노출

1. 발화 조건: `qa_acct`(AROLOGIS_ACCOUNTANT) 또는 `qa_mgr`(AROLOGIS_MANAGER) 로그인 필요.
2. 클릭 경로: admin 로그아웃 후 로그인 화면까지 확인. 두 계정의 비밀번호가 제공되지 않아 아이디 입력/로그인 시도는 하지 않았다.
3. 네트워크: 권한 없는 계정 로그인 요청을 하지 않았으므로 해당 API·상태코드는 없음.
4. GUI 실제 표시: 로그인 화면만 확인했으며, 권한 없는 계정으로 로그인한 뒤 링크가 숨겨지는지는 확인하지 못했다.
5. 스크린샷: [S5 확인 불가 상태](screenshots/r4-S5-no-permission-unverified-real-qa.png)
6. 판정: **확인 불가** — 비밀번호를 추측하지 않았다.
