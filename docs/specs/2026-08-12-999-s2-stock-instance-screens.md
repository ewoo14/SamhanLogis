# #999 S2 — 재고관리 품목 모달 2종 (품목리스트 · 재고수불부)

> 출처: 개발책임자 지시 (2026-08-12) + 이카운트 재고수불부 실물 첨부

## 진입점

**재고관리 화면의 품목코드(모델명)에 하이퍼링크**를 넣는다. 클릭하면 모달로 두 화면을 볼 수 있다.

```
재고관리
  AP145BNPPHH1  ← 클릭
      ├ 「품목리스트」   모달
      └ 「재고수불부」   모달
```

⚠️ 현재 재고관리 화면(`clients/desktop/src/renderer/routes/warehouse/`)에는 **인스턴스 단위 화면이 하나도 없다.** `InventoryStockBalancePage` 는 가용/실재고/예약 3구분 **집계**만 보여준다. 둘 다 신규 구현이다.

---

## ① 품목리스트 모달 — 인스턴스 단위

선택한 품목에 대해 **우리 창고에 있는 재고 개체**를 나열한다.

| 보여줄 것 | 비고 |
|---|---|
| **시리얼키** | `SI-` + 6자. **바코드 포함** |
| 창고 | |
| 재고 상태 (`status`) | `AVAILABLE` / `SHIPPED` |
| **품목 상태 (`quality`)** | **여기서 변경한다** |

### 품목 상태 값 — 개발책임자 확정 (2026-08-12)

```
정상 · 중고 · 파손 · 재포장 · 박스불량
NORMAL · USED · DAMAGED · REPACKAGED · BOX_DEFECT
```

### 변경 규칙 — 출고 전에만

| `status` | 상태 변경 |
|---|---|
| `AVAILABLE` | 가능 |
| `SHIPPED` | **잠김 (읽기 전용)** |

출고 후 파손을 발견하면 **별도 반품 경로로만** 처리한다. 출고 시점 상태가 고정돼 과거 기록이 변하지 않는다.

## ② 재고수불부 모달 — 품목 단위

🔑 **시리얼 인스턴스 단위가 아니다.** 해당 품목의 **입출고 내역**만 본다.

### 기간

- 기본 = **오늘 날짜 기준 월초 ~ 오늘**
- **날짜 범위를 수정할 수 있어야 한다**

### 양식 — 이카운트 실물 기준

첨부된 `AP145BNPPHH1` 재고수불부(2026/05/01 ~ 2026/08/12, 467행)에서 뽑은 구조다.

**헤더 1행**
```
회사명 : (주)삼한공조시스템 / {시작일}  ~ {종료일}  / 재고수불부 I / {품목명} ({품목코드})
```

**컬럼 9개**
```
일자 | 품목명 | 품목코드 | 창고명 | 거래처명 | 적요 | 입고수량 | 출고수량 | 재고수량
```

**행 규칙**

| 행 | 내용 |
|---|---|
| 첫 행 | `전일재고` — `재고수량` 칸에만 기초 잔량 (예 `81`) |
| 입고 행 | `입고수량` 만 채움 · `출고수량` 빈칸 |
| 출고 행 | `출고수량` 만 채움 · `입고수량` 빈칸 |
| 모든 행 | `재고수량` = **누적 잔량** (running balance) |
| 월 소계 | `2026/08  계` |
| 마지막 | `합계` 행 · 출력 일시 |

**실물 표본**
```
전일재고    |                |              |                  |                          |                                   |    |    | 81
2026/05/02 | AP145BNPPHH1…  | AP145BNPPHH1 | 삼성창고 (초월 무갑) | 삼성전자(주)               | 7343889694                        | 16 |    | 97
2026/05/02 | AP145BNPPHH1…  | AP145BNPPHH1 | 삼성창고 (초월 무갑) | 꽃달시스템-이종승          | 지방/울산광역시 북구 사청6길 6 …   |    |  1 | 96
2026/08/12 | AP145BNPPHH1…  | AP145BNPPHH1 | 삼성창고 (초월 무갑) | 형성시스템 - 박두순        | 경기도 광주시 파발로59번길 30      |    |  2 | 44
2026/08  계 |
합계        |
```

### 적요 칸의 두 얼굴

```
입고 행  전표번호        7343889694
출고 행  배송주소        지방/울산광역시 북구 사청6길 6 (화봉동) 1층상가
```

🚨 **`지방/` 는 주소 접두사가 아니라 태그다.** 이 프로젝트의 확정 규칙이다 — 주소 문자열의 일부로 다루면 안 된다. (`야적` 도 같다.)
