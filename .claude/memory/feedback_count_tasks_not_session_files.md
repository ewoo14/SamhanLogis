2026-08-13 개발책임자 정정: **"5개라고? 표시는 3 MCP tasks만 돌고 있다고 나왔는데?"**

PM 이 `~/.codex/sessions/**.jsonl` 의 **최근 N분 내 수정된 파일 수**로 "활성 codex 5개" 라고 보고했다. 실제 가동은 **3개**였다. 끝난 세션도 종료 시점에 마지막 기록을 남기기 때문에 최근 파일 목록에 섞인다.

**How to apply**
```
✅ 가동 수 = TaskList / 태스크 알림으로 센다 (사용자 화면과 같은 숫자)
🚫 세션 파일 mtime 으로 "활성" 을 추정하지 않는다
```

## 세션 파일이 여전히 유용한 곳 — **굶은 세션 판별**

파일 나이는 "돌고 있나" 가 아니라 **"진전이 있나"** 를 본다. 태스크는 살아 있는데 파일이 오래 안 바뀌면 굶은 것이다([[feedback_codex_parallel_throughput_collapse]]).

```
2026-08-13 실측
  #1181 SOL   59분 무기록 · 산출물 0  → TaskStop 후 재발주
  #1162 LUNA  25분 무기록 · 산출물 0  → TaskStop 후 재발주
```

⟹ **두 신호를 같이 본다**
```
태스크 상태  = 몇 개가 살아 있나   (가동 수는 이걸로 센다)
파일 mtime   = 그 중 몇 개가 실제로 일하나
워크트리 diff = 산출물이 실제로 나오고 있나
```
셋이 어긋나면(태스크는 살아 있는데 mtime 이 멈추고 diff 가 0) 그 세션은 굶은 것이고, 정지시켜도 잃을 것이 없다.
