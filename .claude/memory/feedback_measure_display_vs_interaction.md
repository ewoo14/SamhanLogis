# 표시를 쟀다고 조작을 잰 것이 아니다 (2026-07-25 #902/#924 실측)

## 사건 1 — 적대검증이 놓치고 개발책임자가 먼저 잡았다

#902 라운드 fix 가 "제외될 행이 저장될 것처럼 보이는 금액을 표시하는 모순"을 없애려고 `excludedFromSave` 일 때 표시를 `'0'` 으로 억제했다. 그런데 그 값이 **controlled input 의 `value`** 라서 타이핑이 매 렌더마다 `'0'` 으로 되돌아갔다 — **공급가액·부가세·합계 칸에 아예 입력할 수 없게** 됐고, `excludedFromSave` 는 *품목 미선택이거나 수량 0 인 모든 행*이라 **신규 전표의 초기 5행 전부**가 해당됐다.

**CODEX SOL 2차 라운드는 이 각도를 배정받고도 놓쳤다.** 보고서에는 이렇게 적혀 있었다:
```
EXCLUDED_AMOUNTS={"supply":"0","vat":"0","total":"0"}   ← 표시가 0 인지만 확인
```
**표시가 0 인지만 재고 그 칸에 입력을 시도하지 않았다.** 개발책임자가 실사용 중 *"단가 공급가액, 부가세는 왜 수정이 안되지?"* 로 먼저 발견했다.

**How to apply** — 입력 가능한 요소를 건드리는 fix 는 **표시 검사만으로 끝내지 말 것**. 리뷰 브리프와 QA 스펙에 최소한 이 두 가지를 함께 넣는다:
1. 그 칸에 **값을 넣고 화면에 남는지**(`fill` → `inputValue()` 대조)
2. `disabled` 여부만 보지 말 것 — **`disabled=false` 인데 controlled value 고정이면 겉보기엔 편집 가능한데 실제로는 불가능**하다(실측 그대로였다)

억제·마스킹 계열 fix 의 일반 규칙: **읽기 전용 표시를 억제하는 것과 입력 요소의 value 를 고정하는 것은 완전히 다르다.** 후자는 기능 제거다.

## 사건 2 — 라이브 캡처의 대기 조건이 로딩 화면을 결함으로 위장했다

#924 fix 후 라이브 재검증에서 **같은 오측정을 두 번** 했다.
1. 고정 4초 대기 → 표가 **"조회 중"** 상태에서 캡처. `0건` 이 로딩 전 상태인지 결함인지 구별 불가.
2. `'조회 중' 텍스트가 사라질 때까지` 로 바꿨더니 **그 조건이 쿼리 시작 전에 즉시 참**이 돼 같은 오측정 반복.

원인: react-query 전역 `retry: 1` 이라 502 도 `응답시간 × 2 + 렌더` 가 필요하다. 그 사이 **"fix 가 작동하지 않는다"고 결론지을 뻔했다.**

**How to apply**
- 부재(`!includes('로딩중')`)를 대기 조건으로 쓰지 말 것 — **렌더 전에 즉시 참**이 된다. **나타남**을 기다려라(배너·행·버튼).
- 확신이 안 서면 **API 로 결정적 측정**을 먼저 하고 GUI 는 증거로 쓴다. 이번에도 API 측정 덕에 제품이 아니라 하네스 문제임을 분리했다.
- 오측정 산출물은 **삭제하고 재캡처**하며, 그 사실을 PR 에 남긴다(무엇을 잘못 쟀는지가 다음 사람에게 필요하다).

## 사건 3 — PM 이 수단을 지시해 결함을 만들었다

같은 슬라이스에서 PM 이 *"입력 단계에서 정수만 받게 하라"* 고 **수단을 지시**했고, 구현자는 단가와 동일한 `.replace(/[^0-9]/g,'')` 를 적용했다. 단가는 소수점이 무의미하지만 **수량은 자릿수가 재조합**된다:
```
"2.7" → "27"(10배 오주문) · "0.5" → "05" · "-3" → "3" · "1e3" → "13"
전부 제외 안내 없이 저장 가능한 행이 됨
```
원래 결함(BE `@Positive Integer` 에서 절사)보다 **더 나빴다.**

⟹ [[feedback_canonical_workflow]] 의 *"PM 은 불변식만 말하고 구현 수단을 지시하지 않는다"* 를 어긴 직접 실측 사례. 올바른 불변식은 **"사용자가 입력한 수량이 의도하지 않은 다른 수량으로 조용히 바뀌지 않는다"** 였고, 그렇게 다시 주자 구현자는 **변조 대신 거부**(전체 문자열 게이트 `/^\d*$/` 불일치 시 `onChange` 미호출)를 골랐다.
