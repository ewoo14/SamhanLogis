개발책임자 (2026-08-16):

> *"내가 필요없다고 한 GAS는 빼고 나머지는 모두 누락된 기능이라든지 결과 표시방식이
> 모두 동등해야해. UI디자인을 그대로 따라갈 필요는 없어."*

```text
✅ 동등해야 하는 것
   기능           레거시가 하는 일을 현행도 할 수 있어야 한다
   결과 표시방식    같은 입력에 같은 값이 · 같은 단위로 · 같은 구분으로
                  금액 포맷·반올림 자리 · 항목 분류 · 정렬 축 · 합계 산출 · 라벨 의미

🚫 동등할 필요 없는 것
   UI 디자인       화면 배치 · 색 · 폰트 · 컴포넌트 형태 · 버튼 위치
```

## 🔑 헷갈릴 때의 단일 질문

> **"사용자가 그 화면을 보고 내리는 판단이 달라지는가"**

```text
달라진다      → 결과 표시방식이다 (격차 · 맞춰야 한다)
안 달라진다    → UI 디자인이다 (격차 아님)
```

**Why:** "레거시와 같게" 를 UI 복제로 읽으면 쓸데없는 일을 하게 되고,
"디자인은 자유" 로 읽으면 **금액 자리수·항목 분류·합계 묶음** 같은 진짜 격차를 놓친다.
두 오독이 정반대 방향이라 기준선이 필요하다.

🚩 대표적으로 **격차인 것**: 금액 반올림 자리 · 항목을 어느 탭/분류로 넣는가 ·
합계를 무엇으로 묶는가 · 라벨이 가리키는 의미 · 정렬 축 · 생략/이월 규칙

🚩 대표적으로 **격차 아닌 것**: 버튼 위치 · 색 · 표 스타일 · 아이콘 · 여백

## 제외 대상

```text
에어디자이너 · 제이시스템 OCR — 개발책임자가 불필요로 확정
```

## How to apply

- 대조 보고서의 "다름" 을 볼 때 **먼저 UI 디자인 차이인지 가른다**
- "없음"(기능 부재)은 전부 격차다 — 만들어야 한다
- 금액에 닿는 항목은 따로 표시한다 — **한 자리만 달라도 청구액이 달라진다**
- 🚫 애매한 것을 "UI 차이" 로 밀어 넣지 마라. 애매하면 격차로 보고 확인받아라
