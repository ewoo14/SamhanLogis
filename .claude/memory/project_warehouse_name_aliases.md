2026-08-13 개발책임자 지시: **"삼성창고나 초월창고, 삼한창고는 같은 창고인거고, 이화창고와 상일물류 또는 상일창고도 같은 창고인거야."**

```
그룹 A   삼성창고 = 초월창고 = 삼한창고
그룹 B   이화창고 = 상일물류 = 상일창고
```

**왜 중요한가**: 삼성전자 「배송상황조회」 엑셀(가입고 업로드 소스)의 `고객명` 컬럼에는 사람이 아니라 **우리 창고명**이 들어온다. 그 이름이 우리 DB 창고와 1:1로 안 맞는다. 별칭을 모르면 같은 창고가 여러 건으로 갈라지거나 매칭 실패로 가입고가 통째로 누락된다.

**How to apply**: 엑셀 창고명 → DB 창고 매핑은 반드시 별칭 표를 거친다. 이름 문자열 일치로 조인하지 말 것.

## ✅ 정본 확정 (2026-08-13 개발책임자)

> *"00003 삼성창고(초월 무갑)를 정본으로, 이화창고는 코드 2 맞아"*

| 엑셀 창고명 | DB 정본 |
|---|---|
| 삼성창고 · 초월창고 · 삼한창고 | **`00003` 삼성창고 (초월 무갑)** |
| 이화창고 · 상일물류 · 상일창고 | **`2` 상일물류** |

⟹ 그룹 A 에 DB 행이 셋 있으나(`00003`·`11152` 삼한창고(무갑리)·`11155` 2025-공항공사 초월창고) **가입고 매핑 대상은 `00003` 하나**다. 나머지 둘은 별개 행으로 남되 엑셀 창고명 매핑의 목적지가 아니다.

**How to apply**: 삼성전자 배송상황조회 엑셀을 가입고로 넣을 때 `고객명` 컬럼 값을 위 표로 치환한 뒤 DB 창고를 찾는다. 이름 문자열 직접 조인 금지.
